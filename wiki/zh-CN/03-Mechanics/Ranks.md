# 军衔 {#ranks}

每位飞行员都有一个**军衔**，从初级飞行员到高级海军上将。这是一架军事阶梯：8 个阶层，每层 3 个级别，共 24 个军衔，你靠 **PvE 积分**往上爬：它来自你的等级、经验，以及你消灭的外星人。飞行时，游戏只在飞行员的名字前显示一个小**符号**，让你一眼分清新手和老手。文字写法则在企业页面和符号的悬停提示里。

**一分钟了解**

- 你的军衔跟随你的 PvE 积分：狩猎、升级，军衔自然就来了。
- 共有 24 个：飞行员、中士、中尉、上尉、少校、上校、将军和海军上将，每个都分初级、普通和高级。
- 名字前的符号就是军衔：形状代表阶层，一到三个标记代表级别。
- 军衔是**终身的**：重置会保留你的等级、经验和击杀统计，所以也保留你的积分和军衔。
- 企业页面会列出你所在世界中本企业的前 50 名飞行员，并显示你离下一个军衔还有多远。

## 如何获得 PvE 积分 {#how-you-earn-pve-points}

你的 PvE 积分由三部分算出：

**等级 × 100 + 经验 ÷ 1,000（向下取整）+ 你消灭的每个外星人的积分**

越难对付的外星人越值钱：一次击杀按摧毁该外星人所需的伤害给积分。虫群的飞船和战队守卫有各自的积分。每次击杀都会以外星人自己的名字计入你的击杀统计。

| 外星人或飞船 | 每次击杀的 PvE 积分 |
| :--- | ---: |
| Seeker | 1 |
| Phantasm | 2 |
| Bulwark | 4 |
| Goombah | 7 |
| Crystalys | 16 |
| Boss Seeker | 5 |
| Seeker Slave | 1 |
| Pirate Boss | 10 |
| Pirate Scout | 1 |
| Dormant Force | 25 |
| Dormant Pulse | 10 |
| 守卫 I、II、III 的头领 | 10, 15, 25 |
| Brood Drone、Siege Escort、Wrath Guard（任何强度） | 1 |

例如，一名 4 级、经验 12,500 的飞行员消灭了 300 只 Seeker、80 只 Phantasm 和 10 只 Bulwark，积分是 400 + 12 + 300 + 160 + 40 = **912**，也就是初级中士。

**排行榜**页面（社区 › 排行榜）会显示你自己的积分是怎么构成的，其中的**名人堂**则列出最出色的飞行员。[虫群](/wiki/05-Swarms/Swarms.md)的飞船和[战队守卫](/wiki/03-Mechanics/Clans.md#clan-wardens)也在表里。

## 符号 {#the-symbols}

游戏把军衔画成一个小符号：代表阶层的**形状**，带有各自的颜色，以及代表级别的**一个、两个或三个标记**：初级一个，普通两个，高级三个。随着阶层升高，颜色从冷静朴素逐渐变为温暖明亮。

| 阶层 | 形状 | 颜色 |
| :--- | :--- | :--- |
| 飞行员 | 圆点 | 钢蓝色 |
| 中士 | 上下叠放的人字形 | 铜色 |
| 中尉 | 上下叠放的扁平横杠 | 银色 |
| 上尉 | 菱形 | 绿色 |
| 少校 | 朝上的三角形（三角旗） | 青色 |
| 上校 | 空心圆环 | 金色 |
| 将军 | 五角星 | 橙色 |
| 海军上将 | 上方开口的月桂花环，环绕一到三颗星 | 玫瑰色 |

## 在哪里看到它们 {#where-you-see-them}

飞行时你只看到**符号**，从来看不到文字。它位于飞行员名字之前：

- 飞船上方的名字标签，以及目标窗口；
- 聊天中，写下那一行的飞行员名字之前；
- 你的小队列表中，以及小地图上小队队友的悬停提示里；
- 击杀播报中，每个被点名的飞行员之前（外星人前面没有）；
- 名人堂、排行窗口，以及飞行员的个人资料页（大图）。

**文字**（初级中士、上尉 …）在企业页面和悬停提示里：把指针停在符号上。[企业飞行员](/wiki/03-Mechanics/Company-Pilots.md)是游戏自己的编队，没有军衔。

## 企业排名 {#the-company-ranking}

打开**经济 › 企业**。其中的**企业排名**部分按 PvE 积分列出**你所在世界中本企业的前 50 名飞行员**：名次、符号、名字和积分。列表上方是你自己的军衔、你的名次（“第 3 名，共 41 人”），以及一个显示你还需要多少 PvE 积分才能升到下一个军衔的进度条。**所有军衔**会展开一张包含全部 24 个军衔的表格，和上面那张一样。

- 还没有 PvE 积分的飞行员不会被列出：消灭一个外星人就能上榜。
- 列表针对**你的世界**：你所在企业中在另一个世界游玩的飞行员，会出现在那个世界的列表里。
- 只显示名字和公开的数字。

## 晋升 {#promotions}

- 当你达到新的军衔，会收到一条通知（“晋升：高级中士”）和一声简短轻柔的提示音。你离线期间达到的军衔，会在你下次登录时通知一次。
- 从**初级少校**起，晋升还会显示在你所在世界中飞行的本企业飞行员的聊天**系统**标签页里：“Nova 晋升为 初级少校。”

## 军衔与重置 {#ranks-and-the-wipe}

重置在这里什么也不改变。它保留你的等级、经验和击杀统计（[重置时间线](/wiki/03-Mechanics/Wipe-Timeline.md#cross-season-progression-permanent-buffs-)），而你的 PvE 积分由它们算出，所以你的积分和军衔会度过每一次重置。军衔是终身的。

## 需要多久 {#how-long-it-takes}

这些是根据飞行员狩猎速度模型得出的**估算**，不是测量。第二个军衔在狩猎的第一个小时内到手，中士在五小时内。每天狩猎大约两小时的飞行员，会以上尉或高级上尉结束第一个赛季。少校需要一两个赛季，上校需要两到五个，将军需要六到十一个。最后三个军衔需要超过 880 小时的狩猎，也就是每天两小时打十五个赛季，最后一个则超过 1,700 小时：它们只属于最出色的人。
