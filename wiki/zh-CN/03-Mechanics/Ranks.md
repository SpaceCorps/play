# 军衔 {#ranks}

每位飞行员都有一个**军衔**，从初级飞行员到高级海军上将。这是一架军事阶梯：8 个阶层，每层 3 个级别，共 24 个军衔。你的军衔来自你的 **PvE 积分**：它来自你的等级、经验，以及你消灭的外星人。每个军衔都要求一个**最低** PvE 积分，最高的六个军衔在每家企业里还有固定的**名额**。飞行时，游戏只在飞行员的名字前显示一个小**符号**，让你一眼分清一家企业的顶尖飞行员和新手；全服只有一名飞行员会在符号上方戴一顶金色的**王冠**。文字写法则在企业页面和符号的悬停提示里。

**一分钟了解**

- 你的企业只有一份飞行员名单，PvE 积分最多的飞行员排在最前。每家企业都有自己的名单，其他企业的飞行员从不与你竞争。
- 你的军衔是**积分达到其最低要求、且在你的企业里还有空名额的最高军衔**。
- 最高的六个军衔每家企业都有名额：**高级海军上将 1 名**（PvE 积分 50,000 起）、**海军上将 2 名**（45,000 起）、**初级海军上将 4 名**（40,000 起）、**高级将军 8 名**（30,000 起）、**将军 10 名**（27,500 起）和 **初级将军 15 名**（25,000 起）。更低的军衔不限人数，每一级比上一级少要求 2,500 积分，一直降到初级上尉的 2,500。
- **积分相同，军衔相同。** 积分相同的两名飞行员绝不会拿到不同的军衔。当某个军衔的最后一个名额落在并列的中间时，所有并列者都拿到更高的军衔，即使这会超出名额。
- 只有拥有 PvE 积分且在最近 30 天内飞行过的飞行员才会上名单。其他人在再次飞行之前都是初级飞行员，也没有名额。
- 符号上方的金色**王冠**标出全服（所有企业、三个世界）PvE 积分最多的飞行员。
- 你的军衔会变动。到高级上校为止，它只取决于你自己的积分，所以只会上升。最高的六个军衔还会随你企业的其他飞行员而变动：别人占了你上面的名额时，它们可能下降。下降从不通知；新的最高军衔会通知。
- 重置不会改变任何人的积分，所以名单不会重新开始。
- 名字前的符号就是军衔：阶层用形状表示，级别用一到三个标记表示。

## 军衔如何确定 {#the-company-ladder}

你所在企业的飞行员，**三个世界合在一起**，排成一列，PvE 积分最多的排在最前。这一列就是**榜单**。积分相同时，等级高的在前，再按资历老的在前，但这只决定名单的顺序：绝不会让他们拿到不同的军衔。你的军衔由两件事决定：你的积分和你企业的名额：

1. **每个军衔都有最低要求**的 PvE 积分（[见下表](#the-24-ranks)）。飞行员绝不会拥有积分未达到其最低要求的军衔。
2. **最高的六个军衔有名额。** 名额从上往下填，最高的军衔先填：积分达到 50,000 的最强飞行员拿到高级海军上将，直到它唯一的名额填满；剩下的飞行员里，积分达到 45,000 的最强者拿到海军上将，直到它的两个名额填满；依此类推，一直到初级将军。
3. **其他所有人拿到积分在这六个军衔之下所能达到的最高军衔**，最高是高级上校。达到某个军衔最低要求、却发现它的名额已满的飞行员，会落到对他开放的最高军衔。
4. **并列绝不拆开。** 积分相同的飞行员军衔相同。如果某个军衔的最后一个名额落在并列之中，整个并列都拿到更高的军衔，所以一个军衔的人数可以比名额多，但绝不会比应有的少。

**示例。** 一家企业最强的十二名飞行员，以及各自的军衔：

| 名次 | PvE 积分 | 军衔 |
| :---: | ---: | :--- |
| 1 | 60,000 | 高级海军上将 |
| 2 | 52,000 | 海军上将 |
| 3 | 51,000 | 海军上将 |
| 4 | 50,500 | 初级海军上将 |
| 5 | 44,000 | 初级海军上将 |
| 6 | 30,000 | 高级将军 |
| 7 | 29,000 | 将军 |
| 8 | 28,000 | 将军 |
| 9 | 26,000 | 初级将军 |
| 10 | 24,999 | 高级上校 |
| 11 | 21,000 | 上校 |
| 12 | 1,000 | 高级中士 |

第 4 名有 50,500 积分，达到了高级海军上将的最低要求，但高级海军上将唯一的名额和海军上将的两个名额都已被占，所以他是初级海军上将。第 7、8 名有 29,000 和 28,000：两人都达到将军的 27,500，没有达到高级将军的 30,000，而将军还有名额，所以两人都是将军。积分 24,999 的飞行员比初级将军差 1 分，是高级上校，也就是对他开放的最高军衔。如果排在最前的两名飞行员积分都是 60,000，两人都会是高级海军上将，接下来的两名（50,000 和 45,000）则是海军上将的两个名额。

> [!NOTE]
> 只有当一家企业里达到某个最低要求的飞行员比该军衔的名额多时，名额才会起限制作用。在小企业里，军衔仅由积分决定：一家企业里只有他一个人的飞行员，21,000 PvE 积分是上校，50,000 积分是高级海军上将。

## 谁在榜单上 {#who-is-on-the-ladder}

飞行员同时满足**以下三点**时，才在本企业的榜单上：

- 他在一家企业里；
- 他有 PvE 积分：第一次击杀就会让新飞行员上榜；
- 他最近 **30 天**内飞行过。

不在榜单上的飞行员，在任何显示军衔的地方都是**初级飞行员**，没有名额，也不在企业的名单里。设立这条规则，是为了让只试玩过一次就离开的飞行员不会永远待在最底层，也为了让长期不在的飞行员不能连续数月占着少数最高名额或王冠。

> [!TIP]
> 你不在的时候不会损失任何东西。你的积分会保留，当你再次出击，或只是打开企业页面，就会按你离开时的积分重新排位，得到那时这些积分和你企业的名额所给的军衔。

如果你更换企业，你的积分会随你而去，你会进入新企业的榜单，得到它的名额在那里给你的军衔。

## 你的军衔如何变动 {#your-rank-moves}

- **到高级上校为止只取决于你的积分。** 当你的积分达到下一个最低要求，你的击杀一被计入，军衔就会上升，其他任何飞行员都不能让它下降。
- **最高的六个军衔会随你企业的其他飞行员而变动。** 比你先达到最低要求的飞行员会占走一个名额；当你所在军衔的名额已满，你就落到对你开放的下一个军衔。当有飞行员离开榜单或企业，就会空出一个名额，排在他后面的飞行员可以升上去。
- 积分与你相同或比你少的飞行员，绝不会从你手里夺走名额。
- 只有当你的军衔**上升**时才会通知你，也只有那时才通知（[晋升](#promotions)）。下降从不通知：你的符号只是变了。

## 如何获得 PvE 积分 {#how-you-earn-pve-points}

你的 PvE 积分由三部分算出：

**等级 × 100 + 经验 ÷ 1,000（向下取整）+ 你消灭的每个外星人的积分**

越难对付的外星人越值钱：一次击杀按摧毁该外星人所需的伤害给积分。虫群的飞船和战队守卫按同一条规则计算，所以 Pirate Scout 和 Bulwark 一样值钱。每次击杀都会以外星人自己的名字计入你的击杀统计。

| 外星人或飞船 | 每次击杀的 PvE 积分 |
| :--- | ---: |
| Seeker | 1 |
| Phantasm | 2 |
| Bulwark | 4 |
| Goombah | 7 |
| Crystalys | 16 |
| Boss Seeker | 5 |
| Seeker Slave | 1 |
| Pirate Boss | 15 |
| Pirate Scout | 4 |
| Dormant Force | 25 |
| Dormant Pulse | 11 |
| Brood Warden I, II, III | 14, 18, 35 |
| Siege Warden I, II, III | 13, 17, 32 |
| Wrath Warden I, II, III | 14, 18, 34 |
| Brood Drone I, II, III | 1, 1, 2 |
| Siege Escort I, II, III | 2, 3, 6 |
| Wrath Guard I, II, III | 2, 3, 6 |

前五行是普通外星人，接下来六行是三个虫群的飞船。最后是战队守卫（战队守卫战的头领）和它们的随从 Brood Drone、Siege Escort 和 Wrath Guard：I、II、III 是守卫的强度，积分按这个顺序列出。

例如，一名 4 级飞行员有 12,500 经验，击毁过 300 只 Seeker、80 架 Phantasm 和 10 艘 Bulwark，就有 400 + 12 + 300 + 160 + 40 = **912** 积分。这让他成为中士：最低要求是 800，下一个军衔高级中士要求 1,000。到高级上校为止，只有积分算数。

**排行榜**页面（社区 › 排行榜）会显示你自己的积分是怎么构成的，其中的**名人堂**则列出最出色的飞行员。那里 PvE 积分旁边的 **(i)** 列出五种外星人、在每个[虫群](/wiki/05-Swarms/Swarms.md)里击杀一艘飞船能得多少积分（从最小的飞船到首领），以及[战队守卫](/wiki/03-Mechanics/Clans.md#clan-wardens)。

## 符号 {#the-symbols}

游戏把军衔画成一个小符号：代表阶层的**形状**，带有各自的颜色，以及代表级别的**一个、两个或三个标记**：初级一个，普通两个，高级三个。随着阶层升高，颜色从冷静朴素逐渐变为温暖明亮。

| 阶层 | 形状 | 颜色 |
| :--- | :--- | :--- |
| 飞行员 | 圆点 | 钢蓝色 |
| 中士 | 上下叠放的人字形 | 铜色 |
| 中尉 | 上下叠放的扁平横杠 | 银色 |
| 上尉 | 菱形 | 绿色 |
| 少校 | 朝上的三角形（三角旗） | 青色 |
| 上校 | 空心圆环 | 金色 |
| 将军 | 五角星 | 橙色 |
| 海军上将 | 上方开口的月桂花环，环绕一到三颗星 | 玫瑰色 |

## 王冠 {#the-crown}

**全服 PvE 积分最多**的飞行员会在自己军衔符号的上方戴一顶小小的金色**王冠**。“全服”指所有企业和三个世界，而不只是你的企业：整个服务器只有一顶王冠，每家企业最强的飞行员仍然拥有他自己的军衔。如果榜首有几名飞行员积分完全相同，他们都会戴上。

只有榜单上的飞行员才能戴。离开 30 天的飞行员不能戴，不管他积分多高：王冠归榜单上最强的飞行员，等他再次飞行并重新领先，就会拿回去。王冠易主时不会通知任何人，看得见就行。它不是军衔，也不给任何东西：把指针放在戴王冠的符号上，悬停提示会写着“全服 PvE 最强飞行员”。

## 在哪里看到它们 {#where-you-see-them}

飞行时你只看到**符号**，看不到文字。它在飞行员名字前，王冠在它上方，出现在下列所有地方：

- 飞船上方的名字标签，以及目标窗口；
- 聊天中，写下那一行的飞行员名字之前；
- 你的小队列表中，以及小地图上小队队友的悬停提示里；
- 击杀播报中，每个被点名的飞行员之前（外星人前面没有）；
- 名人堂、排行窗口，以及飞行员的个人资料页（大图）；
- 企业页面：你自己的军衔、最强飞行员名单和所有军衔的表格。

**文字**（初级中士、上尉 …）在企业页面和悬停提示里：把指针停在符号上。符号表示这名飞行员在**他自己企业**的飞行员中处于什么位置：另一家企业的少校，是他们企业里的少校，而不是你们企业里的。[企业飞行员](/wiki/03-Mechanics/Company-Pilots.md)是游戏自己的编队，没有军衔。

## 企业排名 {#the-company-ranking}

打开**经济 › 企业**。其中的**企业排名**部分从上到下显示：

- **你的军衔**：它的符号（如果王冠是你的，也带王冠）和名称、你的名次（“第 16 名，共 31 人”）以及一个显示你百分位的小标签（“前 52%”）。
- **一根进度条和它下面的一行字**，说明下一个军衔要什么。像“距 初级将军 还差 2,500 PvE 积分”这样的一行，说的是下一个军衔的最低要求还差多少 PvE 积分。当下一个军衔没有空名额时，这一行会点出占着最后一个名额的飞行员：“超过 Sable 晋升 初级将军 还差 3,100 PvE 积分”。追平他的积分就够了，因为积分相同军衔就相同。高级海军上将显示“已是最高军衔。”
- 你企业的**最强飞行员**及其积分。
- **所有军衔**，默认折叠，点开才显示：24 个军衔，最高的在最前，列有每家企业的**名额**（短横线：不限）、现在拥有该军衔的**人数**（带一根与人数最多的军衔等宽的条），以及**最低积分**。你自己的军衔会被标出，某一行的悬停提示写着：“高级海军上将：每个企业 1 个名额，50,000 PvE 积分起。” 表格下方的一行说明谁在榜单上。
- **名单**：你的企业在三个世界中最强的 **50 名飞行员**，带名次、符号、名字和 PvE 积分。你自己的那一行会被标出。

- 还没有 PvE 积分的飞行员既不在榜单上也不在列表里：消灭一个外星人就能上榜。离开 30 天的飞行员也不在，直到他再次出击或打开这个页面。
- 只显示名字和公开的数字。

## 晋升 {#promotions}

- 当你达到新的最高军衔，会收到一条通知（“晋升：高级中士”）和一声简短轻柔的提示音。“最高”指你自上次出击以来被告知的最高军衔：如果你降了一个级别又夺回来，不会有第二条消息。你离线期间达到的军衔，会在你下次登录时通知一次。下降从不通知。
- 从**初级少校**起，晋升还会显示在你所在世界中飞行的本企业飞行员的聊天**系统**标签页里：“Nova 晋升为 初级少校。”只有当你自己的 PvE 积分让你升上去时，企业才会得知；如果你是因为别的飞行员离开榜单而上升，你会收到自己的通知，其他人都不会被告知。

## 军衔与重置 {#ranks-and-the-wipe}

重置不会改变任何人的积分。它会保留你的等级、经验和击杀统计（[重置时间线](/wiki/03-Mechanics/Wipe-Timeline.md#cross-season-progression-permanent-buffs-)），而你的 PvE 积分就是由它们算出来的，所以重置后你企业的榜单顺序不变，军衔和王冠也不变。不过你的军衔不再是终身的：最高的六个军衔会随你企业的其他飞行员而变动，离开 30 天的飞行员会退出榜单，直到再次飞行。

## 需要多久 {#how-long-it-takes}

这些是根据飞行员狩猎速度的模型得出的**估算**，不是实测。一名每天狩猎约两小时、每个赛季 58 小时的飞行员，一个赛季后大约有 21,200 PvE 积分：上校。按狩猎小时算，飞行员的最低要求在第一个小时内就能达到，中士需要 4 小时，上尉需要 18 小时，少校需要 38 小时，上校需要 55 小时，初级将军需要 67 小时，将军需要 73 小时，高级将军需要 78 小时，初级海军上将需要 101 小时，海军上将需要 113 小时，高级海军上将需要 124 小时。

所以一名典型的活跃飞行员会在第二个赛季达到有名额的军衔。能否拿到名额取决于你企业里其他同样在狩猎的飞行员：只有当达到某个军衔最低要求的飞行员比它的名额多时，名额才有意义。在那之前，军衔仅由你的积分决定。
