# 军衔 {#ranks}

每位飞行员都有一个**军衔**，从初级飞行员到高级海军上将。这是一架军事阶梯：8 个阶层，每层 3 个级别，共 24 个军衔。你的军衔就是你在**本企业飞行员中的名次**，按 **PvE 积分**来排：它来自你的等级、经验，以及你消灭的外星人。飞行时，游戏只在飞行员的名字前显示一个小**符号**，让你一眼分清一家企业的顶尖飞行员和新手。文字写法则在企业页面和符号的悬停提示里。

**一分钟了解**

- 你的企业只有一份飞行员名单，PvE 积分最多的飞行员排在最前。你的军衔由你在这份名单里的名次决定。
- 只有企业里最强的飞行员是**高级海军上将**。其余所有人从上往下分到另外 23 个军衔里：上面人少，下面人多。
- 每个军衔还要求一个**最低 PvE 积分**，这样小企业或新企业就不能白白发出最高的军衔。高级海军上将需要 20,000 积分。
- 你的军衔会变动。别的飞行员超过你时它会下降，你超过他们时它会上升。下降从不通知；新的最高军衔会通知。
- 名单上只有有 PvE 积分、且最近 30 天内飞行过的飞行员。其他人在再次飞行之前都是初级飞行员。
- 重置不会改变任何人的积分，所以名单不会从头开始。
- 名字前的符号就是军衔：形状代表阶层，一到三个标记代表级别。

## 军衔如何确定 {#the-company-ladder}

你所在企业的飞行员，**三个世界合在一起**，排成一列，PvE 积分最多的排在最前。积分相同时，等级高的在前，再按资历老的在前。这一列就是企业的**榜单**，你的军衔由两件事决定：

1. **你的名次。** 第 1 名的飞行员独自是**高级海军上将**。他后面的飞行员按榜单的比例分到另外 23 个军衔里，每个军衔的人数比上一个军衔多四分之一。所以大约五分之一的飞行员是初级飞行员，最强的十分之一是上尉或更高。
2. **你的积分。** 每个军衔都要求一个最低 PvE 积分（[见下表](#the-24-ranks)）。你的军衔是两者中较低的那个：名次给你的，和积分所能达到的。

**举例。** 一家企业的榜单上有 31 名飞行员。仅按名次，军衔如下；最后一列是该军衔要求的最低 PvE 积分。

| 名次 | 军衔 | 最低 PvE 积分 |
| :---: | :--- | ---: |
| 1 | 高级海军上将 | 20,000 |
| 2 | 高级少校 | 4,700 |
| 3 | 高级上尉 | 3,000 |
| 4 | 上尉 | 2,600 |
| 5 | 高级中尉 | 1,900 |
| 6–7 | 中尉 | 1,500 |
| 8 | 初级中尉 | 1,300 |
| 9–10 | 高级中士 | 1,000 |
| 11–13 | 中士 | 800 |
| 14–16 | 初级中士 | 610 |
| 17–20 | 高级飞行员 | 350 |
| 21–24 | 飞行员 | 150 |
| 25–31 | 初级飞行员 | 0 |

你排在 31 人中的第 16 名，有 1,800 PvE 积分。企业页面会显示“第 16 名，共 31 人”和一个小标签“前 52%”：你在企业的前 52% 之内。第 14 到 16 名是初级中士，所以这就是你的军衔，尽管单看积分你已够到中尉（1,500）。要成为中士，你必须升到第 13 名。第 13 名是 Sable，他有 2,100 PvE 积分。要超过他，你需要 2,101，也就是还差 301，企业页面会原样告诉你：“超过 Sable 晋升 中士 还差 301 PvE 积分”。

积分在最顶端同样重要。如果这家企业最强的飞行员只有 12,000 PvE 积分，那么不管他排第几，在达到 20,000 之前他都是高级将军。

> [!NOTE]
> 军衔按整名飞行员来划分，所以小企业在一些较高的军衔里没有人。上校要求企业榜单上至少有 46 名飞行员，将军要 118 名，高级将军 178 名，初级海军上将 301 名，海军上将 675 名。第 1 名是例外：每家企业都有，只要他达到 20,000 PvE 积分，就是高级海军上将。

## 谁在榜单上 {#who-is-on-the-ladder}

飞行员同时满足**以下三点**时，才在本企业的榜单上：

- 他在一家企业里；
- 他有 PvE 积分：第一次击杀就会让新飞行员上榜；
- 他最近 **30 天**内飞行过。

不在榜单上的飞行员，在所有显示军衔的地方都是**初级飞行员**，没有名次，也不在企业的列表里。这条规则是为了让试玩一次就离开的飞行员不会永远垫底，也让离开的飞行员不能一连几个月占着最高军衔。

> [!TIP]
> 你不在的时候什么也不会丢。你的积分会保留，你再次出击，或者只是打开企业页面，就会带着离开时的积分重新排进榜单。如果你原来是最强的飞行员，你会重新成为高级海军上将，原来占着这个军衔的飞行员则后退一名。

如果你换企业，积分随你而去，你会按这些积分在新企业的榜单上排到相应的名次。

## 你的军衔如何变动 {#your-rank-moves}

- 别的飞行员超过你时，它会**下降**。每超过你一个飞行员，你就少一个名次；如果那是你所在军衔的最后一个名次，你就降一个级别。
- 你超过别人时，它会**上升**，击杀一被计入就生效。
- 飞行员加入或离开榜单时它也可能变动，因为每个军衔都是企业的一个比例。不断壮大的企业从不会让保住名次的飞行员降级；飞行员离开时，处在军衔边缘的飞行员可能会降一个级别。
- 只有军衔**上升**时才会通知你（[晋升](#promotions)）。下降从不通知：你的符号只是变了。

## 如何获得 PvE 积分 {#how-you-earn-pve-points}

你的 PvE 积分由三部分算出：

**等级 × 100 + 经验 ÷ 1,000（向下取整）+ 你消灭的每个外星人的积分**

越难对付的外星人越值钱：一次击杀按摧毁该外星人所需的伤害给积分。虫群的飞船和战队守卫按同一条规则计算，所以 Pirate Scout 和 Bulwark 一样值钱。每次击杀都会以外星人自己的名字计入你的击杀统计。

| 外星人或飞船 | 每次击杀的 PvE 积分 |
| :--- | ---: |
| Seeker | 1 |
| Phantasm | 2 |
| Bulwark | 4 |
| Goombah | 7 |
| Crystalys | 16 |
| Boss Seeker | 5 |
| Seeker Slave | 1 |
| Pirate Boss | 15 |
| Pirate Scout | 4 |
| Dormant Force | 25 |
| Dormant Pulse | 11 |
| Brood Warden I, II, III | 14, 18, 35 |
| Siege Warden I, II, III | 13, 17, 32 |
| Wrath Warden I, II, III | 14, 18, 34 |
| Brood Drone I, II, III | 1, 1, 2 |
| Siege Escort I, II, III | 2, 3, 6 |
| Wrath Guard I, II, III | 2, 3, 6 |

前五行是普通外星人，接下来六行是三个虫群的飞船。最后是战队守卫（战队守卫战的头领）和它们的随从 Brood Drone、Siege Escort 和 Wrath Guard：I、II、III 是守卫的强度，积分按这个顺序列出。

例如，一位 4 级、经验 12,500、击杀过 300 只 Seeker、80 只 Phantasm 和 10 只 Bulwark 的飞行员，积分是 400 + 12 + 300 + 160 + 40 = **912**。这够得上中士的最低要求（800）；他是不是中士，取决于他在企业里的名次。

**排行榜**页面（社区 › 排行榜）会显示你自己的积分是怎么构成的，其中的**名人堂**则列出最出色的飞行员。那里 PvE 积分旁边的 **(i)** 列出五种外星人、在每个[虫群](/wiki/05-Swarms/Swarms.md)里击杀一艘飞船能得多少积分（从最小的飞船到首领），以及[战队守卫](/wiki/03-Mechanics/Clans.md#clan-wardens)。

## 符号 {#the-symbols}

游戏把军衔画成一个小符号：代表阶层的**形状**，带有各自的颜色，以及代表级别的**一个、两个或三个标记**：初级一个，普通两个，高级三个。随着阶层升高，颜色从冷静朴素逐渐变为温暖明亮。

| 阶层 | 形状 | 颜色 |
| :--- | :--- | :--- |
| 飞行员 | 圆点 | 钢蓝色 |
| 中士 | 上下叠放的人字形 | 铜色 |
| 中尉 | 上下叠放的扁平横杠 | 银色 |
| 上尉 | 菱形 | 绿色 |
| 少校 | 朝上的三角形（三角旗） | 青色 |
| 上校 | 空心圆环 | 金色 |
| 将军 | 五角星 | 橙色 |
| 海军上将 | 上方开口的月桂花环，环绕一到三颗星 | 玫瑰色 |

## 在哪里看到它们 {#where-you-see-them}

飞行时你只看到**符号**，从来看不到文字。它位于飞行员名字之前：

- 飞船上方的名字标签，以及目标窗口；
- 聊天中，写下那一行的飞行员名字之前；
- 你的小队列表中，以及小地图上小队队友的悬停提示里；
- 击杀播报中，每个被点名的飞行员之前（外星人前面没有）；
- 名人堂、排行窗口，以及飞行员的个人资料页（大图）。

**文字**（初级中士、上尉 …）在企业页面和悬停提示里：把指针停在符号上。符号表示这名飞行员在**他自己企业**的飞行员中处于什么位置：另一家企业的少校，是他们企业里的少校，而不是你们企业里的。[企业飞行员](/wiki/03-Mechanics/Company-Pilots.md)是游戏自己的编队，没有军衔。

## 企业排名 {#the-company-ranking}

打开**经济 › 企业**。其中的**企业排名**部分从上到下显示：

- **你的军衔**：它的符号和名称，你的名次（“第 16 名，共 31 人”），以及一个显示你百分位的小标签（“前 52%”）。
- **一个进度条和它下面的一行**，说明下一个军衔需要什么。像“超过 Sable 晋升 中士 还差 301 PvE 积分”这样的一行，指的是下一个军衔的最后一名飞行员：超过他，这个军衔就是你的。如果只是积分拖住了你，这一行会说明你还差多少 PvE 积分。高级海军上将看到的是“已是最高军衔。”
- **企业最强的飞行员**和他的积分。
- **所有军衔**：打开之前是折叠的。24 个军衔排成金字塔，每个军衔有一条宽度与其占企业比例成正比的条，以及三列：**占比**、现在有多少人（**人数**）和**最低积分**。你自己的军衔会被标出，鼠标停在某一行上会提示“本企业前 10.2% 的飞行员为 上尉 或更高。”表下面的一行说明谁在榜单上。
- **列表**：**三个世界合计的本企业前 50 名飞行员**，有名次、符号、名字和 PvE 积分。你自己的那一行会被标出。

- 还没有 PvE 积分的飞行员既不在榜单上也不在列表里：消灭一个外星人就能上榜。离开 30 天的飞行员也不在，直到他再次出击或打开这个页面。
- 只显示名字和公开的数字。

## 晋升 {#promotions}

- 当你达到新的最高军衔，会收到一条通知（“晋升：高级中士”）和一声简短轻柔的提示音。“最高”指你自上次出击以来被告知的最高军衔：如果你降了一个级别又夺回来，不会有第二条消息。你离线期间达到的军衔，会在你下次登录时通知一次。下降从不通知。
- 从**初级少校**起，晋升还会显示在你所在世界中飞行的本企业飞行员的聊天**系统**标签页里：“Nova 晋升为 初级少校。”只有当你自己的 PvE 积分让你升上去时，企业才会得知；如果你是因为别的飞行员离开榜单而上升，你会收到自己的通知，其他人都不会被告知。

## 军衔与重置 {#ranks-and-the-wipe}

重置不会改变任何人的积分。它保留你的等级、经验和击杀统计（[重置时间线](/wiki/03-Mechanics/Wipe-Timeline.md#cross-season-progression-permanent-buffs-)），而你的 PvE 积分由它们算出，所以重置之后企业榜单的顺序不变。不过你的军衔不再是终身的：它跟随你的名次，因此会随企业飞行员的变动而变动，离开 30 天的飞行员会退出榜单，直到再次飞行。

## 需要多久 {#how-long-it-takes}

这些是根据飞行员狩猎速度模型得出的**估算**，不是测量。最低积分并不是难点：每天狩猎大约两小时、一个赛季 58 小时的飞行员，一个赛季后大约有 21,200 PvE 积分，比高级海军上将要求的还多。以狩猎小时数计，飞行员（军衔）的最低积分在第一个小时内就能拿到，中士要 4 小时，上尉约 9 小时，少校 14 小时，上校 22 小时，将军 32 小时，海军上将 48 小时，高级海军上将 55 小时。

决定你军衔的是名次，而别的飞行员也在狩猎。在 31 名飞行员的企业里，不管其他人有多少积分，只有最强的四人能成为上尉或更高。最低积分防止年轻的企业把最高的军衔发出去；名次则让老企业的顶端保持很小。
