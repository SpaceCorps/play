# Deep Void

<!-- wiki-search: deep void; dv-1; the hollow reach; void gate; threshold; seed; unwakened; crossing; breach; last light; lantern; lanterns; snuffer; fear; monster; flare; flares; davidski; leviathan; lost expedition; darkness; running dark; void bloom; static storm; dark matter; 提灯; 恐惧; 怪物; 照明弹; 黑暗; 暗物质; 失落的远征队; 穿越; graveyard; maw; lattice; throat; drowned flagship; listener; revenant; void mite; shade; blackout; gravity sink; crystal; wall shadows; quartermaster; contract; whisper; dormant swarm; 水晶; 大停电; 重力陷阱; 墙壁阴影; 低语; 合约; 噪音 -->

**Deep Void** 是 Dormant Swamp 之外的黑暗。它的第一张地图 **`DV-1`“The Hollow Reach”** 是游戏中最大的地图，而且一片漆黑：你只能看到光照亮的东西。每个世界都要先击杀 Unwakened，再在 `DS-4` 建造一座 **Void Gate**，才能打开进入的路；之后由持有钥匙卡的飞行员开启大门，附近所有人一起穿越过去。在里面，光让你活下去：提灯和中央的 Last Light。你随身携带的照明弹能照亮前路、引开制导火箭，却挡不住任何东西。你在黑暗中待得越久，积累的**恐惧**就越多，而恐惧满格会招来一样无法被杀死的东西。

**一分钟速览**

- [Unwakened](/wiki/03-Mechanics/Dormant-Swamp.md) 现在可以被击杀了。每个世界**本赛季的第一次击杀**会在 `DS-4` 右上角打开该世界的 **Threshold**。
- 该世界的飞行员向 **Void Gate** 投入 **20 块 Dark Matter Plate** 和 **200,000 Thulium**；随后大门建造 **24 小时**，投入**加速用 Thulium** 会更快。
- 持有 **Dormant Keycard**（最后一个[信号](/wiki/03-Mechanics/Signals.md)的奖励）的飞行员花 **5,000 Thulium** 开启大门：**120 秒**后，环内的所有人一起穿越到 **Breach**。
- 在 `DV-1` 中你只能看到船前方的一个锥形。**真正的光**（点亮的提灯、Last Light、Breach）能挡住 Void 的外星人，并让你的恐惧下降。照明弹不是真正的光。
- 在 Deep Void 中死亡会把你送回基地。安全区以外处处都是 PvP。

## Threshold 与 Void Gate {#the-threshold-and-the-void-gate}

- **Unwakened 会死了。** 它在死亡 24 小时后复活，沼泽的三座炮台（一座火箭炮塔和两座激光炮塔）现在也有了耐久：被摧毁的炮台在 Unwakened 复活前一直失效。参见 [Dormant Swamp](/wiki/03-Mechanics/Dormant-Swamp.md)。
- **Threshold。** 某个世界的 Unwakened 在一个赛季中第一次被击杀时，该世界 `DS-4` 的右上角大约 **27,400 / 4,800** 处会打开一个地方：**Seed**，一个极小的黑洞（只是布景：没有引力，也没有辐射），悬在 **Void Gate** 的空框架中，底座上有二十个黑暗的插槽。Slumbering Void 和 Dormant Sentinel 在其周围 2,500 到 4,100 单位的环带上巡逻。它会一直保留到重置。`DS-4` 是 PvP 区域，Threshold 也是。
- **每个世界建造自己的大门。** Alpha、Beta 和 Gamma 各有自己的 Threshold、大门和资源池；三座大门都通往服务器唯一的 `DV-1`。某个世界的大门开始建造和开启时，全服都会收到通知。
- **面板。** 在框架 **800 单位**以内，它的面板会从你的货舱取走 **Dark Matter Plate**，从你的钱包取走 **Thulium**（以 1,000 为单位），该世界的任何飞行员都可以随时投入任意数量。你投入的东西会留在框架里，不会退还。隐形中的飞船不能使用面板。面板会列出贡献最多的人，以及其他世界大门的进度。

| 资源池 | 容量 | 作用 |
| :--- | ---: | :--- |
| Dark Matter Plates | 20 | 开始建造所需的一半 |
| Thulium | 200,000 | 另一半 |
| 加速用 Thulium | 最多 1,000,000 | 加快建造 |

### 建造 {#the-build}

当第 20 块板**和**第 200,000 个 Thulium 都投入后，框架会按服务器时钟建造 **24 小时**，分 **五个阶段**，每 4 小时 48 分钟一个：锚定、下拱、支柱、冠环和点火。之后大门在本赛季余下时间里保持**开启**。

**加速用 Thulium** 能让建造更快。从 Threshold 打开起到大门开启为止都可以投入，每座大门最多 **1,000,000** Thulium。速度每翻一倍，所需的花费都比上一次更多；建造期间投入的 Thulium 会加快剩下的工作。

| 加速用 Thulium | 从零建造所需时间 | 速度 |
| ---: | ---: | ---: |
| 0 | 24 小时 | ×1 |
| 100,000 | 11 小时 13 分钟 | ×2.1 |
| 200,000 | 6 小时 41 分钟 | ×3.6 |
| 400,000 | 2 小时 48 分钟 | ×8.6 |
| 600,000 | 1 小时 18 分钟 | ×18.5 |
| 800,000 | 39 分钟 | ×37 |
| 1,000,000 | 20 分钟 | ×72 |

**冲向框架的波次。** 框架建造期间，每完成 2 小时的建造工作，就会有一波 **9 只 Slumbering Void 和 3 只 Dormant Sentinel** 扑向它：一次建造共 11 波，与速度无关。这一波会飞到框架周围的圆环上，**向大门开火**；世界会听到：“框架正在遭受攻击。”只要其中还有任何一个活着并在射程内，建造就会**暂停**，框架会**损失工作量**，每波最多 **30 分钟**，且不会低于所在阶段的起点。击毁这一波即可阻止。加速 Thulium 让建造更快，但不会更安全：波次在工作的同一时刻到来。

### 穿越 {#the-crossing}

开启的大门是一个会带走附近所有人的装置，而不是每个飞行员各自跳过去的传送门。

- **启动。** 持有 **Dormant Keycard** 的飞行员在距离 Seed 800 单位以内启动大门，并支付 **5,000 Thulium**。
- **倒计时：120 秒。** 全服会得知是谁开启了大门，结束前 30 秒会再通知一次。Seed 周围 **1,500 单位**的环标出穿越范围。
- **波次。** 四波分别为 **12、15、24、27** 个外星人（共 78 个），在第 0、30、60、90 秒从 Threshold 边缘出现：先是 Slumbering Void 和 Lurker，从第二波起加入 Dormant Sentinel，最后一波还有 Inert Mass。它们猎杀环内和附近的飞行员，首先是启动者。对手也可能赶来：`DS-4` 是 PvP 区域。
- **穿越。** 倒计时到 0 时，环内所有存活的飞行员一起穿越到 `DV-1`，抵达 **Breach**。同行者不需要钥匙卡，也不用付钱；隐形的飞船也会一起穿越。携带任务物品的飞行员无法穿越。
- **休息。** 大门要休息 **3 分钟**后才能再次启动。
- **回程免费。** Last Light 和 Breach 的传送门会像普通传送门跳跃一样，把你一个人送回你自己世界的 Void Gate；Base CPU 在 Deep Void 中同样有效。
- **重置。** 重置时，每座 Void Gate 都会坍缩进它的 Seed，下个赛季重新建造。你的钥匙卡、已探索的地图、失落的远征队和成就都会保留。

## DV-1, The Hollow Reach

- **全服共用一张地图。** Alpha、Beta 和 Gamma 的飞行员一起在 `DV-1` 飞行；每个服务器（Home、US、Singapore）各有一张。你的世界聊天和战队仍属于你自己的世界。
- **大小。** 128,000 × 72,000 单位，是 `DS-4` 面积的 16 倍：以巡航速度从一端飞到另一端大约要六分钟。
- **强度与报酬。** 所有人共用一套数值，也就是 Gamma 的：外星人强度是 Alpha 的两倍，报酬是三倍。
- **安全区以外处处 PvP。** Last Light 的安全区、Breach 的营地和传送门的环是安全的；其他任何地方，无论来自哪个世界的飞行员都可以攻击你。
- **死亡。** 在 Deep Void 中死亡会把你送回基地；要回去就得再穿越一次。
- **墙壁。** 水晶山脊、残骸和破碎的巨型结构会挡住飞船、外星人和射击，也会挡住你的光（见[光与墙壁](#light-and-walls)）。你点击设定的航线会自动绕开它们。

| 区域 | 是什么 |
| :--- | :--- |
| Last Light | 中央的基地：灯火通明、有守卫、安全（见下文）。 |
| The Breach | 每次穿越的落脚点，位于西部，有 Davidski 的营地。 |
| The Hollows | 西北部由水晶山脊组成的密集迷宫；侧道里潜伏着 Lurker，Shade 在其间游荡。 |
| The Glow | 北部的辐射区：各种大小的 Void Bloom，以及成群的 Void Mite。 |
| The Silent Expanse | 南部开阔而漆黑的区域：Leviathan 的地盘，Dormant 虫群每天来访一次的地方。 |
| The Graveyard | 东北部失踪远征队的残骸区：Revenant、Shade，中央是 Drowned Flagship。 |
| The Maw | 东部的破碎环带，环绕着三个远远就能看到发光的小黑洞；Deep Mass 守着哨位。 |
| The Lattice | 西南部的水晶塔，由可以射断的淡色水晶墙相连；墙后潜伏着 Lurker 的巢穴。 |
| The Throat | 东南尽头被活水晶封印，直到你的失落远征队为你打开；Listener 栖身其中。 |

### 黑暗与视野 {#darkness-and-sight}

- **你的光**是船前方一直延伸到屏幕边缘的**锥形**，以及周围的一圈小**光晕**。任何光照亮的东西你都能看到：你自己的、你队伍的、其他飞行员的锥形光，以及提灯。Skylab 的[雷达模块](/wiki/03-Mechanics/Skylab.md#radar-module)达到 3 级时，会把你的锥形光从 80 度加宽到 110 度（在你到达地图时读取）。
- **会发光的东西**远远就能看到：Void Bloom、提灯、Last Light、Seed、Angler 的诱饵、Maw 的重力陷阱、Leviathan 的眼睛。没有光照到的东西不会被绘制：没有飞船，没有名字，也没有血条。
- **由服务器决定。** 没有光照到的东西根本不会发送到你的游戏里，所以黑暗在 PvP 中是公平的。
- **熄灯飞行。** 按 **0** 关掉你的光：只有当别的光照到你时，其他飞行员才能看见你，而你也只能看见发光的东西。开火会让你的光重新亮起 5 秒。关灯待在黑暗中时，恐惧上升速度变为 1.5 倍。
- **地图是一片迷雾。** `DV-1` 由 2,304 个 2,000 单位的方格组成，在你的光找到它们之前都是黑的；找到的方格永远属于你。星系地图会显示你的探索进度（**已探索 37 %**）。

### 光与墙壁 {#light-and-walls}

- **墙壁会挡住你的光。** 你的锥形光和光晕穿不过水晶、残骸或岩石。墙后的外星人，或关灯飞行的飞船，对你来说没有被照亮：不会被绘制，没有名字和血条，你也无法锁定它。正是这一点让 Hollows 成为真正的迷宫。距你的飞船 150 单位以内，什么都不会被遮住。
- **会发光的东西永远不会被挡住。** 开着灯的飞船自己会发光（你的光会暴露你），提灯、Last Light 和 Breach 会越过墙壁发光：无论中间隔着什么，Void 都被挡在外面。照明弹、Void Bloom 和 Angler 的诱饵也会越过墙壁发光，但只是照出站在其中的东西。
- **由服务器决定。** 墙壁对你隐藏的东西根本不会发送到你的游戏，所以被改动的客户端没有任何可泄露的内容。
- **电脑会绘制阴影，手机不会。** **墙壁阴影**（设置，图形）在电脑上默认开启，只改变画面。手机和浏览器不绘制阴影；服务器对它们隐藏的内容是一样的。
- **消失的墙壁什么也挡不住。** 水晶被射断时（见下文），你的光、你的射击和你的航线会立刻穿过缺口。

### 可击碎的水晶 {#breakable-crystal}

Lattice 的淡色水晶墙可以射断；其他墙壁都不会断。

- **只有激光。** 在 1,400 单位以内点击水晶即可将其设为目标，然后像对飞船一样开火（双击、目标窗口的开火按钮或攻击键）。目标窗口会显示**水晶**及其命中点数，激光够不到时会显示**距离太远**或**有东西挡住了**。火箭、爆炸和 Siphon Battery 对它毫无作用。
- **所有人的伤害会叠加。** 一名飞行员单独需要一分钟或更久，五人小队约需 15 秒。受损的墙壁永远不会自行修复；被击碎的墙壁会在 **30 分钟**后完整长回，并把站在其中的东西挤出去。
- **它没有报酬，而且对所有人都是一扇门。** 整张地图都会得知某面墙碎了（不会说是谁），对手可以和你一样走这个缺口，墙后的 Lurker 巢穴也会敞开。

### 危险 {#hazards}

- **Void Bloom**：4,000 到 7,500 单位大小的辐射区，Glow 里比其他任何地方都多，在边缘每秒烧掉你舰船最大船体的 1 %，在中心烧掉 4 %，直接从船体扣除（护盾不会替你挡下它），隐形与否都一样。[Radiation tech](/wiki/03-Mechanics/Pilot-Skills.md) 能降低剂量。它们会发光，所以远远就能看到。会让你穿过辐射区的点击会被规划为绕行，就像黑洞会弯折你的航线一样；终点在其内部的点击则照常飞行。会有一个显示剩余时间的仪表，越过边缘之前会响起警告，里面还有盖革计数器的咔嗒声。
- **Static Storm**：一场 3,000 单位大小的风暴，会在外围区域飘荡 10 分钟。在里面你每秒损失舰船最大船体的 1 %，直接从船体扣除，光照距离减半。风暴出现前 30 秒会向全图发出警告。
- **重力陷阱**：Maw 里的三个小黑洞，每个都是 `DS-4` 的[黑洞](/wiki/03-Mechanics/Black-Hole.md)缩小一半后的样子。陷阱从 1,500 单位处开始吸引，从 2,000 起用辐射灼烧（Radiation tech 能降低剂量），并在 150 处把飞船和外星人一视同仁地吞掉。它从 2,400 单位外就开始发光，所以你在被杀之前就能看到；仪表、警告和盖革计数器的运作与黑洞相同。会让你穿过陷阱的点击会被弯折绕行；终点在其内部的点击则照常飞行。外星人自己会避开这个圈，但被推进去的会被引力抓住。
- **大停电**：每 20 到 30 分钟，整张地图会变暗。提前 5 秒会响起心跳声；然后在 **20 秒**内，每一种光的照射范围只有 40 %：你的锥形光和光晕、提灯和照明弹。Last Light 的泛光和 Breach 的光永远不会缩小，所以朝它们跑。恐惧只会在剩下的光之内下降。这时死者会起身：Revenant 的移动速度快一半，而黑暗每把一名飞行员留在真正的光之外，就会多唤起两个（同时最多 24 个；黑暗降临 80 秒后消失）。

## 光与暗 {#light-against-dark}

**真正的光**是能让你活下去的光：点亮的**提灯**（2,500 单位）、**Last Light**（5,000）和 **Breach**（1,500）。在它里面：

- **Void 的外星人都不会进入**，它们的激光会在光的边缘停下。正在追你的外星人会放弃追击，退回黑暗中。
- **除非你从光中向它开火。** 你站在真正的光中命中的外星人，会在你最后一次命中后的一小段时间里把你当作目标：它会进入那片光并攻击你，Revenant 在其中也不会定住。从黑暗中打出的命中不会改变任何事，站在你身旁、没有开火的飞行员则不会被理会。**Last Light 和 Breach 的光永远不会退让**：从那里开火不会激怒任何东西。Deep Mass、Dormant Swarm 的舰船和首领不会被激怒。
- **你的恐惧会下降**（见下文），而且只在这里下降。
- **其他飞行员仍然可以攻击你。** 光挡住的是 Void，不是你的对手，而且它还会把你暴露给他们。

飞船的锥形光、照明弹、Void Bloom 和 Angler 的诱饵都不是真正的光。

### 提灯 {#lanterns}

失落的远征队在 `DV-1` 各处立起了 **78 盏提灯**；大多数早已熄灭。

- 在 400 单位以内用货舱里的 **1 份暗物质**就能**点亮一盏**：**10 分钟**的光。任何人都可以继续添加燃料，灯箱最多装 **1 小时**。它按服务器时钟燃烧。
- **闪烁。** 在最后一分钟，提灯会闪烁，附近的飞行员会收到通知。
- **它会被打碎。** 一盏提灯有 300,000 点耐久。Snuffer 会吃掉它，**飞行员也可以把它打灭**（没有任何报酬，而且全图都会知道是谁干的）。被打碎的提灯会立刻熄灭并失去燃料，3 分钟后才能重新点亮。
- **共享。** 提灯属于所有人，属于三个世界。你的小地图和完整地图会显示你找到的每一盏提灯：点亮、闪烁、熄灭或破碎。
- **第一道光。** 你一生中第一次点亮每盏提灯时都能获得 **1,000 XP**，并计入**点灯人**[成就](/wiki/03-Mechanics/Achievements.md)。

### Snuffer {#snuffers}

苍白、像飞蛾一样而且很弱的 **Snuffer** 完全无视飞行员：它们从不开火。它们会成群地从黑暗中涌向每一盏点亮的提灯，是唯一会进入真正的光的外星人；每只到达提灯的 Snuffer 都会啃食灯身、烧掉燃料。没人看守的提灯几分钟就会被吃光。把它们打下来；它们有时会掉落暗物质。

### 恐惧与怪物 {#fear-and-the-monster}

**恐惧**是一条 0 到 100 % 的条，显示在你的船体和护盾旁边，只在 Deep Void 的地图上出现。

| 你的行为 | 恐惧 |
| :--- | :--- |
| 身处黑暗 | 每秒 +0.8（从空到满约 2 分钟） |
| 熄灯飞行（关灯） | 黑暗带来的增速 × 1.5 |
| 1,000 单位内的队友 | 每名队友让黑暗带来的增速 −20 %，最多 −40 % |
| 飞行：越快越多 | 每秒 350 单位以内不增加，1,000 时每秒 +1，更快则沿同一条直线继续增加（1,650 时 +2）；Afterburner 只是更快的飞船 |
| 一次激光齐射 | +0.15 |
| 一枚火箭 | +4；特殊火箭 +8；N.U.K.E. 或 N.I.K.E. +15 |
| **身处真正的光中** | **每秒 −10**，且不会增加 |

四项[飞行员技能](/wiki/03-Mechanics/Pilot-Skills.md)各削减一种来源，在 100 级时最多削减 20 %：**Grit** 削减黑暗带来的恐惧，**Thruster theory** 削减高速飞行带来的，**Laser tech** 削减齐射带来的，**Rocket tech** 削减火箭带来的。

| 恐惧 | 会发生什么 |
| ---: | :--- |
| 50 % | 外星人会在 1.5 倍远的距离发现你。 低语开始出现在屏幕边缘。 |
| 75 % | 8,000 单位内的强大外星人会前来猎杀你。 黑暗的影子在你的光的边缘爬行。 |
| 100 % | **怪物来了。** |

**低语和影子**只会绘制在你自己的屏幕上，且在真正的光之外：每隔 45 到 90 秒在飞船后方出现一行短句，以及光晕边缘的几条虫子。它们只是氛围：无法被射击，也不会伤害你（真正的生物也潜伏在光的边缘）。**黑暗中的低语与暗影**（设置，界面）可以把它们关掉。

**怪物**是一群触手与蠕虫，会从黑暗中冲向恐惧已满的那一名飞行员。它的速度为 **750**，比任何飞船都快，能穿过墙壁，而且**无法被杀死**。一旦追上你，它会**立刻吞噬你的飞船**；护盾和隐形都无济于事。它从不进入光中：在你的恐惧开始下降的那一刻（你到达了真正的光），它就会掉头逃走。恐惧会在死亡、穿越和登录时归零。

### 照明弹 {#flares}

**照明弹**（商店的特殊火箭，Davidski 和 Quartermaster 也有卖）会朝你的光标方向射出，最远 1,000 单位，并**悬停在那里燃烧 10 秒**。燃烧期间，在它 800 单位内已锁定目标的制导火箭都会转向它，并无害地爆开，任何地图都是如此。在 Deep Void 中，它的 **700 单位光照只是用来看的光，不是真正的光**：它只照出站在其中的东西，**什么也挡不住**。Void 的外星人和首领在燃烧的照明弹下照样攻击你，就像它不存在一样；Void Mite 不会被它吸引，你的恐惧不会在其中下降，怪物也不会因它而掉头。照明弹是一盏亮 10 秒的灯，也是制导火箭的诱饵，不是避难所。

## Last Light

那支再也没有回来的远征队的前哨站，位于 `DV-1` 中央。它的防御设施仍在运转。

| 环 | 半径 | 作用 |
| :--- | ---: | :--- |
| 泛光灯 | 5,000 | 真正的光，亮如白昼。 |
| 防御 | 4,500 | 四座激光炮塔和一座火箭炮台向外星人开火，从不攻击飞行员。 |
| 安全区 | 3,000 | 任何东西都伤不了你；没有 PvP。 |
| Mission Control、Xenolab 与 Quartermaster | 1,600 | **Void Control** 发布失落的远征队任务和每日合约；**Xenolab** 研究[旅行者指南](/wiki/03-Mechanics/Travelers-Guide.md)；**Quartermaster** 出售激光弹药、火箭和 Repair Drone。 |
| 治疗环 | 1,200 | 在安全区保护你时，每秒恢复你总 HP 的 2 %。 |

炮塔造成的伤害不会给任何人报酬：飞行员只按自己造成的那一份领取报酬。位于中央的 Last Light 传送门会免费把你送回你自己世界的 Void Gate。这里没有机库：你无法降落。 **Quartermaster** 向飞行中的飞行员出售，价格是商店对你的价格。它也出售 **Flares**：每个 25,000 Credits（Davidski 的是 30,000），你最多能带 20 个。

## Davidski 的营地 {#davidskis-camp}

每次穿越都会抵达 **Breach**，[Davidski](/wiki/03-Mechanics/Davidski.md) 把他那艘金色的 Ironclad 停在了 Breach 的光里。和往常一样，他又是第一个到的。

- **营地是安全的**：营地 1,500 单位内没有 PvP，它的光是真正的光。
- **他无法被杀死。** 朝他开火，他会回敬两到三发每发 300,000 的射击，不管是不是安全区。
- 在 1,500 单位以内**和他交谈**：你第一次来时，他的窗口会自动打开。他会讲解黑暗，发布失落的远征队的前两步，并在你要求时重播 *Calloway* 最后一次飞行的录像。
- **他的商店**：**Flares** 每个 30,000 Credits，**Organic Scanner I** 250,000 Credits。研究之后（CPUs），组装厂也能制造这台扫描仪。

## 外星人 {#the-aliens}

Deep Void 的每一种外星人在黑暗中对独行的飞行员都是威胁，而在真正的光中，它们都碰不到你（除非你从光中向它开火，见[光与暗](#light-against-dark)）。它们大多会掉落**暗物质**，这是这张地图最常见的战利品：没在提灯里烧掉的都能带回家。它们的数值在你的[旅行者指南](/wiki/03-Mechanics/Travelers-Guide.md)里：本百科只显示你已习得或研究过的数值。

- 来自 Dormant Swamp 的 **Slumbering Void** 在基地外到处游荡。**Deep Mass** 守在自己的岗位上：它们是 Dormant Swamp 的 Inert Mass，护盾厚得多，自成一个种类。
- **Lurker** 不带任何光，潜伏在侧道和 Lattice 的巢穴中。飞船一靠近它就会醒来，猛扑上来狠咬一口，然后继续战斗。
- **Angler** 挂着一盏远看像点亮的提灯的光。那不是提灯：一靠近光就会熄灭，Lurker 会从黑暗中涌出。
- **Revenant** 是失踪远征队的残骸，只在黑暗中移动。**真正的光**、任何飞行员的锥形光和任何飞行员的光晕都能让它定住，**但它所追猎的那名飞行员的光晕除外**：你自己的光晕定不住它，所以独自一人时要把锥形光一直照在它身上。Void Bloom 的辉光和 Angler 的诱饵永远定不住它。在黑暗中它会迅速逼近，**同时吸走你的护盾和船体**：护盾保护不了船体，而且 **Grit 和 Diminisher 也无法减少这种吸取**。被定住的 Revenant 什么也吸不到。 它们遍布 Graveyard，而大停电会唤起更多。把一个留在光里，然后消灭它。
- **Void Mite** 以十到三十只为一群飞行，主要在 Glow，被光吸引：它们可以猎杀的最亮的飞行员（照明弹不会把它们引向任何地方，也拦不住它们）。关灯飞行会让它们丢失你（开火会让你的光重新亮起 5 秒），进入真正的光也一样，没有 Void 外星人会进入那里。每只碰到你飞船的 Mite 会吸走你的护盾，护盾耗尽后吸走你的船体；整群能摧毁一艘没有防护的飞船，被 Mite 吃掉的飞船会在没有击杀者、没有记功的情况下死亡。单只很弱：一次大爆炸或穿透火力就能清掉一群。
- **Shade** 看起来像飞行员：真实飞船的外观、小地图上的一个点，以及由噪声组成的名字（`%`、`#`、`@`、`&` 和 `?` 中的三到六个），并且像开着灯的飞船一样发光。飞行员的名字由字母、数字和下划线组成，绝不会是噪声：你就是这样分辨它们的。Shade 在你靠近或它猎杀你时会显出原形，一次命中会让所有人看到它 20 秒；它从不进入真正的光。发给它的邀请和私信，得到的回应就像没有这个飞行员一样。Shade 在 Graveyard 和 Hollows 出没。
- **Snuffer** 会吃掉提灯（见上文）。**怪物**会在恐惧满格时到来（见上文）。
- 新的种类有**六种掉落物**：Revenant Ash、Mite Swarm Core、Shade Mask、Flagship Log、Listener Shard 和 Void Coordinates。目前它们是收藏品：不能在拍卖行出售，也还没有配方。见[资源](/wiki/06-Items/Resources.md)。

### Leviathan {#the-leviathan}

一条长约 **10,000 单位**的分节巨虫在 **Silent Expanse** 中游荡。你只能看到被光照到的部分，以及沿着它身体排列的眼睛。

- **它的身体**会伤害它穿过的每一艘飞船，头部伤害最大，还会把你撞开。
- **它的眼睛会射击**：每节的眼睛会张开并发出紫光，一秒后向射程内最近、且不在真正的光中的飞行员开火；熄灯飞行也躲不过它。张开的眼睛承受全部伤害；闭合的体节只承受一半。头部承受更多伤害。
- **它会冲锋**：所有眼睛同时闭上，头部沿直线猛冲。
- **它会潜行**：沉入黑暗，再从飞行员中间冲出；冒出的位置会在 2 秒前以紫色涟漪标出。
- **每个部位都有自己的船体和护盾。** 头部、每一节和尾部会分别被击毁，一次命中只会伤到被打中的部位，而且什么都不会恢复。
- **它会断开。** 打掉一个部位，虫子就会在那里被切断，各段会各自继续飞行。很短的一段无法冲锋、潜行或缠绕。
- **它只是一个首领。** 只有每一段的每个部位都被摧毁它才会死亡，最后倒下的部位算作击杀。下面的 60 % 和 30 % 按整场战斗剩余的量来算。
- **它守在自己的领地内**，也就是 Silent Expanse。
- **低于 60 %** 时，它会缠绕一支队伍：打碎发光的体节就能打开包围圈。**低于 30 %** 时，它附近的提灯燃烧燃料的速度会变为五倍。
- 在它附近，你的恐惧每秒会多涨 1 点，所以一场长战也是在和怪物赛跑。
- 它会在死亡 {{guide:vitals.respawn@The Leviathan}} 后回来。它的宝箱只抽取一次，由击杀获得报酬的飞行员分享。

### Drowned Flagship {#the-drowned-flagship}

被 Static 夺走的远征队旗舰躺在 **Graveyard** 的中心：一艘巨大而缓慢、从不进入真正的光的飞船。它是分三个阶段的一个首领，阶段取两个值中较低的那个，即**它船体的剩余比例，或船体与护盾合计的剩余比例**，所以再强的穿透火力也无法跳过任何一个阶段。

- **从一开始就有舷侧齐射。** 飞船上视野内有飞船的那一侧会发射一轮炮弹，前一刻会有一道闪光。两侧都有飞行员时，两组炮都会开火。
- **从三分之二到三分之一：Lights Out。** 每 {{guide:behaviour.ability:lightsout.everySeconds@The Drowned Flagship}} 秒，{{guide:behaviour.ability:lightsout.reach@The Drowned Flagship}} 单位以内的每名飞行员会失去光 {{guide:behaviour.ability:lightsout.seconds@The Drowned Flagship}} 秒（开火不会让它回来），在这个范围内的提灯和照明弹也一样（提灯保留燃料并会回来）。看得到飞船的飞行员会提前几秒收到警告。Revenant 会起身去猎杀被它弄黑的飞行员。Last Light 和 Breach 永远不会熄灭。没有光的飞行员没有被照亮：只靠你自己的光看到你的对手既看不到你，也无法锁定你，而你只能看到会发光的东西。
- **低于三分之一：裂口渗漏。** 它被撕开的船体会放出 Void Mite，直到它死亡。Lights Out 结束。
- **它唤起和放出的东西不计任何东西。** 它的 Revenant 和 Mite 与其他的行为一样、造成的伤害也一样，但不付报酬、不掉落任何东西，也不计入任何任务、合约或排行榜。
- 它死后 {{guide:vitals.respawn@The Drowned Flagship}} 会回来，它的箱子归造成伤害最多的飞行员。参与击杀它是失落的远征队的第 8 步。

### Listener {#the-listener}

Static 的源头：**Throat** 里一只巨大的水晶耳朵，藏在活水晶之后。当失落的远征队第 9 步的探索任务完成时，封印会为**你**打开，步骤完成后则永久打开。它为每名飞行员单独打开：还没走到这一步的队友无法跟上。

- **它从不猎杀，也没有自己的激光。** 它在听。你在它听力范围内发射的每一轮激光和每一枚火箭（其范围远超你的激光射程）都会给你增加一层**噪音**；恐惧条下面的条会显示你的层数。
- **噪音满 {{guide:behaviour.ability:noise.stacks@The Listener}} 层时，它可能选中你。** 一次只选一名飞行员：先是一个简短的预兆，然后是一道沉重的光束。你到达真正的光、安全的地方或隐形，在你与它之间隔上一堵墙，飞出它的射程，或关灯飞行时，光束就会中断；已经关灯飞行的飞行员不会被选中。一次选择之后它要等几秒才选下一个，被选中的飞行员从零重新开始。
- **安静会清除它。** 不开火地关灯飞行 {{guide:behaviour.ability:quiet.clearDarkSeconds@The Listener}} 秒，会清除你的噪音。小队轮流制造噪音。
- 它的身体很宽：激光可以从它内部打到它，因为射程是算到它中心的。
- 它死后 {{guide:vitals.respawn@The Listener}} 会回来。它的箱子只掷一次，在击杀所报酬的飞行员之间分配；其中有一个 **Void Coordinates**。参与击杀它是失落的远征队的第 10 步。

### Dormant 虫群的来访 {#the-dormant-swarms-visit}

每天一次，[Dormant 虫群](/wiki/05-Swarms/Dormant-Swarm.md)（一个 Dormant Force 和它的两个 Dormant Pulse）会来到 **Silent Expanse**，停留 90 分钟；如果有人与它交战，则会一直停留到被摧毁。没有人会宣布，任何地图上也没有标记：你要在黑暗中找到它。它是 Dormant Swamp 的虫群：被击中之前保持被动，被击中后，被击中者附近的一切都会加入。它的飞船支付和掉落的东西与在 `DS-4` 相同，强度是 Deep Void 的。第一次来访在地图建成后一到六小时，下一次在上一次结束一天后。

## 失落的远征队 {#the-lost-expedition}

Deep Void 的任务链，一次一步，每一步一生只有一次（重置不会夺走它）。前两步 *录像* 和 *点亮一盏* 由 Davidski 在 Breach 发布；其余由 Last Light 的 **Void Control** 发布。Davidski 的步骤之后，每一步都会支付一块 Dark Matter Plate。各步骤及报酬见[任务](/wiki/03-Mechanics/Quests.md#lost-expedition-table)表格。

**Void 合约。** 领取了 *First Light* 之后，Void Control 每天还会张贴三份合约，所有飞行员都一样：一份简单、一份中等、一份困难，从十份中选出（猎杀一定数量的 Void、Lurker、Snuffer、Revenant、Mite、Shade 或 Angler，点亮提灯，在提灯的光里待十分钟，或参与击杀 Leviathan）。像任务一样接取、完成和领取；没完成的会在每天 00:00 UTC 换日时消失。没有连续奖励。每份支付一个步骤的四分之一，在 Deep Void 完成的工作按**你自己世界**的倍率支付（Alpha ×1，Beta ×2，Gamma ×3）：一天的三份在加成之前，在 Alpha 支付 1,192,500 Credits 和 8,925 Thulium，在 Beta 是两倍，在 Gamma 是三倍，另加 25 暗物质。只有困难合约会额外加一块 Dark Matter Plate。

## 小贴士 {#good-to-know}

- **带上燃料。** 给提灯用的暗物质，以及长途穿行前清空的恐惧条。照明弹只亮几秒，能引开制导火箭，但挡不住任何东西。
- **结伴飞行。** 附近的队友能减缓你在黑暗中的恐惧上涨，你们的锥形光也会照亮同一片区域。
- **火箭很吵。** 每一枚火箭都会带来大量恐惧；在黑暗中战斗，也是在和恐惧条战斗。
- **光会暴露你。** 在 PvP 中，点亮的提灯会把你暴露给每一个能看到它的对手。
- **谨慎地射击水晶。** 你打碎的墙壁对你的对手也是一扇门，而且 30 分钟后才会长回来。
