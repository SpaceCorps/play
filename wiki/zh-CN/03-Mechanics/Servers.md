# 服务器 {#servers}

<!-- wiki-search: servers; server; server list; regional server; regional servers; home server; region; helsinki; singapore; us east; north america; asia; europe; ping; latency; delay; lag; launch; dock; return to base; bring my ship home; unreachable; full; updating; maintenance; staff only; 服务器; 服务器列表; 区域服务器; 主服务器; 地区; 北美; 亚洲; 欧洲; 延迟; 出击; 对接; 返回基地; 接回我的飞船; 无法连接; 已满; 更新中; 维护中; 仅限工作人员 -->

SpaceCorps 运行在三台游戏服务器上：**Helsinki**（欧洲）、**Singapore**（亚洲）和 **US East**（北美）。Helsinki 是**主服务器**：你的账号、空间站、飞船、物品和奖励都在那里。Singapore 和 US East 是**区域服务器**：你可以从它们出击，离游戏更近、延迟更短，对接时这次飞行会被送回 Helsinki。每台服务器都有自己的星空和自己的飞行员；规则、外星人、虫群和赛季时钟在所有服务器上都相同。

## 概览 {#at-a-glance}

| | Helsinki（主服务器） | Singapore 和 US East（区域服务器） |
| :--- | :--- | :--- |
| 你的账号、空间站、飞船、物品和奖励 | 在这里 | 在 Helsinki |
| 飞行、战斗、采矿、拾取战利品、任务 | 可以 | 可以 |
| 你遇到的飞行员 | 从 Helsinki 飞行的人 | 从那台服务器飞行的人 |
| 机库、Skylab、装配站、拍卖行、商店、战队页面和星系之门 | 一如往常 | 属于空间站：窗口会这样告诉你，并提供**返回基地** |

## 从区域服务器出击的飞行流程 {#how-a-flight-goes}

1. **出击。**在列表（[见下](#choosing-a-server)）中选择服务器并点击出击。主服务器把你送到区域服务器，你的飞船在那里的状态就是它此刻在你空间站里的样子。
2. **飞行。**你像在其他地方一样战斗、采矿、拾取战利品。你赚到的东西暂时留在区域服务器上：信用点、Thulium、经验值、荣誉、你的统计数据，以及你的无人机、宠物和飞行员专长的经验。大约每 **30 秒**就会送回 Helsinki，所以即使出了问题，损失也很少。
3. **对接。**你对接时（**返回基地**，或对接到某座空间站），飞行结束，你赚到的其余部分被送回，你回到自己的空间站。你的排名点数、军衔和排行榜在 Helsinki 计算，所以它们在你对接时变化，而不是在飞行过程中。

如果游戏关闭或连接中断，区域服务器会等你一小会儿，然后自己结束这次飞行，并像对接那样把它送回。只有主服务器知道你拥有什么：区域服务器只汇报你做了什么，你的其他东西在那里不会有任何变化。

## 选择服务器 {#choosing-a-server}

**服务器**列表位于登录界面和出击页。每一行有服务器的名称和地区（欧洲、亚洲、北美）、它的**延迟**（与它建立连接所需的时间：越低越近）、有多少人在那里**飞行中**，以及它的**状态**。点击一行即可选择：选择会被记在这台电脑上，出击就从它起飞。如果你选的服务器在出击时没有开放，你会改从 Helsinki 起飞，游戏会告诉你。一台区域服务器同时容纳 60 名飞行员。

### 状态用语 {#status-words}

| 状态 | 含义 |
| :--- | :--- |
| 开放 | 你可以从那里出击 |
| 已满 | 所有位置都满了：稍后再试，或选择另一台服务器 |
| 更新中，正在更新 | 更新到来期间，服务器处于游戏的另一个版本：请稍等 |
| 请更新游戏 | 服务器运行的版本比你的游戏新：请更新游戏 |
| 已停止 | 服务器此刻没有响应 Helsinki：请稍后再试 |
| 维护中 | 此刻没有人能从那里出击：重置正在倒计时，或服务器因工作被关闭 |
| 仅限工作人员 | 尚未向玩家开放 |
| 无法连接 | 你的电脑无法连上它：见下文 |

## 当服务器无法连接时 {#unreachable}

**无法连接**表示你的电脑没能连上那台服务器，括号里的话（在这一行的提示里，以及出击失败时的消息里）说明了原因：找不到它的名称、它没有及时响应、它拒绝了连接，或安全连接失败。有些网络会屏蔽服务器的地址，一台服务器可能对一位飞行员可以连上而对另一位连不上。**这期间请从 Helsinki 出击**：不会损失任何东西，你的空间站就在那里。如果它一再发生，请告诉我们是哪台服务器、括号里的话，以及你在哪个国家游玩；这能告诉我们该修什么。

服务器还可能有一条**备用线路**，也就是同一台服务器的第二个地址。当你的电脑连不上服务器自己的地址，却能连上它的备用线路时，这一行仍然可选，延迟（Ping）显示的是备用线路的数值，提示里会写“通过备用线路连接。”，出击也走这条线路。你不需要自己选择，其他方面没有任何变化。

## 接回我的飞船 {#bring-my-ship-home}

如果你在从区域服务器飞行时关闭了游戏，当你回到空间站时，飞船可能仍在飞行中。此时空间站会显示**你的飞船仍在另一台服务器上飞行**，而**接回我的飞船**按钮会结束那次飞行并把飞船接回来，让空间站重新可用。

## 更新与重置 {#updates-and-the-wipe}

服务器会一起更新：更新之前，区域服务器会被要求把它们的飞行送回，当其中一台处于另一个版本时，它那一行会显示“更新中”。所有服务器都遵循主服务器的赛季时钟。在[重置](/wiki/03-Mechanics/Wipe-Timeline.md)前的最后五分钟，没有人能从区域服务器出击（维护中），半分钟之前区域服务器会把所有人送回，待它们的星空为新赛季重建完成后再重新开放。

## 你的数据 {#your-data}

当你从区域服务器飞行时，你的飞船、物品和钱包的一份副本会在飞行期间保存在那里，不含你的电子邮件地址和密码，并在这次飞行被送回后删除。
