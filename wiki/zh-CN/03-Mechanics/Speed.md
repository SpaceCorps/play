# 速度计算 {#speed-calculation}

速度决定你的舰船在太空地图上的移动快慢，让你能够追击目标、脱离战斗或穿越各个区域。

## 速度公式 {#the-speed-formula}

你的舰船的最终速度由服务器按以下公式计算：

\[\text{最终速度} = (\text{舰船基础速度} + \text{引擎总速度}) \times (1.0 + \text{速度加成总百分比})\]

### 1. 引擎的有效速度 {#1-effective-engine-speed}

每台已装备的引擎都会产生速度。如果引擎中嵌有推进器，引擎的速度会因此改变：

\[\text{引擎速度} = (\text{引擎基础速度} \times \text{推进器倍率}) + \text{推进器固定加成}\]

- **推进器倍率**：嵌入该引擎的所有推进器的速度倍率之积（例如 Thruster III 为 `1.1`，即 `+10%`）。
- **推进器固定加成**：推进器提供的所有固定速度加值之和（例如 Thruster III 为 `+15` 速度）。

### 2. 收益递减（边际效率） {#2-diminishing-returns-marginal-efficiency-}

为了防止玩家靠堆叠无限数量的引擎换取无限的速度，游戏采用了**收益递减（边际效率）曲线**。所有引擎按各自的速度贡献排序，并依次计算。自适应核心（混合发生器）和护盾核心也按同样的方式排序，每一类各自成组，因此同时装有引擎和自适应核心的舰船，两者各有自己的前四名：

| 引擎排名 | 效率倍率 |
| :---: | :--- |
| **第 1 至 4 台** | **100%**（1.0） |
| **第 5 台** | **85%**（0.85） |
| **第 6 台** | **70%**（0.70） |
| **第 7 台** | **55%**（0.55） |
| **第 8 台及以后** | **25%**（0.25） |

此外，引擎速度还要乘以其所在槽位的效率（核心槽位：100%，支援槽位：75%，辅助槽位：50%）。

### 3. 速度加成百分比与护盾惩罚 {#3-speed-bonus-percent-shield-penalties}

速度加成总百分比等于所有已装备引擎（及混合发生器）的速度加成之和，再减去已装备护盾带来的惩罚：

- **引擎速度加成**：引擎提供正的速度百分比（例如 Engine III 提供 `+5%`）。
- **护盾速度惩罚**：重型护盾会拖累你的舰船，带来负的速度百分比（例如 Heavy Shield Core 带来 `-5%` 速度）。
- **槽位折算**：这些百分比加成和惩罚同样会按物品所装槽位的效率折算。装在你无人机上的护盾，拖慢你的程度与装在核心槽位中的护盾相同。
- **不会低于零**：无论你携带多少护盾，你的速度都不会低于 0。
