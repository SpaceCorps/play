# 统计 {#statistics}

**统计**页面（**社区 › 统计**）是你的记录。它显示你在当前飞行的重置里做了什么、在所有重置合计里做了什么、在每个已结束的重置里做了什么，并在**日志**中显示你的飞行员身上发生的事的日记。各部分排在顶部的栏里：**概览**、**日志**、**排名**、**名人堂**和**星区情报**。栏右端的按钮会重新加载该部分。

## 本次重置、总计和往期重置 {#this-wipe-total-and-past-wipes}

概览、排名和星区情报有一个三选一的开关：

- **本次重置**是自当前[重置](/wiki/03-Mechanics/Wipe-Timeline.md)开始以来你做的事。页面默认打开它。
- **总计**是自你开始游戏以来在所有重置合计里做的事。
- **往期重置**是已结束重置的列表，最新的在前。选一个，页面就显示你在那次重置里做了什么。

开关旁边的一行说明哪次重置正在进行、第几天以及何时开始。每个方块还在第二行显示另一个数字（重置数字下面是**总计 61,200**，总计下面是**本次重置 +5,100**），所以没有什么藏在一次点击之后。你的选择会被记住。三个按钮放不下时（窗口很窄，或你的语言里的词很长），开关会变成带有同样三个选项的菜单。

游戏不会为重置另设一套计数器。每次重置开始时，它会把你的数字原样记下来；**本次重置**就是你现在的数字减去这些。你射击、飞行或击毁东西时不会多写任何东西，你的总计也从不清零，所以这两个数字总是对得上。

| | 本次重置 | 总计 |
| :--- | :--- | :--- |
| **等级** | 升了的等级（**+2**，下面是**当前 14 级**） | 你的等级 |
| **经验值** | 获得的经验值 | 你的经验值 |
| **荣誉** | 你赚到的荣誉（见下文） | 你现在的荣誉 |
| **PvE 和 PvP 排名积分** | 你现在拥有的积分 | 你现在拥有的积分；第二行显示你在往期重置中的最好成绩（如果有）（**最高 21,300（重置 2）**） |
| **飞行距离**、**射击次数** | 你在本次重置里飞行和射击的量 | 全部 |
| **任务** | 你在本次重置里完成的任务 | 你完成的全部 |
| **击杀**、**损失**、**弹药消耗** | 每行两个数字，**本次重置**和**总计** | |

两个积分方块始终显示你现在拥有的积分。排名积分在重置时如何重新开始，见[军衔](/wiki/03-Mechanics/Ranks.md)和[重置时间线](/wiki/03-Mechanics/Wipe-Timeline.md)。

## 荣誉 {#honor}

荣誉可能下降：误伤友军会扣掉一些，更换企业会使其减半，管理员也可以设定它。**本次重置**只计算你**赚到**的荣誉。被扣走的部分会在显示数字前加回来，所以损失不会掩盖你赚到的，而被人设成更低数值的荣誉也不算赚到。因误伤友军损失 150 荣誉之后，你赚到的仍然全部算数。**总计**里的数字就是你当前的荣誉。

## 往期重置 {#past-wipes}

从列表中选一次重置（**重置 2（2026-10-01 – 2026-10-24）**），方块和列表就显示你在其中做了什么。上方一行给出结果：你在企业里的名次、你的军衔，以及你的 PvE 和 PvP 积分。**打开本次重置的日志**会在那次重置上打开你的日志，**本次重置的星区情报**则显示它的星区表。在你的第一次重置结束之前，页面会这么说，并为结束时保存你的结果。

- **自某日起统计。** 按重置统计从游戏版本 0.4.26 开始。对于当时已在进行的重置，游戏无法知道你开始时的数字，所以从服务器更新的那天起统计（如果重置本身留下了记录，则据此统计），页面会显示自该日**起统计**。有时只有**任务**方块带有这个标记：游戏知道重置开始时的所有数字，却不知道你已完成多少任务，所以这些从那天起算，其余都是准确的。
- **测试重置。** 管理员在测试服务器上手动执行的重置会标上**（测试重置）**。
- **你的结果会被保存**，只要你还有账号。

## 星区情报 {#sector-intel}

星区情报按星区逐个列出你飞行的距离、你射击的次数、你击落的外星人，以及你在那里被击毁的次数。它与概览使用同一个开关。**总计**的星区表统计你在某个星区里做过的每一次击杀，所以比**本次重置**的**击杀**列表里的击杀更多；想比较时，请把两者设为同一个选项。星区内按外星人的细分不会为重置保存：往期重置把一个星区的击杀列为一个数字。

## 按重置查看名人堂 {#the-hall-of-fame-by-wipe}

名人堂（这里和排行榜页面）列出每个世界以及所有世界合计的每个排名（PvE 和 PvP）的前五十名飞行员。在排名和世界开关旁边，一个**重置**菜单选择列表：**当前**，或一次已结束的重置（**重置 2**、**重置 1** ……），显示它结束时的样子。保存了历史总榜 PvE 列表的服务器还会提供**历史总榜**。往期重置的列表永久保存。如果飞行员删除了账号，他的名次保留，该行显示**已删除的飞行员**；其他每一行都会打开该飞行员的个人资料。

## 你的个人资料 {#your-profile}

任何已登录的飞行员都能打开的飞行员个人资料，在击杀方块下面显示他**在本次重置中**击毁了多少外星人和飞行员，以及一条显示他在每次已结束重置中的结果的条带（**W2 #41 PvE · 上尉**：他在所有飞行员的 PvE 列表中的名次和他的军衔）。个人资料对往期重置只说这些。你的损失、射击次数、飞行距离、星区、每次重置的游戏时长和损失的荣誉是私密的：只有你自己能看到。

## 日志 {#the-logbook}

日志是你的飞行员的私人日记：一份按时间倒序排列、用你自己的语言写成的事件列表。**它不是聊天记录：聊天从不被记录。**

### 它记录什么 {#what-it-records}

每条记录属于六个分组之一，列表上方的筹码按分组筛选（可同时选多个；**全部**清除选择；每个筹码显示它包含多少条记录）：

- **战斗**：击落的外星人、你被击毁（被什么或被谁）、你击毁的飞行员、误伤友军、首领或守护者的首次击杀。
- **经济**：你在商店买了什么、订阅了什么、制造、锻造炉、增益、拍卖行（卖出、买入、竞得）、兑换码和邀请好友。
- **采矿**：你打碎的小行星和收集的碎块。
- **进度**：新等级、新军衔、完成的任务、建成的 Skylab 模块、孵化的 P.E.T.、购买的飞船或无人机编队。
- **奖励**：打开的容器、每日奖励、使用的特殊物品、成就、称号、已绑定的 Steam 账号、赛季奖品和客服的礼物。
- **系统**：你加入了游戏、日志开始了、一次重置何时开始和结束，以及你的战队里发生的事（加入、离开、新职务）。

击杀和采矿会被**折叠成每小时游戏时间一条记录**：**击落了 143 个外星人：Seeker ×90、Phantasm ×40、Bulwark ×13**。点击这条记录会展开那一小时的信用点、Thulium、经验值和荣誉（采矿则按岩石种类）。其余一切都是一件事一条记录。一行里出现的另一位飞行员（击毁你的那位）以编号保存，并以他现在的名字显示；如果他的账号已不存在，这一行显示**某位飞行员**。

### 记录保存多久 {#how-long-entries-are-kept}

- **常规记录**（击杀、采矿、购买、被击毁等）保存 **21 天**，最多保留最新的 **400** 条。
- **里程碑记录**（新等级、军衔、完成的任务、重置、奖品等）保存**一年（365 天）**，最多保留最新的 **500** 条。

你的日记从服务器开启日志的那天开始。之前的内容不会被补上，第一条记录会说明日志开始了。

### 谁能读 {#who-can-read-it}

只有你。你打开页面时，游戏服务器替你读取日记，其他飞行员无法索取。只有当某位飞行员求助时，客服才能读取他的日记，每一次这样的读取都会像管理员的其他操作一样被记录。你删除账号时，你的日记会随之删除。

### 阅读 {#reading-it}

- **重置**选择你要查看哪次重置的记录：当前的（页面默认打开它）、更早的，或**所有重置**。横穿列表的一条线标出重置从哪里开始、在哪里结束（**重置 3 开始了**、**重置 2 结束了 · 你在企业里排名第 41**），即使是你什么都没做的重置也会显示。
- 搜索框和**查找**会在记录的种类和详情中查找。
- **复制本页**把页面上的各行复制到剪贴板，每条记录一行，是可以粘贴到消息或表格里的文本（时间、分组、句子）。
- 列表每页显示十五条记录，下方是翻页按钮。在窄窗口里，每条记录会变成一张小卡片。

### 日志不可用时 {#when-the-logbook-is-not-available}

日志是游戏旁边一个独立的小型服务，游戏从不等待它。可能发生两件事，都不会让游戏停下来：

- **这个服务器没有开启日志。** 页面会这么说。这样的服务器上不会记录任何东西。
- **暂时无法连接日志。** 页面会让你一分钟后再试。你的记录不会丢失：游戏会保留这期间发生的事，并在服务恢复后发送。只有非常长时间的中断才可能损失最旧的常规记录（里程碑记录会优先保留）。

## 常见问题 {#questions}

**重置之后我的击杀去哪了？** 它们没有消失。页面默认打开**本次重置**，它在每次新重置里从零开始，而**总计**就在每个方块和每个列表的旁边。你的总计从不清零。

**为什么本次重置显示的荣誉比我的荣誉增加的还多？** 因为**总计**是你的余额，被扣走的荣誉（误伤友军、更换企业时的减半）把它减少了。**本次重置**统计你赚到的（见[荣誉](#honor)），所以它是更大的数字。

**为什么一个星区显示的击杀比我的击杀列表多？** 因为**总计**的星区表把所有重置加在一起，而击杀列表显示的是**本次重置**。请把两者设为同一个选项。

**为什么某次重置写着“自某日起统计”？** 见[往期重置](#past-wipes)：按重置统计从版本 0.4.26 开始。

**其他飞行员能读我的日志吗？** 不能。见[谁能读](#who-can-read-it)。

**为什么我的日志回溯不到三周以前？** 常规记录保存 21 天。一年内的里程碑记录都在：选择**所有重置**以及**进度**或**系统**筹码。

## 须知 {#good-to-know}

- **往期重置**的数字和某次重置的名人堂在该次重置结束时写入，之后不再改变。
- 版本 0.4.26 之前的服务器的统计页面没有开关，也没有往期重置；那里的日志是早期版本的简单表格。
- [军衔](/wiki/03-Mechanics/Ranks.md)说明排名积分和企业排名如何运作；[重置时间线](/wiki/03-Mechanics/Wipe-Timeline.md)说明一次重置会带走什么、保留什么。
