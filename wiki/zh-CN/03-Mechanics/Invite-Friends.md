# 邀请好友 {#invite-friends}

每名飞行员都有一个专属的**邀请码**。刚接触游戏的朋友使用一次这个邀请码，就能获得一份新手礼包；当这位朋友达到 5 级时，你可以领取 Thulium 奖励，更多朋友达到 5 级时还有更多奖励。这一切都在同一个页面：**社区 › 邀请好友**。

## 你的邀请码 {#your-code}

- 打开**社区 › 邀请好友**即可看到你的邀请码，格式类似 `BCDF-GHJK`。它在你第一次查看时生成，并永远属于你：它不会改变，其他人也看不到它。
- **复制邀请码**会把邀请码复制到你的剪贴板；**复制邀请消息**会复制一段简短的文字，可直接粘贴发给朋友：其中包含游戏名称、你的邀请码和输入位置（非 Steam 版本中，还包含获取游戏的地址）。Steam 版本的消息不含下载地址。
- 输入邀请码时大小写均可，连字符可有可无。

## 朋友能获得什么 {#what-a-friend-gets}

朋友在**社区 › 邀请好友**下输入你的邀请码（对于仍可使用邀请码的飞行员，该页面会显示一张卡片，标题是**有朋友给的邀请码吗？**），并立即一次性获得：

| 新手礼包 | |
| :--- | :--- |
| **信用点** | 100,000 |
| **Thulium** | 5,000 |
| **N.I.K.E.** | 1 |
| **Quantum Laser 2** | 1 |
| **Engine II** | 1 |
| **Advanced Plasma** | 1,000 |

礼包会放入朋友的机库。Advanced Plasma 是 x2 弹药。如果其中任何一部分无法发放，就整份都不发放，游戏会提示稍后再试。

## 谁可以使用邀请码 {#who-can-use-a-code}

邀请码仅限**新账号**使用，游戏也会确保这一点：

- **4 级及以下**。5 级及以上的飞行员无法使用邀请码。
- **每个账号一次**。已经使用过邀请码的账号不能再使用其他邀请码。
- **绝不能使用自己的邀请码。**
- **每个网络地址每天三次**。同一个网络地址（一个家庭、一所学校、移动运营商的共享地址）在任意 24 小时内最多只能使用 3 个邀请码。当某个网络的名额用完时，页面会提示；请明天再试，或换一个网络。
- **不要乱猜**。在十分钟内输入十个不存在的邀请码，游戏就会要求你等待。

无法使用邀请码的朋友会在输入框下方看到原因，措辞通俗易懂。

## 朋友达到 5 级时 {#when-a-friend-reaches-level-5}

当使用过你邀请码的朋友达到 **5 级**（160,000 经验值）时，**2,500 Thulium** 的奖励会在朋友列表中等你领取，朋友旁边有一个**领取**按钮。奖励绝不会自动发放：你可以随时领取，每位朋友一次，即使那时朋友的账号已经不在了。

每位朋友会显示三种状态之一，既有文字也有颜色：

- **已加入**：使用了你的邀请码。
- **已达到 5 级**：奖励等你领取。
- **已领取**：你已经领取了奖励。

侧边栏“社区”分组中的**邀请好友**条目，在有奖励等待领取时会带有一个小小的 **(!)**，飞行中的**返回基地**按钮也一样。

## 里程碑 {#milestones}

达到 5 级的朋友还会计入一个阶梯式的奖励。每个里程碑只发放一次，可按任意顺序，在你领取时发放：

| 达到 5 级的朋友数 | 奖励 |
| :---: | :--- |
| **3** | 5,000 Thulium |
| **5** | 10,000 Thulium |
| **10** | 25,000 Thulium |
| **25** | 75,000 Thulium |

里程碑会显示**未解锁**（并标明还差多少位朋友）、**可领取**（带有**领取**按钮）或**已领取**。只有达到 5 级的朋友才会计入，仅仅使用过邀请码的朋友不算，而且一旦朋友达到 5 级，就会永久计入。

## 须知 {#good-to-know}

- 赛季的[重置](/wiki/03-Mechanics/Wipe-Timeline.md)不会影响邀请码、朋友或你已领取的奖励。
- 奖励和里程碑由游戏服务器设定，可能会在更新中改变；页面始终显示当前生效的内容。
- 在邀请好友功能推出之前的游戏服务器没有这个页面：该栏目会对此予以说明。
- 你邀请的朋友可以像其他飞行员一样加入你的[战队](/wiki/03-Mechanics/Clans.md)或[小队](/wiki/03-Mechanics/Groups.md)。
