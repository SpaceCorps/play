# Server {#servers}

<!-- wiki-search: servers; server; server list; regional server; regional servers; home server; region; helsinki; singapore; us east; north america; asia; europe; ping; latency; delay; lag; launch; dock; return to base; bring my ship home; unreachable; full; updating; maintenance; staff only; server; serverliste; regionalserver; heimatserver; region; nordamerika; asien; europa; verzögerung; starten; andocken; zurück zur basis; mein schiff nach hause holen; nicht erreichbar; voll; update läuft; wartung; nur team -->

SpaceCorps läuft auf drei Spielservern: **Helsinki** (Europa), **Singapore** (Asien) und **US East** (Nordamerika). Helsinki ist der **Heimatserver**: Dein Konto, deine Station, dein Schiff, deine Items und deine Belohnungen liegen dort. Singapore und US East sind **Regionalserver**: Von dort aus kannst du fliegen, um näher am Spiel zu sein und eine kürzere Verzögerung zu haben, und der Flug wird beim Andocken nach Helsinki nach Hause geschickt. Jeder Server hat seinen eigenen Himmel und seine eigenen Piloten; die Regeln, die Aliens, die Schwärme und die Saisonuhr sind auf allen gleich.

## Auf einen Blick {#at-a-glance}

| | Helsinki (Heimatserver) | Singapore und US East (Regionalserver) |
| :--- | :--- | :--- |
| Dein Konto, deine Station, dein Schiff, deine Items und deine Belohnungen | hier | in Helsinki |
| Fliegen, Kämpfen, Abbauen, Looten, Missionen | ja | ja |
| Die Piloten, denen du begegnest | die von Helsinki aus fliegen | die von diesem Server aus fliegen |
| Hangar, Skylab, Montage, Auktion, Shop, Clan-Seite und Galaxietore | wie gewohnt | die der Station: das Fenster sagt es und bietet **Zurück zur Basis** an |

## So läuft ein Flug von einem Regionalserver {#how-a-flight-goes}

1. **Starten.** Wähle den Server in der Liste ([unten](#choosing-a-server)) und drücke Starten. Der Heimatserver schickt dich zum Regionalserver, und dein Schiff ist dort so, wie es in diesem Moment in deiner Station steht.
2. **Fliegen.** Du kämpfst, baust ab und lootest wie überall. Was du verdienst, bleibt vorerst auf dem Regionalserver: Credits, Thulium, Erfahrung, Ehre, deine Statistiken und die Erfahrung deiner Drohnen, Haustiere und Pilotenfertigkeiten. Etwa alle **30 Sekunden** wird es nach Helsinki nach Hause geschickt, damit wenig verloren geht, falls etwas schiefläuft.
3. **Andocken.** Wenn du andockst (**Zurück zur Basis** oder ein Andocken an einer Station), endet der Flug, der Rest deiner Einnahmen wird nach Hause geschickt, und du bist wieder in deiner Station. Deine Ranglistenpunkte, Ränge und Ranglisten werden in Helsinki berechnet, sie bewegen sich also beim Andocken, nicht während des Flugs.

Wenn das Spiel sich schließt oder die Verbindung abbricht, wartet der Regionalserver eine kurze Weile auf dich, beendet den Flug dann selbst und schickt ihn nach Hause, wie ein Andocken es täte. Der Heimatserver bleibt der einzige Ort, der weiß, was dir gehört: Der Regionalserver meldet, was du getan hast, und sonst ändert sich dort nichts von dir.

## Einen Server wählen {#choosing-a-server}

Die Liste **Server** steht auf dem Anmeldebildschirm und auf dem Startblatt. Jede Zeile hat Namen und Region des Servers (Europa, Asien, Nordamerika), seinen **Ping** (wie lange eine Verbindung dorthin dauert: je niedriger, desto näher), wie viele dort **im Flug** sind und seinen **Status**. Klicke auf eine Zeile, um sie zu wählen: Die Wahl wird auf diesem Computer gemerkt, und Starten fliegt von dort aus. Ist der gewählte Server beim Start nicht offen, fliegst du stattdessen von Helsinki aus, und das Spiel sagt es dir. Ein Regionalserver nimmt 60 Piloten gleichzeitig auf.

### Die Statuswörter {#status-words}

| Status | Was er bedeutet |
| :--- | :--- |
| Offen | du kannst dort starten |
| Voll | alle Plätze sind belegt: versuche es gleich noch einmal oder wähle einen anderen Server |
| Update läuft, Wird aktualisiert | der Server hat eine andere Spielversion, während ein Update unterwegs ist: warte etwas |
| Spiel aktualisieren | der Server läuft auf einer neueren Version als dein Spiel: aktualisiere das Spiel |
| Offline | der Server antwortet Helsinki gerade nicht: versuche es später wieder |
| Wartung | von dort kann gerade niemand starten: Ein Wipe läuft herunter, oder der Server ist für Arbeiten abgeschaltet |
| Nur Team | noch nicht für Spieler geöffnet |
| Nicht erreichbar | dein Computer kann ihn nicht erreichen: siehe unten |

## Wenn ein Server nicht erreichbar ist {#unreachable}

**Nicht erreichbar** heißt, dein Computer konnte sich nicht mit diesem Server verbinden, und die Worte in Klammern (im Tipp der Zeile und in der Meldung, wenn ein Start scheitert) sagen, wie: sein Name wurde nicht gefunden, er hat nicht rechtzeitig geantwortet, er hat die Verbindung abgelehnt oder die sichere Verbindung ist fehlgeschlagen. Manche Netzwerke sperren die Adresse eines Servers, und ein Server kann für einen Piloten erreichbar sein und für einen anderen nicht. **Fliege währenddessen von Helsinki aus**: Nichts geht verloren, und deine Station ist dort. Wenn es immer wieder passiert, sag uns, welcher Server, die Worte in Klammern und aus welchem Land du spielst; so erfahren wir, was zu beheben ist.

Ein Server kann außerdem eine **Ersatzroute** haben, eine zweite Adresse desselben Servers. Wenn dein Computer die eigene Adresse des Servers nicht erreicht, aber seine Ersatzroute, ist die Zeile offen, ihr Ping ist der der Ersatzroute, ihr Tipp sagt „Über die Ersatzroute erreicht.“ und der Start läuft auf diesem Weg. Du musst sie nicht auswählen, und sonst ändert sich nichts.

## Mein Schiff nach Hause holen {#bring-my-ship-home}

Wenn du das Spiel schließt, während du von einem Regionalserver aus fliegst, kann dein Schiff noch auf seinem Flug sein, wenn du in die Station zurückkehrst. Die Station sagt dann **Dein Schiff fliegt noch auf einem anderen Server**, und die Schaltfläche **Mein Schiff nach Hause holen** beendet diesen Flug und holt das Schiff nach Hause, damit die Station wieder funktioniert.

## Updates und der Wipe {#updates-and-the-wipe}

Die Server werden gemeinsam aktualisiert: Vor einem Update werden die Regionalserver gebeten, ihre Flüge nach Hause zu schicken, und solange einer auf einer anderen Version ist, steht in seiner Zeile Update läuft. Alle Server folgen der Saisonuhr des Heimatservers. In den letzten fünf Minuten vor einem [Wipe](/wiki/03-Mechanics/Wipe-Timeline.md) kann niemand von einem Regionalserver aus starten (Wartung), eine halbe Minute davor schicken die Regionalserver alle nach Hause, und sie öffnen wieder, sobald ihr Himmel für die neue Saison neu aufgebaut ist.

## Deine Daten {#your-data}

Während du von einem Regionalserver aus fliegst, wird dort für den Flug eine Kopie deines Schiffs, deiner Items und deiner Geldbörse gehalten, ohne deine E-Mail-Adresse und dein Passwort, und sie wird gelöscht, wenn der Flug nach Hause geschickt wurde.
