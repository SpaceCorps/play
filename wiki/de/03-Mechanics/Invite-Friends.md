# Freunde einladen {#invite-friends}

Jeder Pilot hat einen persönlichen **Einladungscode**. Ein Freund, der neu im Spiel ist, verwendet ihn einmal und bekommt ein Startpaket; erreicht dieser Freund Level 5, holst du eine Thulium-Belohnung ab, und mehr, je mehr deiner Freunde es schaffen. Alles steht auf einer Seite: **Community › Freunde einladen**.

## Dein Code {#your-code}

- Öffne **Community › Freunde einladen**, um deinen Code zu sehen, geschrieben wie `BCDF-GHJK`. Er wird beim ersten Hinsehen erzeugt und gehört dir für immer: Er ändert sich nie, und niemand sonst sieht ihn.
- **Code kopieren** legt den Code in deine Zwischenablage; **Einladungstext kopieren** legt einen kurzen Text hinein, bereit zum Einfügen für einen Freund: der Name des Spiels, dein Code und wo man ihn eingibt (und, außerhalb von Steam, wo man das Spiel bekommt). In der Steam-Version lässt die Nachricht die Download-Adresse weg.
- Du kannst einen Code in Groß- oder Kleinbuchstaben eingeben, mit oder ohne Bindestrich.

## Was ein Freund bekommt {#what-a-friend-gets}

Ein Freund gibt deinen Code unter **Community › Freunde einladen** ein (die Seite zeigt jedem Piloten, der noch einen verwenden kann, eine Karte **Einen Code von einem Freund?**) und bekommt sofort und auf einmal:

| Startpaket | |
| :--- | :--- |
| **Credits** | 100.000 |
| **Thulium** | 5.000 |
| **N.I.K.E.** | 1 |
| **Quantum Laser 2** | 1 |
| **Engine II** | 1 |
| **Advanced Plasma** | 1.000 |

Das Paket landet im Hangar des Freundes. Advanced Plasma ist die Munition x2. Kann ein Teil davon nicht vergeben werden, wird keines vergeben, und das Spiel bittet, es später noch einmal zu versuchen.

## Wer einen Code verwenden kann {#who-can-use-a-code}

Der Code ist für **neue Konten**, und das Spiel sorgt dafür, dass das so bleibt:

- **Level 4 oder niedriger.** Ein Pilot auf Level 5 oder höher kann keinen Code verwenden.
- **Einmal pro Konto.** Ein Konto, das einen Code verwendet hat, kann keinen weiteren verwenden.
- **Nie dein eigener Code.**
- **Drei pro Netzwerkadresse und Tag.** Von einer Netzwerkadresse (ein Haushalt, eine Schule, die gemeinsame Adresse eines Mobilfunkanbieters) können in jeweils 24 Stunden höchstens 3 Codes verwendet werden. Die Seite sagt es, wenn ein Netzwerk sein Kontingent verbraucht hat; versuche es morgen oder aus einem anderen Netzwerk erneut.
- **Kein Raten.** Zehn Codes, die niemand hat, innerhalb von zehn Minuten eingegeben, und das Spiel bittet dich zu warten.

Einem Freund, der keinen Code verwenden kann, wird unter dem Feld in einfachen Worten gesagt, warum.

## Wenn ein Freund Level 5 erreicht {#when-a-friend-reaches-level-5}

Erreicht ein Freund, der deinen Code verwendet hat, **Level 5** (160.000 Erfahrung), wartet eine Belohnung von **2.500 Thulium** in der Freundesliste auf dich, mit einer Schaltfläche **Abholen** neben dem Freund. Sie wird nie von selbst ausgezahlt: Du holst sie ab, einmal pro Freund, wann du willst, auch wenn das Konto des Freundes dann nicht mehr existiert.

Ein Freund zeigt einen von drei Zuständen, in Worten ebenso wie in Farbe:

- **Beigetreten**: hat deinen Code verwendet.
- **Level 5 erreicht**: Die Belohnung wartet auf dich.
- **Abgeholt**: Du hast sie abgeholt.

Der Eintrag **Freunde einladen** in der Gruppe Community der Seitenleiste trägt ein kleines **(!)**, solange etwas zum Abholen wartet, und **Zurück zur Basis** im Flug ebenso.

## Meilensteine {#milestones}

Freunde, die Level 5 erreichen, zählen auch für eine Meilensteinleiter. Jeder Meilenstein wird einmal ausgezahlt, in beliebiger Reihenfolge, wenn du ihn abholst:

| Freunde auf Level 5 | Belohnung |
| :---: | :--- |
| **3** | 5.000 Thulium |
| **5** | 10.000 Thulium |
| **10** | 25.000 Thulium |
| **25** | 75.000 Thulium |

Ein Meilenstein zeigt **Gesperrt** (mit der Zahl der noch fehlenden Freunde), **Bereit** (mit einer Schaltfläche **Abholen**) oder **Abgeholt**. Es zählen nur Freunde, die Level 5 erreicht haben, nicht die, die nur den Code verwendet haben, und ein Freund, der es erreicht hat, bleibt dauerhaft mitgezählt.

## Gut zu wissen {#good-to-know}

- Der [Wipe](/wiki/03-Mechanics/Wipe-Timeline.md) der Saison berührt weder Codes noch Freunde noch das, was du abgeholt hast.
- Die Belohnungen und die Meilensteine werden auf dem Spielserver festgelegt und können sich mit einem Update ändern; die Seite zeigt immer die geltenden.
- Ein Spielserver aus der Zeit vor Freunde einladen hat diese Seite nicht: Der Bereich weist darauf hin.
- Freunde, die du einlädst, können wie jeder andere Pilot deinem [Clan](/wiki/03-Mechanics/Clans.md) oder deiner [Gruppe](/wiki/03-Mechanics/Groups.md) beitreten.
