# Invite Friends

Every pilot has one personal **invite code**. A friend who is new to the game uses it once and gets a starter pack; when that friend reaches level 5, you collect a Thulium reward, and more as more of your friends get there. It is all on one page: **Community › Invite Friends**.

## Your Code

- Open **Community › Invite Friends** to see your code, written like `BCDF-GHJK`. It is made the first time you look and is yours for good: it never changes, and nobody else sees it.
- **Copy code** puts the code in your clipboard; **Copy invite message** puts a short text in it, ready to paste to a friend: the game's name, your code and where to enter it (and, outside Steam, where to get the game). In the Steam build the message leaves the download address out.
- You can type a code in upper or lower case, with or without the hyphen.

## What a Friend Gets

A friend enters your code under **Community › Invite Friends** (the page shows a **Have a code from a friend?** card to any pilot who can still use one) and gets, at once and in one go:

| Starter pack | |
| :--- | :--- |
| **Credits** | 100,000 |
| **Thulium** | 5,000 |
| **N.I.K.E.** | 1 |
| **Quantum Laser II** | 1 |
| **Engine II** | 1 |
| **Advanced Plasma** | 1,000 |

The pack goes into the friend's hangar. Advanced Plasma is the x2 ammo. If any part of it cannot be given, none is, and the game says to try again later.

## Who Can Use a Code

The code is for **new accounts**, and the game keeps it that way:

- **Level 4 or lower.** A pilot at level 5 or above cannot use a code.
- **Once per account.** An account that used a code cannot use another.
- **Never your own code.**
- **Three per network address per day.** From one network address (a household, a school, a mobile carrier's shared address) at most 3 codes can be used in any 24 hours. The page says so when a network has used its share; try again tomorrow or from another network.
- **No guessing.** Ten codes nobody has, typed within ten minutes, and the game asks you to wait.

A friend who cannot use a code is told why, in plain words, under the field.

## When a Friend Reaches Level 5

When a friend who used your code reaches **level 5** (160,000 experience), a reward of **2,500 Thulium** waits for you in the list of friends, with a **Collect** button next to the friend. It is never paid by itself: you collect it, once per friend, whenever you like, even if the friend's account is gone by then.

A friend shows one of three states, in words as well as colour:

- **Joined**: used your code.
- **Reached level 5**: the reward waits for you.
- **Collected**: you have collected it.

The **Invite Friends** entry in the sidebar's Community group carries a small **(!)** while something waits to be collected, and so does **Return to Base** in flight.

## Milestones

Friends who reach level 5 also count toward a ladder. Each milestone is paid once, in any order, when you collect it:

| Friends at level 5 | Reward |
| :---: | :--- |
| **3** | 5,000 Thulium |
| **5** | 10,000 Thulium |
| **10** | 25,000 Thulium |
| **25** | 75,000 Thulium |

A milestone shows **Locked** (with how many friends are still missing), **Ready** (with a **Collect** button) or **Collected**. Only friends who reached level 5 count, not those who only used the code, and a friend who reached it stays counted for good.

## Good to Know

- The season's [wipe](/wiki/03-Mechanics/Wipe-Timeline.md) does not touch codes, friends or what you collected.
- The rewards and the milestones are set on the game server and may change in an update; the page always shows the ones in force.
- A game server from before Invite Friends has no such page: the section says so.
- Friends you invite can join your [Clan](/wiki/03-Mechanics/Clans.md) or your [Group](/wiki/03-Mechanics/Groups.md) like any other pilot.
