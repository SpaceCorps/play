# 속도 계산 {#speed-calculation}

속도는 함선이 스페이스맵에서 얼마나 빠르게 움직이는지를 결정합니다. 속도가 빠르면 대상을 추격하고, 교전에서 벗어나고, 섹터 사이를 이동하기 쉬워집니다.

## 속도 공식 {#the-speed-formula}

함선의 최종 속도는 서버에서 다음 공식으로 계산합니다.

\[\text{최종 속도} = (\text{함선 기본 속도} + \text{엔진 속도 합계}) \times (1.0 + \text{속도 보너스 비율 합계})\]

### 1. 엔진의 실효 속도 {#1-effective-engine-speed}

장착한 엔진은 모두 속도를 만들어 내며, 추진기가 들어 있는 적응형 코어도 마찬가지입니다. 엔진 안에 추진기가 들어 있으면 그 엔진의 속도가 달라집니다.

\[\text{엔진 속도} = (\text{엔진 기본 속도} + \text{추진기 고정 보너스}) \times \text{추진기 배율}\]

- **추진기 고정 보너스**: 추진기가 더하는 고정 속도를 모두 합한 값입니다 (예: Impulse Thruster III는 속도 `+15`).
- **추진기 배율**: 그 엔진의 슬롯에 끼운 모든 추진기의 속도 배율을 곱한 값입니다 (예: Momentum Thruster III는 `1.09`, 즉 `+9%`, Impulse Thruster III는 `1.03`, 즉 `+3%`). 엔진이 만들어 내는 모든 것에 곱해집니다. 엔진 자체의 기본 속도와 추진기의 고정 보너스 모두 해당합니다. 적응형 코어에는 자체 기본 속도가 없지만, 그 추진기의 고정 보너스에는 똑같이 배율이 곱해집니다.

Engine III(기본 속도 6)에 Momentum Thruster IV(`+12`, `1.11`) 3개를 끼우면 (6 + 3 x 12) x 1.11 x 1.11 x 1.11 = 57.4의 속도를 내고, Impulse Thruster IV(`+17`, `1.02`) 3개를 끼우면 (6 + 3 x 17) x 1.02 x 1.02 x 1.02 = 60.5입니다. 추진기 배율에 붙는 대장간 보너스는 1을 넘는 부분을 키웁니다. `1.11`에 +15% 보너스가 붙으면 `1.1265`가 됩니다.

### 2. 수확 체감 (한계 효율) {#2-diminishing-returns-marginal-efficiency-}

엔진을 끝없이 쌓아 속도를 무한정 올리는 일을 막기 위해 **수확 체감(한계 효율)** 곡선이 적용됩니다. 모든 엔진은 속도 기여도 순으로 정렬되어 차례대로 계산됩니다. 적응형 코어(하이브리드)와 실드 코어도 같은 방식으로 순위가 매겨지며, 종류마다 따로 묶어 계산합니다. 그래서 엔진과 적응형 코어를 모두 장착한 함선은 종류별로 처음 4개씩이 최대 효율을 받습니다.

| 엔진 순위 | 효율 배율 |
| :---: | :--- |
| **1~4번째** | **100%** (1.0) |
| **5번째** | **85%** (0.85) |
| **6번째** | **70%** (0.70) |
| **7번째** | **55%** (0.55) |
| **8번째 이후** | **25%** (0.25) |

여기에 더해, 엔진 속도에는 슬롯 효율(코어 100%, 지원 75%, 보조 50%)이 곱해집니다.

### 3. 속도 보너스 비율과 실드 페널티 {#3-speed-bonus-percent-shield-penalties}

속도 보너스 비율의 합은 장착한 엔진(과 하이브리드)의 속도 보너스를 모두 더한 값에서 장착한 실드의 페널티를 뺀 값입니다.

- **엔진 속도 보너스**: 엔진은 속도를 몇 퍼센트씩 올려 줍니다 (예: Engine III는 `+5%`).
- **실드 속도 페널티**: 무거운 실드는 함선을 둔하게 만들어 속도를 깎습니다 (예: Heavy Shield Core는 속도 `-5%`).
- **슬롯 보정**: 이 보너스와 페널티의 비율에도 아이템을 장착한 슬롯의 효율이 똑같이 적용됩니다. 드론에 장착한 실드도 코어 슬롯에 장착한 실드와 똑같이 속도를 떨어뜨립니다.
- **0 아래로 내려가지 않음**: 실드를 아무리 많이 장착해도 속도는 0 아래로 내려가지 않습니다.
- **드론 편대**: 착용 중인 [드론 편대](/wiki/03-Mechanics/Formations.md)는 최종 속도를 한 번 더, 독립된 계수로 바꿉니다. Gyre +10%, Cordon −3%, Auger −9%, Culler −10%, Redoubt −11%, Rampart −17%입니다. Afterburner는 그 결과에 배율을 곱합니다.
