# SpaceCorps をはじめよう {#getting-started-in-spacecorps}

究極の宇宙戦争体験へようこそ。SpaceCorps のパイロットとして、あなたは自分で選んだ陣営を代表し、銀河の覇権をかけて戦い、貴重な資源を集め、宇宙での名声を築いていきます。

## 基本の通貨と名誉 {#core-resources}

生き残り、勝ち進むには、2種類の通貨を管理し、名誉にも目を配る必要があります。製作に使う素材は[資源](/wiki/06-Items/Resources.md)のページに、入手先と用途とともにまとめてあります。
- **クレジット**：標準となる主要通貨です。倒したすべてのエイリアンと達成したミッションから支払われ、あなたの [Skylab](/wiki/03-Mechanics/Skylab.md) のクレジットファームでも生産されます。基本的な装備、艦、標準的な装備の購入に使います。
- **Thulium**：貴重な放射性鉱石であり、高価値の通貨です。倒したすべてのエイリアンと達成したミッションから支払われ、あなたの Skylab の Thulium ファームでも生産されます。エリート兵器、エンジン、ハイブリッドシールド、強力なブースターパックの購入と、アセンブリでのモジュールの強化に使います。
- **名誉**：お金ではなくスコアで、陣営での階級、忠誠、評価を示す指標です。名誉を稼ぐと階級称号が上がりますが、自分の陣営の味方パイロットを攻撃すると、名誉が大きく減点されます。自企業のパイロット（プレイヤーの艦、または自企業の[企業パイロット](/wiki/03-Mechanics/Company-Pilots.md)）を撃破すると、名誉を100失います。ほかの何かがそのパイロットを撃破する前の15秒間に攻撃を当てた場合も同じです。企業の仲間を弱らせてエイリアンにとどめを刺させても、自分で撃破したのと同じだけ減点されます。企業の仲間を撃破しても PvP 撃破にはならず、PvP ポイントも得られません。

ステーションでは、クレジット、Thulium、名誉が各ページの右上に、セクターと「出撃」ボタンのすぐ隣に表示されます。ウィンドウが狭くて長い数値が収まらないときは短縮表示（987.7M）になります。カーソルを合わせると、数値の全体が読めます。

## 友達と一緒に遊ぶ {#playing-with-friends}

[クラン](/wiki/03-Mechanics/Clans.md)に加入するか、最大5人までの[グループ](/wiki/03-Mechanics/Groups.md)で飛びましょう。あなた専用のコードで、新しい友達を誘うこともできます。**コミュニティ › 友達招待**では、友達にスターターパックが贈られ、友達がレベル5に達すると、あなたに Thulium の報酬が入ります。詳しくは[友達招待](/wiki/03-Mechanics/Invite-Friends.md)を参照してください。

## ミッション {#missions}

ミッションは、レベルを上げるいちばん早い方法です。ツールバー（ステーションのセーフゾーン内）から、またはステーションの上に浮かぶ **Mission Control** の吹き出しをクリックして、**Mission Control** を開きましょう。88のミッションで、レベル1から8まで進めます。各レベルにはミッションが10個あり（順不同で達成できます）、10個を達成すると**スペシャル**が解放されます。レベルごとのミッションは、基地から境界、そして PvP の中心部へと、1セクターずつ外側へ導いてくれます。仕組みと各ミッションの報酬は、[クエスト](/wiki/03-Mechanics/Quests.md)を参照してください。

## 撃破と復帰 {#dying-and-coming-back}

船体が0になると艦は破壊され、復帰画面で復帰する場所を尋ねられます。選択肢は常に3つ表示され、クリックか、キー `1`、`2`、`3` で選びます（選択は爆発の3秒後に有効になるため、戦闘中に押していたキーで選んでしまうことはありません）。

| 選択肢 | キー | 復帰場所 | 使用後のロック |
| :--- | :---: | :--- | :--- |
| **基地で復帰** | `1` | あなたのワールドにある自企業の基地（`M-1`、`T-1`、`G-1` のいずれか）のステーションのセーフゾーン内。どこで撃破されても同じです。 | なし |
| **最寄りのポータルで復帰** | `2` | 撃破された場所から直線距離でもっとも近い、そのセクターのポータルの隣（ポータルから150～300ユニット）。ポータルが1つのセクターでは、そのポータルを使います。ポータルのないセクター（中立セクター）では、この選択肢はグレーアウトされます。 | 3分 |
| **その場で復帰** | `3` | 撃破された場所（同じセクター内）。 | 5分 |

- **ロックは、その選択肢で復帰した時点から始まります**。撃破された時点ではなく、ロックはその選択肢だけに掛かります。ポータルで復帰しても、その場での復帰はロックされません。ロック中の選択肢は復帰画面でグレーアウトされ、残り時間（分と秒）がカウントダウン表示されて、時間が来ると自動的に使えるようになります。ロックはサーバーが管理しているため、ログアウトして入り直してもリセットされません。新しいシーズン（ワイプ）ではリセットされます。
- **サーバーに拒否された選択は、何も消費しません。**選択肢が使えない場合（まだロック中、セクターにポータルがない、撃破後にワールドを変更した）、ロックは使われず、艦も移動しません。もう一度選び直してください。
- **復帰直後の保護。**どの場所を選んでも、復帰した艦は**3秒間**ダメージを受けず、ロックオンもされません。エイリアンも追跡をやめるため、あなたを撃破した相手がすぐにもう一度撃破することはできません。この3秒間は**自分も攻撃できません**。レーザーもロケットも通知とともに拒否され、保護が途中で解除されることもありません。残り秒数は HUD に表示されます。保護は時間切れで終わります。
- **ブラックホール。** [ブラックホール](/wiki/03-Mechanics/Black-Hole.md)の放射線リング（危険セクター 4 の中心から4,200ユニット）の内側は、復帰場所にはなりません。そこで撃破された場合、「その場で復帰」を選ぶと、中心とあなたの位置を結ぶ線上で、リングの外側にいちばん近い地点に復帰し、その旨が通知されます。
- **危険セクター。**そこでも3つの選択肢すべてが使えます。
- **復帰時の船体には上限があります。**どの場所を選んでも、艦の船体は**最大10,000**、シールドは空の状態で復帰します。Protos（船体8,000）は満タンで戻りますが、それより大きい艦（Kitefin の24,000から Ironclad の600,000まで）は10,000で戻るため、次の戦闘の前に Repair Drone か Emergency Repair で修理してください（[戦闘](/wiki/03-Mechanics/Combat.md)と[アビリティ](/wiki/03-Mechanics/Abilities.md)を参照）。シールドはいつもどおり回復します。復帰画面にもその旨が表示されます。
- **それ以外の撃破のペナルティ。**アイテムは失いません。選択肢が決めるのは、復帰する場所だけです。アビリティは使用可能な状態で、ステルスは解除され、EMP の効果時間外の状態で復帰します。[グループ](/wiki/03-Mechanics/Groups.md)には残ったままです。
- **ドッキング。**復帰画面の「基地に戻る」を押すと、いつもどおり同じ船体のまま基地で復帰します。選ぶ前にゲームが終了してしまった場合は、[ハンガー](/wiki/03-Mechanics/Hangar.md)で艦を無料で修復できます。その場合は基地にいて、船体は同じ、シールドは空です。

## キーボード操作とキー設定 {#keyboard-controls-keybindings}

SpaceCorps はキーボード操作のカスタマイズに対応しています（ゲーム内の設定パネルから変更できます）。以下は初期設定のキー割り当てです。

| アクション | 操作 / キー | 説明 |
| :--- | :--- | :--- |
| **艦の移動** | スペースマップ上で `Left Click` | クリックした目的地の座標へ艦を飛行させます。 |
| **カメラの回転とズーム** | `Right Drag`、`Mouse Wheel` | 右ドラッグで艦を中心に視点を回転できます。ホイール（または中ボタンドラッグ）で、30ユニットの距離から1,500ユニットまでズームイン／ズームアウトできます。1,500ユニットでは約4,400×2,650ユニットの宇宙空間が映り、これは1,000ユニット表示の2.25倍の面積です。回転とズームは、操作をやめた2秒後に基本の視点へ戻ります。ただし、設定 › 一般で**カメラを置いた位置のままにする**をオンにすると、視点は指定した角度と距離を保ちます（このスイッチの隣にある**視点をリセット**ボタンで、基本の視点に一度だけ戻せます。スイッチをオフにしても同様に戻ります）。設定 › 一般の**カメラズーム**は基本の距離を決める項目で、50%～338%の範囲で設定できます（初期値は150%）。スイッチがオンのときは、これを動かすとカメラが新しい距離に移動します。 |
| **ターゲット選択** | 対象を `Left Click` | エイリアン、敵パイロット、ポータルを現在のターゲットとして選択します。ターゲットウィンドウ（後述）に、その名前、距離、船体、シールドが表示されます。 |
| **選択したターゲットを攻撃** | `Key A`（または `Ctrl + Click`） | 選択したターゲットへ、レーザーとロケットの発射を開始します。 |
| **ロケット発射** | `Key R` | 最後に発射したロケット（なければホットバーの最初のロケット）を発射します。誘導ロケットは選択中のターゲットへ、直進ロケットはカーソルの方向へ飛びます。直進ロケットをマウスで狙うには、ホットバーのスロットをクリックして準備状態にし、続けて宇宙空間をクリックします。すべてのロケットは5秒のタイマーを共有します。 |
| **ポータルジャンプ** | `Key J` | ポータルから500ユニット以内（そのセーフゾーン内）にいるときに、ジャンプを開始します。ジャンプには3秒かかり（ホットバーの上のバーで確認できます）、完了するまで範囲内にとどまる必要があります。危険セクターでは、攻撃を受けている間はジャンプを開始できません。 |
| **構成切り替え** | `Key C` | 構成 1 と構成 2 を切り替えます（有効なレーザー、シールド、速度の構成を入れ替えます）。 |
| **ホットバー（メイン）** | `Digits 1 - 9` | HUD のメインホットバーのスロットにあるアイテムやアクション（弾薬、修理ボットなど）を起動します。 |
| **ホットバー（サブ）** | `Shift + Digits 1 - 9` | サブホットバーのスロットにあるアイテムやアクションを起動します。何かを置くと、メインの列の上にこの列が表示されます。「弾薬」「ロケット」「エクストラ」の選択画面を開く（またはスロットをドラッグする）と、そこにアイテムを置けます。 |
| **フルスクリーン** | `F11` または `Alt + Enter`（Windows） | ボーダーレスのフルスクリーンをオン／オフに切り替えます。飛行画面の右上にあるボタンでも、Windows と macOS の両方で同じ操作ができます。この2つのキーは固定で、変更できるキー設定には表示されません。チャットで入力している間、`Alt + Enter` は無効になります。 |
| **復帰場所の選択** | `Keys 1 - 3` | 復帰画面で：`1` は基地、`2` は最寄りのポータル、`3` はその場。上の*撃破と復帰*を参照してください。 |
| **ターゲット画面** | `Key V` | ターゲットウィンドウの表示／非表示を切り替えます。左上のツールバーの最初のボタンでも同じ操作ができます。 |
| **グループ画面** | `Key B` | グループウィンドウの表示／非表示を切り替えます。グループの艦、船体、シールドが表示されます。グループへの招待が届いている間は、`Y` で承諾、`Escape` で拒否します。[グループ](/wiki/03-Mechanics/Groups.md)を参照してください。 |

## ターゲットウィンドウ {#the-target-window}

エイリアンまたはパイロットをクリックすると、**ターゲットウィンドウ**に選択中の対象が表示されます。名前、距離、船体とシールドのバー、そして射撃中かどうかがわかります。**照準**ボタンで攻撃の開始と停止ができ（`A` と同じ）、**X** ボタンでターゲットを解除できます（`Esc` と同じ）。何も選択していないときは、その旨が1行で表示されます。

ほかのウィンドウと同じ扱いのウィンドウです。タイトルバーをドラッグすれば好きな場所に移動でき、隅にある赤いランプか**左上のツールバーの最初のボタン**（または `V`）で閉じられ、同じ方法でもう一度開けます。置いた位置と開閉の状態は、アカウントごとに記憶されます。最初は画面の上部、2つのツールバーの間に表示されます。閉じても表示が隠れるだけで、ターゲットは選択されたまま、攻撃も続きます。

## ゲームが重いとき {#when-the-game-lags}

**設定 › インターフェース › ネットワーク情報を表示**をオンにすると、右上に小さなカードが表示されます（ウィンドウの邪魔にならない位置に出ます。オンにするまでは表示されません）。どちら側が遅いのかがわかります。

| 項目 | 内容 | 良好・低速の目安 |
| :--- | :--- | :--- |
| **Ping** | ゲームサーバーとの往復時間です（横のアイコンは、良好なときはバー3本、低速のときは2本、不良のときは1本です。ほかの項目は、低速のときは三角形、不良のときは八角形のアイコンになります）。 | 80 ms 未満なら良好、150 ms を超えると不良です。 |
| **ジッター**、**スナップショットの古さ** | サーバーからの更新（毎秒20回）が、どれだけ均等に、どれだけ新しい状態で届くかを示します。 | ジッターが 25 ms 未満で、古さが 100 ms 未満なら良好です。 |
| **最長の途切れ** | 直近10秒間で、サーバーからの更新がもっとも長く途絶えた時間です。 | 1秒を超えると停止です。 |
| **サーバー** | サーバー自身の 50 ms ステップ1回にかかる時間です（99パーセンタイル）。サーバーが古くて報告できない場合は*なし*と表示されます。 | 20 ms 未満なら良好、35 ms を超えると不良です。 |
| **クライアント** | あなたのコンピューターのフレーム時間です（95パーセンタイル）。 | 25 ms 未満なら良好、33 ms を超えると不良です。 |

どこかが不良のときは、数値の下の1行が、どちら側に原因があるかを教えてくれます。*ネットワークが低速*、*ネットワークが遅延*、*通信が停止*はあなたの回線かサーバーまでの経路が原因で、*サーバー高負荷*はサーバーが原因です（サーバーが混み合うと Ping も上がり、更新が遅れて届くことがあります）。*クライアントが低速*はあなたのコンピューターが原因なので、グラフィックの詳細を下げてみてください。*クライアントが停止*は、ゲーム自体が一瞬描画を止めたことを意味します（Alt+Tab での切り替えや、ウィンドウの最小化など）。同じ数値は、1分に1回、停止があったときはすぐに、ゲームのログファイルにも書き込まれます。そのため、「21:10 に重かった」という報告にも、ログから答えられます。

## 初心者向けのかんたんなコツ {#quick-pro-tips-for-beginners}

1. **構成**：常に2つの異なるセットアップを用意しておきましょう。たとえば、**構成 1**はジェネレータースロットをすべてエンジンとスラスターにして、素早い退避や移動に使い、**構成 2**はシールドとレーザーを搭載して戦闘に使います。
2. **セーフゾーン**：ポータルと基地の周囲には**セーフゾーン**があります。この範囲内では、ほかのパイロットはあなたを攻撃できないため、安全にシールドを回復したり、戦闘のクールダウンが明けるのを待ったりできます。
3. **最初のアビリティ**：スターターキットでは、すでに Repair Drone I が Protos のアビリティスロットに装着されています。そのため、Emergency Repair ボタン（ホットバーの横の `E`）で、船体が損傷しているときいつでも、10秒かけて船体を回復できます。[アビリティ](/wiki/03-Mechanics/Abilities.md)を参照してください。
4. **毎日のクラン税**：クランに所属している場合、クランバンクが UTC の午前0時に、あなたのクレジット残高から毎日一定の税率（0%～5%）を徴収する点に注意してください。クラン選びは慎重に！
5. **Wiki からコピー**：記事の任意のテキストをドラッグして選択し、`Ctrl+C`（Mac では `Cmd+C`）を押すとコピーできます。リンクをクリックすると、これまでどおりそのページが開きます。記事の上部にある**ページをコピー**は、ページ全体を Markdown 形式でコピーします。チャットやメモに貼り付けられます。
