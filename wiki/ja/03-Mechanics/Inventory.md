# インベントリと装備 {#inventory-equipment}

ハンガーでは、艦と装備を管理できます。アイテムを効果的に装備することが、生き残り、優位に立つための鍵です。基地で行えるほか、飛行中でもセーフゾーン内なら行えます。詳しくは[飛行中のハンガー](/wiki/03-Mechanics/Hangar.md)をご覧ください。

## 装備スロットとステータス効率 {#equipment-slots-stat-efficiencies}

従来の宇宙ゲームとは異なり、SpaceCorps には段階式の装備スロットがあり、装着したモジュールがどれだけ力を発揮するかは、スロットによって変わります。

- **レーザースロット**：攻撃用の武器（レーザー）のためのスロットです。常に**ダメージと射程の100%**で機能します。
- **ジェネレータースロット**：シールド、エンジン、アダプティブコアが共用するスロットです。効率の異なる3つの帯域に分かれていて、帯域によってアイテムの基本ステータスのどれだけが反映されるかが決まります。ハンガーでは、各帯域の名前の横に説明を表示する (i) があります。
  - **コアスロット**：ここに置いたアイテムは、基本ステータスの**100%**を受け取ります。どの艦にもあり、最も強いシールドとエンジンはここに入れましょう。
  - **サポートスロット**：ここに置いたアイテムは、基本ステータスの**75%**を受け取ります（例：速度やシールド容量が75%）。どの艦にもあります。
  - **補助スロット**：ここに置いたアイテムは、基本ステータスの**50%**を受け取ります。持っているのは一部の艦だけです（Nomad は1つ、Paragon と Storm は2つ、Ironclad は3つ、Wraith は4つ。Protos、Kitefin、Ostirion にはありません）。追加の、より弱いシールドやエンジンに向いていて、最も強いものはコアスロットに入れます。
  - **ドローンスロット**：自分のドローンに載せたシールドは、コアスロットのものと同じように数えられ、ステータスの**100%**が反映されます（[ドローンの仕組み](/wiki/03-Mechanics/Drones.md)を参照）。
  - **未割り当て／レガシースロット**：ここに置いたアイテムは、ステータスに寄与しません。
  - **重ねるほど効果も薄れます**：シールドとエンジンは強い順（スロットの割合を掛けたあとの値で）に順位が付けられ、帯域の割合に、その順位の割合が掛け合わされます。1～4個目はそのまま、5～7個目は85%、70%、55%、8個目以降はシールドが50%、エンジンが25%です。詳しくは[シールド](/wiki/03-Mechanics/Shields.md)と[速度](/wiki/03-Mechanics/Speed.md)をご覧ください。
- **エクストラスロット**：Repair Drone など、特殊なユーティリティアイテム用のスロットです。Protos、Kitefin、Ostirion、Nomad には2つ、製作する Paragon、Ironclad、Wraith、Storm には3つあり、Extra Slots CPU（[エクストラ](/wiki/06-Items/Extras.md#extra-slots-cpus)）を導入すると、3、5、7つ増えます。
- **装甲スロット**：船体を増やす[船体装甲](/wiki/06-Items/Hull-Plating.md#hull-plate-slots)用のスロットです。製作する4隻の艦だけが持ち（Paragon は5つ、Storm は7つ、Ironclad は15、Wraith は9つ）、Skylab で研究するまでそれぞれロックされています。2つの構成で共通です。

## インベントリの並び順 {#inventory-order}

インベントリのアイテムは、購入した順、製作した順、見つけた順に関係なく、ショップと同じ順序で並びます。関連する種類は隣り合って並びます。レーザー、レーザーアンプ、レーザー弾薬、続いてシールドとシールドセル、エンジンとスラスター、アダプティブコア、エクストラ（Repair Drone）、ドローンとドローン編成、そして資源の順です。同じ種類の中では、価格の安いものが先で（クレジット払いが Thulium 払いより先）、次に価格のないもの、つまり製作専用の装備とドロップ品が続き、いずれもレアリティの低いものが先です（同じレアリティのレーザーはダメージの低いものが先）。レーザー弾薬は x1 から x4 の順で、最後に Siphon Battery が来ます。ロケットは種類順（単体は範囲爆発より先、誘導は直進より先）に並び、その中で段階順になるため、Thulium で買うエピックのロケットは、その種類の最後に来ます。同じアイテムの複数のコピーは、エンチャント段階の順に並びます。グリッドの上には、種類ごとに1つのチップが同じ順序で並び、それぞれ検索に一致したアイテムの数が表示されます。チップは1つずつオン／オフを切り替えられるので、レーザー、シールド、エンジンを調整している間は、弾薬や Repair Drone を隠せます。チップをクリックするとその種類の表示／非表示が切り替わり、Shift を押しながらクリック（またはダブルクリック）するとその種類だけが残り、もう一度クリックすると残りが戻ります。**すべて**はすべての種類を表示し、**なし**はすべてを隠すので、そこから必要なものだけをオンにできます。取り消し線の入ったチップはオフ、チェックマークの付いたチップはオンです。検索はオンの種類を対象とし、選択内容はパイロットとともに保存されます。すべてが隠れている場合、グリッドにはそのことが表示され、**すべてのカテゴリーを表示**のボタンが出ます。

## 出品可能なアイテム {#marketable-items}

獲得したアイテム（ドロップ、ミッション報酬、アセンブリと鍛冶場が作るもの）には、タイルに小さな**出品可能**のタグが付き、アイテムカードには「出品可能」、一部のユニットしか売れないスタックには「出品可能（3 / 5）」と表示されます。カテゴリのチップの隣にある**出品可能のみ**チップを使うと、そうしたアイテムだけが表示されます。タグの付いたアイテムのごみ箱の隣にある**木槌**のボタンで、[オークション](/wiki/03-Mechanics/Auction.md)の出品シートが開きます（飛行中は表示されません。売却はステーションのページで行います）。購入したもの、落札したもの、プレゼントされたものにはタグが付かず、再び売ることはできません。

## アイテム同士の装着（サブソケット） {#item-to-item-equipping-sub-sockets-}

一部のメインアイテムには、サポートアイテムを「装備」させて（サブソケットと呼びます）、パラメーターを強化できます。サブソケットするには、ハンガーのインベントリ内で、サポートアイテムをメインアイテムの上に直接ドラッグします。

### 対応表 {#compatibility-table}

| メインアイテム | 装着できるサブソケットアイテム | 効果 |
| :--- | :--- | :--- |
| **レーザー** | レーザーアンプ | 基本ダメージとクリティカル関連のステータスを高める、またはターゲットの吸収率からポイントを差し引く（Penetration Amp） |
| **シールドコア** | シールドセル | シールド容量とリチャージ速度を強化 |
| **エンジン** | スラスター | エンジン速度と倍率を強化 |
| **ハイブリッドジェネレーター** | シールドセルまたはスラスター | シールド容量、リチャージ速度、または速度を強化 |
| **ドローン** | それぞれのスロットにレーザーかシールド（Master Drone にはスロットが2つ） | レーザーはそのダメージを斉射に加算。シールドはコアスロットのシールドとして数えられる（ステータスの100%） |

## 弾薬の管理 {#ammo-management}

レーザー弾薬は消耗品です。
- 弾薬はインベントリ内でスタックされます。
- 使用するレーザー弾薬は、HUD のホットバーで切り替えられます。
- 高品質の弾薬ほど、ダメージの倍率が高くなります（例：Standard Battery は x1、Advanced Plasma は x2、Ultra Core は x3、Experimental Fusion Core は x4）。Siphon Battery は、シールドにだけ x1 のダメージを与え、そのぶんを自分のシールドに加えます。
