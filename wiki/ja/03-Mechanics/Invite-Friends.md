# 友達招待 {#invite-friends}

パイロットには1人1つ、専用の**招待コード**があります。ゲームを始めたばかりの友達がそのコードを1回使うとスターターパックがもらえ、その友達がレベル5に達すると、あなたは Thulium の報酬を受け取れます。友達が増えてレベル5に達するほど、報酬も増えます。すべて、**コミュニティ › 友達招待**の1つのページにまとまっています。

## あなたのコード {#your-code}

- **コミュニティ › 友達招待**を開くと、`BCDF-GHJK` のような形のコードが表示されます。コードは初めて見たときに作られ、ずっとあなたのものです。変わることはなく、ほかの人には見えません。
- **コードをコピー**はコードをクリップボードにコピーし、**招待メッセージをコピー**は、友達にそのまま貼り付けられる短いメッセージをコピーします。ゲーム名、あなたのコード、コードを入力する場所（Steam 以外では、ゲームの入手先も）が入っています。Steam 版では、メッセージにダウンロード先のアドレスは含まれません。
- コードは、大文字でも小文字でも、ハイフンありでもなしでも入力できます。

## 友達がもらえるもの {#what-a-friend-gets}

友達は、**コミュニティ › 友達招待**であなたのコードを入力します（まだコードを使えるパイロットには、ページに**友達からのコードをお持ちですか？**のカードが表示されます）。すると、すぐに、一度にまとめて次のものがもらえます。

| スターターパック | |
| :--- | :--- |
| **クレジット** | 100,000 |
| **Thulium** | 5,000 |
| **N.I.K.E.** | 1 |
| **Quantum Laser 2** | 1 |
| **Engine II** | 1 |
| **Advanced Plasma** | 1,000 |

パックは友達のハンガーに入ります。Advanced Plasma は x2 弾薬です。一部でも渡せない場合は、何も渡されず、ゲームから、あとでもう一度試すよう案内されます。

## コードを使える人 {#who-can-use-a-code}

コードは**新しいアカウント**向けで、ゲームがそのように制限しています。

- **レベル4以下。**レベル5以上のパイロットはコードを使えません。
- **1アカウントにつき1回。**コードを使ったアカウントは、別のコードを使えません。
- **自分のコードは使えません。**
- **同じネットワークアドレスからは1日3回まで。**1つのネットワークアドレス（家庭、学校、携帯電話会社の共有アドレスなど）から使えるコードは、24時間のうち最大3回です。ネットワークが上限に達すると、ページにその旨が表示されます。明日もう一度試すか、別のネットワークから試してください。
- **当てずっぽうはできません。**誰も持っていないコードを10分以内に10回入力すると、ゲームから、しばらく待つよう求められます。

コードを使えない友達には、入力欄の下に、わかりやすい言葉で理由が表示されます。

## 友達がレベル5に達したとき {#when-a-friend-reaches-level-5}

あなたのコードを使った友達が**レベル5**（経験値160,000）に達すると、**2,500 Thulium** の報酬が友達リストで待っていて、その友達の横に**受け取る**ボタンが表示されます。報酬が自動で支払われることはなく、友達1人につき1回、好きなタイミングで受け取れます。その時点で友達のアカウントがなくなっていても受け取れます。

友達は3つの状態のいずれかで表示され、色だけでなく文字でも示されます。

- **参加済み**：あなたのコードを使いました。
- **レベル5に到達**：報酬があなたを待っています。
- **受け取り済み**：報酬を受け取りました。

サイドバーのコミュニティグループにある**友達招待**の項目には、受け取れるものがある間、小さな **(!)** が付きます。飛行中の**基地に戻る**にも同じ印が付きます。

## マイルストーン {#milestones}

レベル5に達した友達は、段階的な報酬にもカウントされます。マイルストーンはそれぞれ1回ずつ、好きな順番で、受け取ったときに支払われます。

| レベル5に達した友達 | 報酬 |
| :---: | :--- |
| **3人** | 5,000 Thulium |
| **5人** | 10,000 Thulium |
| **10人** | 25,000 Thulium |
| **25人** | 75,000 Thulium |

マイルストーンは、**未解放**（あと何人の友達が足りないかも表示）、**受け取り可**（**受け取る**ボタン付き）、**受け取り済み**のいずれかで表示されます。カウントされるのはレベル5に達した友達だけで、コードを使っただけの友達は含まれません。一度レベル5に達した友達は、ずっとカウントされたままです。

## 知っておくと便利なこと {#good-to-know}

- シーズンの[ワイプ](/wiki/03-Mechanics/Wipe-Timeline.md)で、コード、友達、受け取ったものが失われることはありません。
- 報酬とマイルストーンはゲームサーバーで設定されていて、アップデートで変わることがあります。ページには、常に現在有効なものが表示されます。
- 友達招待が追加される前のゲームサーバーには、このページはありません。その場合は、セクションにその旨が表示されます。
- 招待した友達も、ほかのパイロットと同じように、あなたの[クラン](/wiki/03-Mechanics/Clans.md)や[グループ](/wiki/03-Mechanics/Groups.md)に参加できます。
