# デイリー報酬 {#daily-rewards}

<!-- wiki-search: daily reward; daily rewards; daily login; login bonus; login reward; calendar; advent calendar; chest; chests; season prize; souvenir; blueprint; streak; デイリー報酬; デイリーログイン; ログインボーナス; カレンダー; 宝箱; シーズン特典; 記念品; 設計図; 連続 -->

シーズンごとに**デイリー報酬のカレンダー**があります。シーズンの毎日に、小さな贈り物が1つずつ用意されています。ステーションで**受け取る**を押すと、その日の贈り物があなたのものになります。受け取った日数が多いほど、もらえるものも増えます。受け取った日数が7、14、21、28日になると**宝箱**が届き、シーズン最後の3日間には**シーズン特典**を受け取れます。受け取り逃した日は、その日の贈り物を失うだけで、ほかには何も失いません。カレンダーは**ダッシュボード**（**デイリー報酬**のカード）と、**シーズンとプロフィール › カレンダー**にあります。

## 1分でわかる {#in-one-minute}

- **29枚のタイル。** シーズンの UTC の1日ごとに1枚です。シーズンは30日ですが、30日目は[ワイプ](/wiki/03-Mechanics/Wipe-Timeline.md#30-day-season-schedule)の5分間のカウントダウンなので、受け取るものはありません。
- **受け取るのはあなたです。** 1回押すと1枚のタイルを受け取れます。受け取れるのはパイロットごとに1回です。何も自動では受け取られません。
- **6時間の猶予。** タイルは、その日が終わってから6時間のあいだ開いたままです。
- **連続記録はありません。** 受け取り逃した日は、その日のタイルを失うだけです。大切なのは受け取った日数で、連続しているかどうかではありません。
- **4つの宝箱**が、受け取った日数が7、14、21、28日になったときに届きます。
- **シーズン特典**はシーズン最後の3日間に受け取れます。受け取った日数が10日で記念品の外観、20日で艦のデザイン設計図です。
- **ワイプのたびに新しいカレンダー。** シーズンの贈り物はすべて1日目から見られます。
- **あえて控えめに。** 29日分を合わせても、価値はおよそ数時間分の狩りに相当する程度で、シーズン全体に分けて配られます。

## 1日 {#the-day}

カレンダーの1日は **UTC の1日**です。**00:00 UTC** に、すべてのパイロットで同じ瞬間に切り替わります。日数の数え方は、クランの日次ラインと同じです（「29日中の*n*日目」、[クラン](/wiki/03-Mechanics/Clans.md#the-day)を参照）。あなたのタイムゾーンには従わず、シーズンページに表示されるシーズン日（シーズンが始まった時刻に切り替わります）とも別物です。すべてをサーバーの時計が決めます。お使いのコンピューターの時計は何も変えません。

次の報酬がいつ開くかは、カードにもタブにも**あなた自身のタイムゾーンで**表示されます（「新しい報酬は現地時間の 02:00 に開きます（00:00 UTC）」）。自分で調べるには、00:00 UTC を換算してください。いくつか例を挙げます。

| 地域 | UTC の午前0時は |
| :--- | :--- |
| 中央ヨーロッパ | 01:00（冬）または 02:00（夏） |
| モスクワ、イスタンブール | 03:00 |
| 日本、韓国 | 09:00 |
| 米国東海岸 | 19:00（冬）または 20:00（夏） |
| 米国西海岸 | 16:00（冬）または 17:00（夏） |

- **1日目は短いです。** シーズンはワイプとともに UTC の1日の途中から始まるので、タイル1は、そのときからその日の終わりまで、さらに猶予の時間のあいだ開いています。
- **29日目は長いです。** 最後のタイルは、ワイプのカウントダウンが始まるまで開いたままで、開いてから24時間以上になることもあります。カウントダウンが始まると、新しいシーズンが始まるまで何も受け取れません。
- **管理者はシーズン日を動かすことがあります。** カレンダーもそれに従います。飛ばされた日は全員にとって受け取り逃しとなり、すでに受け取ったタイルは受け取り済みのままです。

## タイル {#the-tiles}

カレンダータブには、1日につき1枚のタイルが並ぶ格子が表示されます。日付の番号、贈り物、言葉で書かれた状態が載っています。シーズンの贈り物はすべて最初の日から見えるので、何が来るのか分かります。受け取った日数（たとえば「29日中11日受け取り済み」）も数え、次の宝箱がいつ届くかも表示します。ダッシュボードのカードには、今日の贈り物と**受け取る**ボタンが1つだけ表示されます。

| 状態 | 意味 |
| :--- | :--- |
| **今日** | 今、開いています。**受け取る**を押してください。 |
| **受け取り済み** | もう手に入れています。 |
| **昨日** | 昨日のタイルで、猶予のあいだはまだ開いています。残り時間が表示され、専用の**受け取る**ボタンがあります。 |
| **受け取り逃し** | その日と猶予の時間が終わりました。贈り物は失われ、ほかには何も変わりません。 |
| **… 後に開く** | これから来る日です。贈り物は見られますが、まだ受け取れません。 |
| **参加前** | 初めてサインインする前の日です。受け取れません。 |

報酬が待っているあいだは、サイドバーの**シーズンとプロフィール**と、飛行中の**基地に戻る**に小さな **(!)** が表示され、サインイン時にもメッセージで知らせます（1日につきコンピューターごとに1回）。

## 猶予と受け取り逃し {#grace-and-missed-days}

タイルは真夜中に閉じるわけではありません。UTC の1日が終わってから**6時間**のあいだ開いたままです。この6時間は2枚のタイル、つまり昨日と今日のタイルが開いていて、それぞれ別々に押して受け取ります。猶予が過ぎると、昨日のタイルは完全に**受け取り逃し**となり、それより前には戻れません。

受け取り逃した日は、**その日の贈り物を失うだけで、ほかには何も失いません**。途切れる連続記録はありません。受け取った日数、宝箱、シーズン特典はそのまま続きます。猶予のあいだに受け取ったタイルは、時間内に受け取ったタイルとまったく同じに数えられます。

## 宝箱 {#chests}

宝箱は、受け取った日数がある数に達する**受け取り**と一緒に届き、それより前には届きません。押すものも、探す鍵もありません。大切なのは日付ではなく日数です。7日の宝箱は、シーズンの何日目であっても、7日目の受け取りと一緒に届きます。

| 宝箱 | 届くとき |
| :---: | :--- |
| **1つ目** | 7日受け取り済み |
| **2つ目** | 14日受け取り済み |
| **3つ目** | 21日受け取り済み |
| **4つ目** | 28日受け取り済み |

どの宝箱にも**Specimen Vault**が1つ入っています。何でも少しずつ入っているコンテナです。後ろの宝箱には、ワイプで失われない小さなおまけが付くことがあります。各宝箱の中身はカレンダータブで確認できます。コンテナはあなただけのもので、コンテナのページで開けます。開けていないコンテナは、[ワイプ](/wiki/03-Mechanics/Wipe-Timeline.md)を越えてもアカウントに残ります。

ゲームがコンテナを渡せないとき（たとえばコンテナが有効になっていないとき）は、代わりに、クレジット、Thulium、ほぼ同じ価値のブースターの**セット**が支払われます。宝箱が失われることはなく、両方もらえることもありません。

## シーズン特典 {#season-prize}

シーズン特典には2つの段階があります。シーズン最後の**3日間**（27日目から29日目）に、ワイプのカウントダウンが始まるまで受け取れます。27日目より前は、日数が足りていても、タブには**最後の3日間に開きます**と表示されます。各段階は1回ずつ、どちらの順でも受け取れます。

| 段階 | 必要な日数 | 賞品 |
| :---: | :--- | :--- |
| **1** | 10日受け取り済み | **シーズン記念品**：外観 |
| **2** | 20日受け取り済み | **デザイン設計図**：艦のデザインの技術 |

- **記念品**は、スキン、カラー、排気エフェクト、オーラのどれか（[コスメティック](/wiki/06-Items/Cosmetics.md)）で、そのために取り分けられた外観の短いリストからシーズンごとに選ばれ、エピックより上になることはありません。ほかの外観と同じく見た目だけのもので、アカウントに属し、ワイプを越えて残ります。すでに持っている場合は、持っていない次の記念品がもらえます。すべて持っている場合は、250 Thulium がもらえます。
- **設計図**は、艦のデザイン1つの研究を、あなたの代わりに済ませたものです。そのデザインの技術と、それに必要な技術が対象です。艦をそのデザインに変換する作業は、これまでどおりアセンブリで行い、費用もこれまでどおり[艦のデザイン](/wiki/03-Mechanics/Ship-Designs.md#getting-a-design)に書かれたとおりです。シーズンのデザインは13種のうちの1つで、決まった順番で選ばれるため、同じデザインが13シーズンのあいだ巡ってくることはありません。すでに知っている場合は、持っていない次のデザインがもらえます。13種すべてを知っている場合は、アイテムである Dark Matter Plate を4個もらえます。ワイプの前にトランスポートキャッシュに入れてください。

## 贈り物 {#the-gifts}

1日の贈り物は小さなものです。次のどれかです。

- **弾薬とロケット**。ほどほどの数です。
- **素材、プレート、消耗品**。Forge kit（鍛冶場の1ステップ分の素材）もあります。
- 数時間分の**ブースター**。ブースターの贈り物は、その時間をあなたの[ブースター](/wiki/06-Items/Boosters.md#active-boosters)に加えます。
- **クレジットと Thulium**。少量です。
- **少数の特別なアイテム**（Workforce Contract、Forger's Seal）。1シーズンで4枚のタイルまでです。

このページは、どのシーズンの贈り物も挙げていません。カレンダーはワイプのたびに変わるからです。このシーズンの贈り物はカレンダータブで確認できます。贈り物は贈り物です。カレンダーのアイテムには**出品可能**のタグが付かず（[出品可能なアイテム](/wiki/03-Mechanics/Inventory.md#marketable-items)）、[オークション](/wiki/03-Mechanics/Auction.md)に出品できません。

## ワイプ {#the-wipe}

新しいシーズンは新しいカレンダーです。[ワイプ](/wiki/03-Mechanics/Wipe-Timeline.md)で古いカレンダーは閉じ、新しいカレンダーが29個の新しい贈り物とともに開き、受け取った日数は0から数え直しになります。ワイプは、すべてのアイテムから取り上げるもの以外は、受け取ったものを何も取り上げません。

- **削除されるもの：** アイテムである贈り物（弾薬、ロケット、素材、プレート、消耗品）は、[トランスポートキャッシュ](/wiki/03-Mechanics/Wipe-Timeline.md#transport-cache-travel-capsule-)に入れていなければワイプで削除されます。カレンダーにはそうした贈り物に注意書きが付きます。
- **残るもの：** ブースター、クレジット、Thulium、特別なアイテム、外観、技術（設計図）、コンテナ。
- **最後の4日間（26日目から29日目）は、残る贈り物だけが出ます。** 最後の週の贈り物がワイプで失われることはありません。

## 途中参加と途中開始のカレンダー {#late-joiners-and-late-calendars}

**シーズンの途中で参加した場合、** 初めてサインインする前のタイルには**参加前**と表示され、受け取れません。宝箱とシーズン特典は全員に同じ日数を求めるので、遅れて参加したパイロットが届く範囲は狭くなります。16日目に初めてサインインしたパイロットは、残りのタイルが14枚なので、受け取れるのは最大14日です。最初の2つの宝箱とシーズン特典の段階1には届きますが、段階2（20日）には届きません。

**カレンダーも途中から始まることがあります。** ふつうはシーズンとともに開きます。たとえば、シーズンの途中でゲームにデイリー報酬が加わったときなどに、あとから開くことがあります。そのようなカレンダーは残りの日数だけを持ち、すべてがそれに合わせて縮みます。14日目に開くものは、タイルが16枚（「16日中」）、宝箱は受け取り4、8、12、15日、シーズン特典の段階は6日と11日です。ダッシュボードのカードには、何日目に開いたかが表示されます。残りが10日未満だと、進行中のシーズンにはカレンダーが一切なく（**今シーズンはカレンダーがありません**）、次のカレンダーはワイプとともに始まります。

## よくある質問 {#questions}

- **N日目が受け取れないのはなぜ？** 理由は4つあります。その日がまだ来ていない（**… 後に開く**）。その日と猶予の時間が終わった（**受け取り逃し**）。その日が初めてサインインする前だった（**参加前**）。あるいは、ワイプのカウントダウンが始まった。カレンダーのないシーズンや、オフにされたカレンダーでは、受け取るものがありません。
- **自分のタイムゾーンに従う？** いいえ。1日は UTC の1日です。表示される時刻だけが、あなたのタイムゾーンに換算されます（[1日](#the-day)）。
- **サーバーが止まっていたら？** 6時間の猶予が、真夜中前後の短い停止をカバーします。もっと長い停止では、管理者が全員のためにその日をさらに長く開けておくことがあります。そのタイルは**昨日**と表示され、専用のカウントダウンが付きます。
- **2日分をまとめて受け取れる？** 2枚のタイルが開いているあいだだけです。UTC の午前0時から6時間のあいだ、昨日と今日のタイルを1回ずつ押して受け取れます。タイルを2回受け取ったり、前もって受け取ったりすることはできません。
- **毎日サインインしないといけない？** いいえ。連続記録はありません。飛ばした日はその日の贈り物を失うだけで、宝箱とシーズン特典は受け取った日数だけを数えます。
- **プレミアムで変わる？** いいえ。プレミアムでタイルが増えたり、贈り物が良くなったりすることはなく、カレンダーがプレミアムの日数を贈ることもありません。
- **クランは必要？** いいえ。カレンダーはクランの日次ラインと同じ日を使いますが、あなただけのものです。
- **レベル制限はある？** いいえ。どのパイロットも、レベル1から受け取れます。
- **ワイプではどうなる？** 新しいカレンダーが届き、0日から数え直しになります。アイテムである贈り物はトランスポートキャッシュに入れていなければ削除され、それ以外は残ります（[ワイプ](#the-wipe)）。

## 知っておくと便利なこと {#good-to-know}

- 贈り物、数字、猶予の時間はゲームサーバーで設定され、アップデートで変わることがあります。カレンダータブには、常に現在有効なものが表示されます。
- デイリー報酬より前のゲームサーバーにはカレンダーがなく、カードとタブは隠れたままです。管理者がカレンダーをオフにすることもあります。その場合も、受け取ったものは受け取り済みのままです。
- 新しいカレンダーはワイプの前に作られるので、ゲームの管理者が開始前に確認し、おかしな贈り物があれば変更できます。
