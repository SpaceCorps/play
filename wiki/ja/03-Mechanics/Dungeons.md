# ダンジョン {#dungeons}

<!-- wiki-search: dungeon; dungeons; gate; gates; clan gate; clan gates; clan dungeon; summon; warlord; gate warlord; boss; maze; loot zone; chest; card; vote; stage; instance; gate delta; gate epsilon; gate zeta; gate eta; gate theta; gate iota; gate goombah; gate pirate; gate crystalys; ダンジョン; ゲート; ウォーロード; 迷路; ステージ; 戦利品ゾーン; カード -->

**ダンジョン**は、ゲーム内では**ゲート**と呼ばれます。最奥に**ウォーロード**が待つ、閉ざされた迷路です。[クラン](/wiki/03-Mechanics/Clans.md)の副リーダーまたはリーダーがゲートを開き、クランバンクから代金を支払うと、クランのメンバーが1つの[グループ](/wiki/03-Mechanics/Groups.md)として一緒に飛び込みます。迷路のエイリアンを突破し、戦利品ゾーンを開いてそれぞれからカードを1枚選び、ウォーロードを倒します。戦闘に参加したパイロットには、ウォーロードを倒した時点で、後述の上限の範囲内で報酬が支払われます。ゲートはクランページの**ゲート**タブにあります。

ゲートはエイリアンだけと戦う場所です。中ではクランの仲間を含め、誰も攻撃できません。エイリアンは何も支払いません。報酬はウォーロードだけのものなので、報酬を受け取る唯一の方法は、ウォーロードが倒れるときに戦闘に参加していることです。

## 挑戦の流れ {#how-a-run-goes}

1. **召喚。** ゲートタブで、[副リーダーまたはリーダー](/wiki/03-Mechanics/Clans.md#hierarchy-roles)がステージを選び、**召喚**を押します。代金は[クランバンク](/wiki/03-Mechanics/Clans.md#clan-economy-taxation)から引かれ、ゲートには上の一覧のマップのどれかが割り当てられます。誰も開始しなかったゲートは閉じ、代金はバンクに戻ります。
2. **入る。** クランのメンバーは、飛行中にクランウィンドウで**入る**を押します。中にいるパイロットがゲートのグループになります。
3. **開始。** ゲートを開いたパイロットか役員が、十分なパイロットが中にそろったら**開始**を押します。その後に戻れるのは、すでに中にいたパイロットだけです。
4. **迷路を突破する。** 迷路の一方の端から入ると、反対の端でウォーロードが待っています。エイリアンは各部屋で眠っていて、グループが近づくと群れで目を覚まします。
5. **戦利品ゾーンを開く。** 迷路の中のリングがゾーンを示します。ゾーンを守り切ると、グループはカードに投票し、そのカードはウォーロードの報酬と一緒に支払われます。
6. **ウォーロードを倒す。** シールドと船体を削り、アビリティに対処します。倒れるとゲートはクリアです。
7. **報酬を受け取る。** 報酬はウォーロードが倒れた瞬間に支払われます。ゲートは中にいるパイロットのために少しの間開いたままになり、その後閉じます。

## 入るには {#entering}

ゲートに入るには、**飛行中の船**が必要です。まず出撃してからクランウィンドウを開いてください。さらに、クランのメンバーが十分にそろった[グループ](/wiki/03-Mechanics/Groups.md)も必要です。ステージが求める**レベル**を満たしている必要があり、すでに別のゲートの中にいてはいけません。ゲートのパーティには人数の上限があり、満員になると誰も入れません。

ゲートを開くのは副リーダーかリーダーで、クランが同時に開けるのは1つだけ、1日に開ける数にも上限があります。クランバンクに代金が必要です。クランは、1つ前のステージをクリアして初めて次のステージを開けます。

ゲートの中ではワールドを変更できず、Jump CPU と Base CPU は動作しません。ゲートのバーにある**退出**ボタンは、確認のあとで外に出してくれます。退出したパイロットや撃破されたパイロットは、数回だけ、短い待ち時間を挟んで再び飛び込めます。

## ステージ {#the-stages}

## 迷路 {#the-maze}

各ゲートは、専用のマップにある閉ざされた迷路で、マップは上の一覧のどれかです。迷路は複数のレイアウトのうちの1つです。迷路は部屋と通路の格子で、壁は頑丈です。船は壁を通り抜けられず、壁は射撃を遮るので、壁は遮蔽物になります。メテオは上から降ってくるため、壁では防げません。

## エイリアン {#the-aliens}

## ウォーロード {#the-warlord}

## 戦利品ゾーン {#loot-zones}

グループが見つけた戦利品ゾーンは、迷路の床のリングで示されます。リングの中にしばらく立つとゾーンが目を覚まし、エイリアンの波が押し寄せます。そこでグループはゾーンを**守り**ます。バーが満ちるまで、パイロットを1人は中に残してください。リングの中にエイリアンがいるとバーは止まり、誰も中にいない間はバーが戻るので、先に波を片付けましょう。ゾーンが開くと、グループは異なる3枚のカードを見て、1枚に**投票**します。ゾーンが開くのは1回だけで、その波は二度と来ません。

- **選択**：グループの投票時間は45秒。居合わせた全パイロットが投票するか、1枚のカードが過半数の票を得ると早く終わる

## 報酬 {#pay}

### 報酬を受け取れる条件 {#who-is-paid}

エイリアンは決して報酬を出しません。報酬が出なくてもクリアは最後まで遊べ、結果画面が理由を教えてくれます。そのステージの報酬をすでに受け取っていても、入場が断られることはありません。そのクリアが何も支払わないだけです。

- **1日**：ステージの報酬は、UTCの1日につき1回、パイロットに支払われる。ウォーロードが倒れた日が対象

- **中にいる時間**：合計で2分以上
- **戦闘への貢献**：次のうち少なくとも1つ：ウォーロードの船体とシールドの2%を削った; ゲートのエイリアンを10体撃破した; ウォーロードとの戦闘中に他のパイロットを50,000回復した

## コツ {#tips}

- ゾーンを守る前に、そのゾーンの波を片付けましょう。エイリアンが入ってきたら、リングの中で戦います。
- 壁を使いましょう。レーザーは壁を通らず、ウォーロードのリングも壁で止まります。
- ロケット弾幕のために EMP Charge を取っておきましょう。
- ゲートのバーの時計に注意してください。時間切れになるとゲートは失敗し、何も支払われません。
