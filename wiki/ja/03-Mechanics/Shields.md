# シールドの仕組み {#shield-mechanics}

シールドは、受けるダメージの大部分を吸収し、艦の船体を直接のダメージから守ります。

## シールドの計算 {#shield-calculations}

艦の最終的なシールドのパラメーターは、次のように計算されます。

\[\text{Final Shield Capacity} = \text{Total Base Capacity} \times (1.0 + \text{Total Shield Bonus Percent})\]
\[\text{Final Shield Recharge Rate} = \text{Total Base Recharge} \times (1.0 + \text{Total Shield Bonus Percent})\]

### 1. スロット効率と逓減 {#1-slot-efficiency-diminishing-returns}

エンジンと同様に、装備したシールド（とハイブリッドジェネレーター）は強い順に並べられ、スロット効率（コア：100%、サポート：75%、補助：50%、ドローンのスロット：コアスロットと同じ100%）と、順位に基づく逓減カーブが適用されます。シールドは、その有効な分、つまり容量にスロットの割合を掛けた値で順位付けされます。回復には独自の順位があり（その値にスロットの割合を掛けたもの）、シールドボーナスは上位**4つ**が有効です。自分の[ドローン](/wiki/03-Mechanics/Drones.md)に載せたシールドも、艦自身のシールドと一緒に順位付けされます。

- **1～4個目のシールド**：限界効率**100%**（1.0）。
- **5個目のシールド**：限界効率**85%**（0.85）。
- **6個目のシールド**：限界効率**70%**（0.70）。
- **7個目のシールド**：限界効率**55%**（0.55）。
- **8個目以降**：限界効率**50%**（0.50）。（バージョン0.4.7まではエンジンと同じ25%でした。エンジンは今も25%です。[速度](/wiki/03-Mechanics/Speed.md)をご覧ください。）

**増やしてもシールドは下がりません。**シールドやシールドセルを追加しても、シールド容量や回復量は決して下がりません。どの数値も有効な値の高い順に並べられるので、新しい部品は自分にふさわしい順位に入ります。吸収率はシールドの平均なので、平均より弱い新しいシールドを追加すると下がることがあります。セルでは決して下がりません。

**ハンガーに表示されます。** 力を最大限には発揮できないシールド、エンジン、アダプティブコアには、スロットに小さなパーセント表示が付きます（例：`64%` は、85%の5個目のシールドが、75%のサポートスロットにある場合）。カーソルを合わせると内訳が見られます。戦闘ステータスのシールドと速度のタイルにカーソルを合わせると、アイテムが順位順に並び、もう1つ付けたときの効果が分かります。飛行中の艦船ウィンドウでも、シールドバーと速度にカーソルを合わせると同じ一覧が表示されます。

### 2. シールドの吸収率（ダメージの配分） {#2-shield-absorbance-damage-split-}

吸収率とは、攻撃のうちシールドが受け持つ割合のことで、残りは HP に直接当たります。
- **シールドごと**：シールドの吸収率に、装着したシールドセルの吸収率を足した値です。シールド単体では**45～50%**（Light 45%、Basic 48%、Heavy 50%）で、セルは1個につき2～10ポイント加わります（Capacity Shield Cell I～IV は +2%、+3%、+4%、+5%、Absorption Shield Cell I～IV は +4%、+6%、+8%、+10%）。
- **平均吸収率**：艦の吸収率は、コア、サポート、補助の各スロットと、ドローンにあるシールドの単純平均です。アダプティブコアには固有の吸収率がなく、平均には含まれません（アダプティブコアに入れたセルが加えるのは、容量とリチャージだけです）。シールドを1つも装備していないと吸収率は0%になり、船体がすべての攻撃を受け、アダプティブコアのセルのシールドポイントも使われません。そのため、必ずシールドも一緒に装備しましょう。
- **そのままで得られる最高値は80%です**。最高のシールドに最高のセルを組み合わせた場合で、すべてのスロットに、Absorption Shield Cell IV を3個装着した Heavy Shield Core を入れたときです。弱いシールドを混ぜると、平均は下がります。シーズンストアのバフも鍛冶場のバフも、この数字には含まれません。
- **例**：Basic Shield Core（48%）に Absorption Shield Cell I を2個装着すると56%です。そこに Light Shield Core（45%）を加えると、平均は50.5%になります。
- **このステータスは100%で頭打ちにはなりません。**攻撃側の*シールド貫通*が引かれる前の、シールドが攻撃のうち受け持つ分を表すので、艦は1回の攻撃の全量より大きな値を持てます。112%なら、貫通が最大12%の攻撃者の攻撃でも、全量を受け止められます。

#### シールド貫通 {#shield-penetration}

一部の攻撃には**シールド貫通**があります。その攻撃に対して、あなたの吸収率から差し引かれるポイントです。シールドが受け持つ割合は次のとおりです。

\[\text{Shield Share} = \text{clamp}(\text{Absorbance} - \text{Penetration},\ 0,\ 100\%)\]

- シールドが受け持つのは、攻撃のうち最大 `round(damage x share)` で、残りは船体が受けます。シールドの残りが取り分に足りないときは、足りない分が HP に回り、シールドが0なら、すべてのダメージが HP に直接当たります。
- **シールド貫通の出どころ**：単体ロケットの*シールド貫通*（Lancet I 10%、Lancet II 25%、Lancet III 35%、Rivet I 5%、Rivet II 25%、Rivet III 35%、N.I.K.E. 35%。範囲爆発にはありません。[ロケット](/wiki/06-Items/Rockets.md)を参照）と、レーザー弾薬のシールド貫通（Ultra Core 5%、Experimental Fusion Core 10%。[レーザーと弾薬](/wiki/06-Items/Lasers.md)を参照）です。エイリアンにはなく、x1 と x2 の弾薬にもありません。レーザーの命中は、射手のレーザーの Penetration Amp（スロットごとに +2%～+8%、レーザー全体の平均）とドローン編成の貫通（Gemini +9%、Stiletto +16%）も差し引きます。合計はレーザーでは**50%**、ロケットでは40%で頭打ちです（[レーザーの命中の合計](/wiki/06-Items/Lasers.md#shield-penetration-of-a-laser-hit)）。
- **例**：吸収率80%で Lancet III（35%）を受けた場合、シールドが攻撃の45%を、船体が55%を受けます。100%の場合は、65%と35%です。112%で貫通12%の場合は、攻撃の全量を受け止めます。45%（Light Shield Core のみ）で35%を受けた場合は、10%がシールド、残りが船体に当たります。Light Shield Core を完全に貫通するロケットはありません。最強のレーザー（50%）は、それを成し遂げます。それに対して最高のシールド（80%）が受けるのは命中の30%、船体は70%で、Light Shield Core 単体（45%）は何も受けません。
- エイリアンには吸収率のステータスがなく、攻撃を80% / 20%に振り分けます（その攻撃の貫通ぶんは引かれます）。
- Siphon Battery のダメージはシールドだけから引かれ、吸収率も貫通も関係しません。

#### 100%に達する、超える {#reaching-and-passing-100-}

- **そのままの状態**：最大80%です（上を参照）。
- **Shield Absorbance Boost**：ワイプポイントで購入する、シーズンストアの永続バフです。**1レベルごとに+0.1ポイント、最大+10ポイント**（100レベル、1レベル25 WP）。艦の吸収率に固定のポイントを加えるもので、シールドを装備している艦なら、どの艦でも同じ値が加わります。4レベル（100 WP）で80%は80.4%に、12レベル（300 WP）で Light Shield Core の45%は46.2%になります。シールドを装備していない艦は0%のままです。100レベルには2,500 WP が必要で、何回かのワイプをかけて目指す目標です。現時点のワイプポイントの入手手段（撃破のマイルストーンとミッション）は、上限まで合わせて855 WP で、ワイプをまたいで持ち越すと34レベル、+3.4ポイントが買えます。ワイプポイントの入手手段は今後も増える予定です。[シーズンとワイプポイント](/wiki/03-Mechanics/Wipe-Timeline.md#cross-season-progression-permanent-buffs-)を参照してください。
- **鍛冶場**：シールドとシールドセルには、**吸収率**のバフが付くことがあり、このバフはステータスに掛け算で効きます。50%のシールドに+5%なら、+2.5ポイントです。永遠段階まで完全に鍛造した最高のセット（コア1個とセル3個、すべてのバフが最大値で、+15%）では、最大12ポイント、平均で約10ポイントが加わります（[鍛冶場](/wiki/06-Items/Forge.md)を参照）。
- **合計**：そのままで80%、バフで+3.4ポイント（現時点の855 WP をすべて使った場合）、鍛冶場のバフで最大+12ポイントを足すと、現時点では最大で**95.4%**になります。このバフの100レベルすべて（+10ポイント、2,500 WP）を使えば、102%になります。バフだけ、鍛冶場だけでは100%に届きません。そこに到達するのは何回かのワイプをかけて目指す目標で、ワイプポイントの入手手段は今後も増える予定です。

### シールドのブースト：容量、吸収率、リチャージ {#shield-boosts-capacity-absorbance-recharge}

シールド関連のブーストはどれも、3つのステータスのうち1つを上げ、ブースターウィンドウでは、それぞれの種類の下に表示されます。

- **容量**（最大シールドポイント）：Shield Wall Booster 1 と 2 のブースターと、永続の Shield Capacity Boost。
- **吸収率**（攻撃のうちシールドが受け持つ割合）：永続の Shield Absorbance Boost（1レベルごとに+0.1ポイント、最大+10ポイント）。
- **リチャージ**（毎秒回復するシールドポイント）：Shield Regen Booster。

数値は[ブースター](/wiki/06-Items/Boosters.md)を参照してください。

## シールドの自然回復 {#shield-passive-regeneration}

シールドは時間とともに自然に回復し、戦闘に備えた状態を保ちます。

- **回復のティック**：シールドが最大容量を下回っていると、毎秒、リチャージ速度に等しい量のシールドポイントが回復します。
- **戦闘による中断（15秒の待機）**：ダメージを受けると回復は止まり、**15秒間**ダメージを受けなかったあとにだけ再開します。ドローン編成の Adamant と Redoubt（[ドローン編成](/wiki/03-Mechanics/Formations.md)）は例外で、戦闘中でも毎秒シールドを回復します。
