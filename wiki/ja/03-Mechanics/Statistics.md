# 統計 {#statistics}

**統計**ページ（**コミュニティ › 統計**）は、あなたの記録です。今飛んでいるワイプで何をしたか、すべてのワイプを合わせて何をしたか、終わった各ワイプで何をしたか、そして**ログブック**には、パイロットに起きたことの日記が表示されます。セクションは上部のバーに並びます。**概要**、**ログブック**、**ランキング**、**殿堂**、**セクター情報**です。バーの右端のボタンで、そのセクションを再読み込みできます。

## 今回のワイプ、累計、過去のワイプ {#this-wipe-total-and-past-wipes}

概要、ランキング、セクター情報には、3つの選択肢を持つ切り替えがあります。

- **今回のワイプ**は、現在の[ワイプ](/wiki/03-Mechanics/Wipe-Timeline.md)が始まってからあなたがしたことです。ページはこれで開きます。
- **累計**は、プレイを始めてからすべてのワイプを合わせてあなたがしたことです。
- **過去のワイプ**は、終わったワイプの一覧で、新しいものが先頭です。1つ選ぶと、そのワイプで何をしたかが表示されます。

切り替えの横の1行は、どのワイプが進行中か、何日目か、いつ始まったかを示します。各タイルは2行目にもう一方の数字も表示します（ワイプの数字の下に**累計 61,200**、累計の下に**今回のワイプ +5,100**）。そのため、クリックの陰に隠れるものはありません。選択は記憶されます。3つのボタンが収まらない場合（狭いウィンドウ、言語によっては長い語）は、同じ3つの選択肢を持つメニューに変わります。

ゲームはワイプ用に別のカウンターを持ちません。各ワイプの開始時にあなたの数値をそのまま書き留め、**今回のワイプ**は現在の数値からその値を引いたものです。撃つ、飛ぶ、撃破するときに余分なものは何も書き込まれず、累計は決してリセットされないので、2つの数字は常に一致します。

| | 今回のワイプ | 累計 |
| :--- | :--- | :--- |
| **レベル** | 上がったレベル（**+2**、その下に**現在 レベル14**） | あなたのレベル |
| **経験値** | 獲得した経験値 | あなたの経験値 |
| **名誉** | 獲得した名誉（下記参照） | 現在の名誉 |
| **PvE・PvP ランキングポイント** | 現在持っているポイント | 現在持っているポイント。2行目には、あれば過去のワイプでの最高の結果が表示されます（**最高 21,300（ワイプ2）**） |
| **飛行距離**、**発射数** | このワイプで飛んだ距離と撃った数 | すべて |
| **ミッション** | このワイプで完了したミッション | 完了したすべて |
| **撃破**、**被撃破**、**弾薬の使用量** | 各行に2つの数字、**今回のワイプ**と**累計** | |

2つのポイントのタイルは、常に現在持っているポイントを表示します。ワイプでランキングポイントがどう再スタートするかは、[階級](/wiki/03-Mechanics/Ranks.md)と[ワイプのタイムライン](/wiki/03-Mechanics/Wipe-Timeline.md)に書かれています。

## 名誉 {#honor}

名誉は減ることがあります。味方への誤射で少し引かれ、企業を変えると半分になり、管理者が値を設定することもあります。**今回のワイプ**は、あなたが**獲得した**名誉だけを数えます。奪われた分は数字を表示する前に足し戻されるため、損失が獲得した分を隠すことはなく、誰かがより低い数値に設定した名誉は獲得とは数えられません。誤射で名誉を150失っても、獲得したものはすべて獲得したままです。**累計**の数字は、現在の名誉そのものです。

## 過去のワイプ {#past-wipes}

一覧からワイプを選ぶ（**ワイプ2（2026-10-01 – 2026-10-24）**）と、タイルと一覧にそのワイプでの行動が表示されます。その上の1行が結果を示します。企業内での順位、階級、PvE と PvP のポイントです。**このワイプのログブックを開く**でそのワイプのログブックが開き、**このワイプのセクター情報**でそのセクター表が表示されます。最初のワイプが終わるまで、ページはそう伝え、終わったときのためにあなたの結果を保管します。

- **日付から集計。** ワイプごとの統計は、ゲームのバージョン0.4.26で始まりました。そのときすでに進行中だったワイプでは、ゲームは開始時のあなたの数値を知ることができなかったため、サーバーが更新された日から（あればワイプ自身が残した記録から）集計し、ページにはその日**から集計**と表示されます。**ミッション**のタイルだけに印が付くこともあります。ゲームはワイプ開始時のすべての数値を知っていましたが、完了したミッションの数は知らなかったため、それはその日から数え、残りは正確です。
- **テストワイプ。** 管理者がテストサーバーで手動で実行したワイプには**（テストワイプ）**と表示されます。
- **結果は保管されます**。アカウントがある限り続きます。

## セクター情報 {#sector-intel}

セクター情報は、セクターごとに、飛行距離、撃った数、撃破したエイリアン、そこで撃破された回数を一覧にします。概要と同じ切り替えに従います。**累計**のセクター表は、あるセクターでこれまでにしたすべての撃破を数えるため、**今回のワイプ**の**撃破**一覧より多くの撃破を含みます。比較するには、両方を同じ選択にしてください。セクター内のエイリアン別の内訳はワイプには保存されません。過去のワイプでは、セクターの撃破は1つの数字で表示されます。

## ワイプごとの殿堂 {#the-hall-of-fame-by-wipe}

殿堂（このページとランキングのページ）は、各ワールドと全ワールド合計の、各ランキング（PvE と PvP）の上位50人のパイロットを一覧にします。ランキングとワールドの切り替えの横にある**ワイプ**メニューで一覧を選びます。**現在**、または終わったワイプ（**ワイプ2**、**ワイプ1** …）の、終了時点の一覧です。通算の PvE 一覧を持つサーバーでは**歴代**も選べます。過去のワイプの一覧は永久に保管されます。パイロットがアカウントを削除した場合も順位は残り、行には**削除されたパイロット**と表示されます。それ以外の行はパイロットのプロフィールを開きます。

## あなたのプロフィール {#your-profile}

ログイン中のパイロットなら誰でも開けるパイロットのプロフィールには、撃破のタイルの下に**このワイプで**エイリアンとパイロットを何体・何人撃破したかと、終わった各ワイプでの結果の帯が表示されます（**W2 #41 PvE · 大尉**：全パイロットの PvE 一覧での順位と階級）。プロフィールが過去のワイプについて示すのはこれだけです。被撃破、発射数、飛行距離、セクター、ワイプごとのプレイ時間、失った名誉は非公開で、あなただけが見られます。

## ログブック {#the-logbook}

ログブックは、あなたのパイロットの非公開の日記です。起きたことの一覧で、新しいものが先頭、あなたの言語で表示されます。**チャットのログではありません。チャットは記録されません。**

### 記録されるもの {#what-it-records}

各項目は6つのグループのどれかに属し、一覧の上のチップでグループごとに絞り込めます（複数同時に可。**すべて**で選択を解除。各チップには含まれる項目数が表示されます）。

- **戦闘**：撃破したエイリアン、自分が撃破されたこと（何に、または誰に）、撃破したパイロット、味方への誤射、ボスやガーディアンの初撃破。
- **経済**：ショップで買ったもの、加入したサブスクリプション、クラフト、鍛冶場、ブースター、オークション（売却、購入、落札）、ボーナスコード、友達招待。
- **採掘**：壊した小惑星と、集めた破片。
- **進行**：新しいレベル、新しい階級、完了したミッション、建設した Skylab モジュール、孵化した P.E.T.、購入した船やドローン編成。
- **報酬**：開けたコンテナ、デイリー報酬、使った特別アイテム、実績、称号、連携した Steam アカウント、シーズンの賞品、サポートからの贈り物。
- **システム**：ゲームに参加したこと、ログブックが始まったこと、ワイプがいつ始まりいつ終わったか、クランで起きたこと（加入、脱退、新しい役割）。

撃破と採掘は**プレイ1時間につき1つの項目にまとめられます**：**エイリアン143体を撃破：Seeker ×90、Phantasm ×40、Bulwark ×13**。項目をクリックすると、その1時間のクレジット、Thulium、経験値、名誉が展開されます（採掘では岩の種類別）。それ以外はすべて、1つの出来事につき1つの項目です。行に出てくる別のパイロット（あなたを撃破した相手）は番号として保存され、現在の名前で表示されます。そのアカウントがなくなっていれば、行には**あるパイロット**と表示されます。

### 項目の保存期間 {#how-long-entries-are-kept}

- **通常の項目**（撃破、採掘、購入、被撃破など）は**21日間**保存され、最大で新しい**400**件までです。
- **節目の項目**（新しいレベル、階級、完了したミッション、ワイプ、賞品など）は**1年（365日）**保存され、最大で新しい**500**件までです。

日記は、サーバーでログブックが有効になった日に始まります。それ以前のものは追加されず、最初の項目にはログブックが始まったことが書かれます。

### 誰が読めるか {#who-can-read-it}

あなただけです。ページを開くと、ゲームサーバーがあなたの代わりに日記を読み、ほかのパイロットがそれを要求することはできません。サポートがパイロットの日記を読めるのは、そのパイロットが助けを求めたときだけで、そのような閲覧はすべて、管理者が行うほかの操作と同じように記録されます。アカウントを削除すると、日記も一緒に削除されます。

### 読み方 {#reading-it}

- **ワイプ**は、項目を表示するワイプを選びます。現在のもの（ページはこれで開きます）、以前のもの、または**すべてのワイプ**です。一覧を横切る線は、ワイプがいつ始まりいつ終わったかを示します（**ワイプ3が始まりました**、**ワイプ2が終わりました · 企業内で41位でした**）。何もしなかったワイプでも表示されます。
- 検索ボックスと**検索**は、項目の種類と詳細を調べます。
- **ページをコピー**は、ページの行を1行に1項目ずつクリップボードに入れます。メッセージや表に貼り付けられるテキストです（時刻、グループ、文）。
- 一覧は1ページに15件を表示し、下にページボタンがあります。狭いウィンドウでは、各項目が小さなカードになります。

### ログブックが使えないとき {#when-the-logbook-is-not-available}

ログブックはゲームの隣にある独立した小さなサービスで、ゲームがそれを待つことはありません。起こりうることは2つで、どちらもゲームを止めません。

- **このサーバーではログブックが有効になっていません。** ページがそう表示します。そのようなサーバーでは何も記録されません。
- **ログブックに現在接続できません。** ページは1分後にもう一度試すよう案内します。項目は失われません。その間に起きたことはゲームが保持し、サービスが戻ったら送信します。非常に長い停止だけが、最も古い通常の項目を失う原因になりえます（節目の項目が先に保持されます）。

## よくある質問 {#questions}

**ワイプの後、私の撃破はどこへ行きましたか？** なくなっていません。ページは**今回のワイプ**で開き、新しいワイプごとにゼロから始まります。**累計**は、すべてのタイルと一覧で隣に表示されています。累計は決してリセットされません。

**なぜ今回のワイプの名誉は、名誉の増加分より大きいのですか？** **累計**は残高であり、奪われた名誉（味方への誤射、企業変更時の半減）がそれを減らしたからです。**今回のワイプ**は獲得した分を数える（[名誉](#honor)を参照）ので、大きい数字になります。

**なぜセクターの撃破が、撃破一覧より多いことがあるのですか？** **累計**のセクター表はすべてのワイプを合計し、撃破一覧は**今回のワイプ**を表示しているからです。両方を同じ選択にしてください。

**なぜワイプに「から集計」と日付が付いているのですか？** [過去のワイプ](#past-wipes)を参照してください。ワイプごとの統計はバージョン0.4.26で始まりました。

**ほかのパイロットは私のログブックを読めますか？** いいえ。[誰が読めるか](#who-can-read-it)を参照してください。

**なぜログブックは3週間より前にさかのぼれないのですか？** 通常の項目は21日間保存されます。1年分の節目の項目は残っています。**すべてのワイプ**と、**進行**または**システム**のチップを選んでください。

## 知っておくと便利なこと {#good-to-know}

- **過去のワイプ**の数値とワイプの殿堂は、そのワイプが終わったときに書き込まれ、その後は変わりません。
- バージョン0.4.26より前のサーバーの統計ページには、切り替えも過去のワイプもありません。そこでのログブックは、以前のバージョンの単純な表です。
- [階級](/wiki/03-Mechanics/Ranks.md)は、ランキングポイントと企業ランキングの仕組みを説明します。[ワイプのタイムライン](/wiki/03-Mechanics/Wipe-Timeline.md)は、ワイプが何を取り、何を残すかを説明します。
