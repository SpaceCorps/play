# サーバー {#servers}

<!-- wiki-search: servers; server; server list; regional server; regional servers; home server; region; helsinki; singapore; us east; north america; asia; europe; ping; latency; delay; lag; launch; dock; return to base; bring my ship home; unreachable; full; updating; maintenance; staff only; サーバー; サーバー一覧; 地域サーバー; ホームサーバー; リージョン; 北米; アジア; ヨーロッパ; 遅延; ラグ; 出撃; ドッキング; 基地に戻る; 機体をホームに戻す; 到達不可; 満員; 更新中; メンテナンス中; スタッフ専用 -->

SpaceCorps は3つのゲームサーバーで動いています。**Helsinki**（ヨーロッパ）、**Singapore**（アジア）、**US East**（北米）です。Helsinki は**ホームサーバー**で、あなたのアカウント、ステーション、機体、アイテム、報酬はそこにあります。Singapore と US East は**地域サーバー**です。そこから飛べば、ゲームに近い場所で、より短い遅延で遊べます。ドッキングすると、その飛行は Helsinki のホームに送られます。各サーバーにはそれぞれの空とパイロットがいて、ルール、エイリアン、群れ、シーズンの時計はどのサーバーでも同じです。

## 概要 {#at-a-glance}

| | Helsinki（ホームサーバー） | Singapore と US East（地域サーバー） |
| :--- | :--- | :--- |
| あなたのアカウント、ステーション、機体、アイテム、報酬 | ここ | Helsinki |
| 飛行、戦闘、採掘、ルート、ミッション | できる | できる |
| 出会うパイロット | Helsinki から飛んでいる人 | そのサーバーから飛んでいる人 |
| ハンガー、Skylab、アセンブリ、オークション、ショップ、クランページ、ギャラクシーゲート | いつもどおり | ステーションのもの：ウィンドウがそう表示し、**基地に戻る**を案内します |

## 地域サーバーからの飛行の流れ {#how-a-flight-goes}

1. **出撃。**リスト（[下](#choosing-a-server)）でサーバーを選び、出撃を押します。ホームサーバーがあなたを地域サーバーに送り、機体はその時点でステーションにあるとおりの状態でそこに現れます。
2. **飛行。**ほかの場所と同じように戦い、採掘し、ルートを集めます。稼いだものは、しばらくは地域サーバーに残ります。クレジット、Thulium、経験値、名誉、統計、ドローンとペットとパイロットスキルの経験値です。約**30秒**ごとに Helsinki のホームへ送られるので、何かあっても失うものは少なくて済みます。
3. **ドッキング。**ドッキングすると（**基地に戻る**、またはステーションへのドッキング）、飛行は終わり、残りの稼ぎがホームに送られて、あなたはステーションに戻ります。ランキングポイント、ランク、ランキングは Helsinki で計算されるので、飛行中ではなくドッキングしたときに動きます。

ゲームが閉じたり接続が切れたりした場合、地域サーバーはしばらくあなたを待ち、そのあと自分で飛行を終了して、ドッキングと同じようにホームへ送ります。何を所有しているかを知っているのは引き続きホームサーバーだけです。地域サーバーはあなたがしたことを報告するだけで、あなたに関するそれ以外のものは何も変わりません。

## サーバーを選ぶ {#choosing-a-server}

**サーバー**のリストは、サインイン画面と出撃シートにあります。各行には、サーバーの名前と地域（ヨーロッパ、アジア、北米）、その**Ping**（接続にかかる時間：小さいほど近い）、そこで**飛行中**の人数、**状態**が出ます。行をクリックして選ぶと、選択はこのコンピューターに記憶され、出撃はそこから飛びます。選んだサーバーが出撃時に開いていない場合は、代わりに Helsinki から飛び、ゲームがそのことを知らせます。地域サーバーは同時に60人のパイロットを受け入れます。

### 状態の表示 {#status-words}

| 状態 | 意味 |
| :--- | :--- |
| 稼働中 | そこから出撃できます |
| 満員 | 席がすべて埋まっています：少し待ってやり直すか、別のサーバーを選んでください |
| 更新中、更新作業中 | 更新が来ている間、サーバーはゲームの別のバージョンになっています：少し待ってください |
| ゲームを更新 | サーバーがあなたのゲームより新しいバージョンで動いています：ゲームを更新してください |
| 停止中 | サーバーがいま Helsinki に応答していません：あとでやり直してください |
| メンテナンス中 | いまはそこから誰も出撃できません：ワイプのカウントダウン中か、作業のためサーバーが止められています |
| スタッフ専用 | まだプレイヤーには開放されていません |
| 到達不可 | あなたのコンピューターから届きません：下を参照してください |

## サーバーに接続できないとき {#unreachable}

**到達不可**は、あなたのコンピューターがそのサーバーに接続できなかったという意味で、カッコ内の言葉（行のヒントと、出撃に失敗したときのメッセージ）がその理由を示します。名前が見つかりませんでした、時間内に応答がありませんでした、接続が拒否されました、安全な接続に失敗しました、のいずれかです。サーバーのアドレスをブロックするネットワークもあり、あるパイロットには届くのに別のパイロットには届かないこともあります。**その間は Helsinki から飛んでください**：失われるものはなく、ステーションもそこにあります。何度も起こる場合は、どのサーバーか、カッコ内の言葉、そしてプレイしている国を教えてください。何を直せばよいかがわかります。

サーバーには**予備の経路**、つまり同じサーバーの2つ目のアドレスがある場合もあります。あなたのコンピューターがサーバー本来のアドレスには接続できず、予備の経路には届くとき、その行は選択可能になり、Pingは予備の経路のものが表示され、ヒントには「予備の経路で接続しています。」と出て、出撃もその経路を通ります。自分で選ぶ必要はなく、ほかに変わることはありません。

## 機体をホームに戻す {#bring-my-ship-home}

地域サーバーから飛行している途中でゲームを閉じると、ステーションに戻ったときも機体がまだ飛行中のままのことがあります。その場合、ステーションに**機体はまだ別のサーバーで飛行中です**と表示され、**機体をホームに戻す**ボタンでその飛行を終えて機体を戻せるので、ステーションがまた使えるようになります。

## 更新とワイプ {#updates-and-the-wipe}

サーバーはまとめて更新されます。更新の前に地域サーバーは飛行をホームに送るよう求められ、別のバージョンになっている間はその行に「更新中」と表示されます。すべてのサーバーはホームサーバーのシーズンの時計に従います。[ワイプ](/wiki/03-Mechanics/Wipe-Timeline.md)の最後の5分間は、地域サーバーから誰も出撃できず（メンテナンス中）、30秒前には地域サーバーが全員をホームに送り、新しいシーズンのために空が作り直されたら再び開きます。

## あなたのデータ {#your-data}

地域サーバーから飛行している間は、あなたの機体、アイテム、財布のコピーが飛行のあいだそこに保持されます。メールアドレスとパスワードは含まれず、飛行がホームに送られたときに削除されます。
