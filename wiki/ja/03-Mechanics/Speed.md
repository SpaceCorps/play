# 速度の計算 {#speed-calculation}

速度は、艦がスペースマップ上でどれだけ速く動くかを決め、ターゲットを追いかけたり、戦闘から逃げたり、エリアを移動したりするのに役立ちます。

## 速度の計算式 {#the-speed-formula}

艦の最終的な速度は、サーバーで次の式を使って計算されます。

\[\text{Final Speed} = (\text{Ship Base Speed} + \text{Total Engine Speed}) \times (1.0 + \text{Total Speed Bonus Percent})\]

### 1. エンジンの実効速度 {#1-effective-engine-speed}

装備したエンジンはどれも速度を生み出し、スラスターを装着したアダプティブコアも同じです。エンジンにスラスターが装着されている場合は、そのエンジンの速度が変化します。

\[\text{Engine Speed} = (\text{Engine Base Speed} + \text{Thruster Flat Bonus}) \times \text{Thruster Multiplier}\]

- **スラスターの固定ボーナス**：スラスターによる固定の速度加算の合計です（例：Impulse Thruster III は速度 `+15`）。
- **スラスター倍率**：そのエンジンに装着したすべてのスラスターの速度倍率の積です（例：Momentum Thruster III は `1.09`、つまり `+9%`、Impulse Thruster III は `1.03`、つまり `+3%`）。エンジンが生み出すもの全体に掛かります。エンジン自身の基本速度にも、スラスターの固定ボーナスにも掛かります。アダプティブコアには自身の基本速度がありませんが、そのスラスターの固定ボーナスには同じように倍率が掛かります。

Engine III（基本速度 6）に Momentum Thruster IV（`+13.1`、`1.11`）を3基装着すると、(6 + 3 x 13.1) x 1.11 x 1.11 x 1.11 = 62.0 の速度になります。Impulse Thruster IV（`+16.5`、`1.035`）を3基装着すると (6 + 3 x 16.5) x 1.035 x 1.035 x 1.035 = 61.5 です。鍛冶場でスラスター倍率に付くボーナスは、1を超える部分を伸ばします。`1.11` に +15% のボーナスが付くと `1.1265` になります。

### 2. 逓減（限界効率） {#2-diminishing-returns-marginal-efficiency-}

パイロットがエンジンを際限なく重ねて無限の速度を得るのを防ぐため、**逓減（限界効率）**のカーブが適用されます。すべてのエンジンは、速度への貢献度の順に並べられ、順番に処理されます。アダプティブコア（ハイブリッド）とシールドコアも同じ方法で順位付けされ、種類ごとに別々のグループになります。そのため、エンジンとアダプティブコアの両方を搭載した艦には、それぞれに最初の4つがあります。

| エンジンの順位 | 効率倍率 |
| :---: | :--- |
| **1～4個目** | **100%**（1.0） |
| **5個目** | **85%**（0.85） |
| **6個目** | **70%**（0.70） |
| **7個目** | **55%**（0.55） |
| **8個目以降** | **25%**（0.25） |

さらに、エンジンの速度には、スロット効率（コア：100%、サポート：75%、補助：50%）が掛けられます。

### 3. 速度ボーナス率とシールドのペナルティ {#3-speed-bonus-percent-shield-penalties}

速度ボーナス率の合計は、装備したエンジン（とハイブリッド）の速度ボーナスをすべて足し、装備したシールドのペナルティを引いたものです。

- **エンジンの速度ボーナス**：エンジンは、プラスの速度の割合を加えます（例：Engine III は `+5%`）。
- **シールドの速度ペナルティ**：重いシールドは艦を重くし、マイナスの速度の割合を加えます（例：Heavy Shield Core は速度 `-5%`）。
- **スロットによる補正**：これらの割合のボーナスとペナルティにも、そのアイテムを装備したスロットの効率が掛けられます。ドローンに装着したシールドも、コアスロットのシールドと同じように艦を遅くします。
- **0を下回らない**：シールドをいくつ搭載しても、速度が0を下回ることはありません。
- **ドローン編成**：使用中の[ドローン編成](/wiki/03-Mechanics/Formations.md)は、最終速度をもう一度、独立した係数として変えます。Gyre +10%、Cordon −3%、Auger −9%、Culler −10%、Redoubt −11%、Rampart −17%です。Afterburner はその結果に倍率をかけます。
