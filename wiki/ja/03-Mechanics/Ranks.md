# 階級 {#ranks}

すべてのパイロットには**階級**があり、ジュニアパイロットからシニア提督まであります。3つのグレードを持つ8つの段階からなる軍隊式のはしごで、全部で24階級です。あなたの階級は、**自企業のパイロットの中での順位**で決まります。順位は **PvE ポイント**（レベル、経験値、倒したエイリアンから得られるポイント）で数えます。飛行中、ゲームはパイロット名の前に小さな**記号**だけを表示するので、企業のトップクラスのパイロットと新人が一目で分かります。言葉での表記は、企業ページと記号のツールチップにあります。

**1分でわかる**

- 企業は、パイロットを PvE ポイントの多い順に並べた1つのリストを持っています。あなたの階級は、そのリストでの順位で決まります。
- **シニア提督**になれるのは、企業で一番のパイロット1人だけです。ほかの全員は上から順に残りの23階級に振り分けられ、上位は少人数、下位は大人数です。
- どの階級にも**最低 PvE ポイント**が必要で、小さな企業や新しい企業が最上位の階級をただで配れないようになっています。シニア提督に必要なのは 20,000 ポイントです。
- 階級は動きます。ほかのパイロットに抜かれると下がり、抜くと上がります。下がったことは通知されません。新しい最高階級は通知されます。
- リストに載るのは、PvE ポイントがあり、過去30日以内に飛行したパイロットだけです。それ以外は、再び飛行するまでジュニアパイロットです。
- ワイプで誰のポイントも変わらないので、リストが最初からになることはありません。
- 名前の前の記号が階級です。形が段階を、1〜3個の印がグレードを表します。

## 階級の決まり方 {#the-company-ladder}

あなたの企業のパイロットは、**3つのワールドをまとめて**1列に並びます。先頭は PvE ポイントが最も多いパイロットです。ポイントが同じ場合は、レベルが高いほうが前、次に古参のパイロットが前です。この列が企業の**ランキング**で、あなたの階級は2つのことで決まります。

1. **順位。** 1位のパイロットは**シニア提督**で、1人だけです。その後ろのパイロットは、ランキングの割合に応じて残りの23階級に振り分けられ、各階級は1つ上の階級より4分の1多くのパイロットを抱えます。そのため、パイロットの約5分の1がジュニアパイロットで、上位10分の1が大尉以上になります。
2. **ポイント。** どの階級にも最低 PvE ポイントがあります（[下の表](#the-24-ranks)）。あなたの階級は、順位から決まる階級とポイントが届く階級の、低いほうです。

**例。** ランキングに31人のパイロットがいる企業を考えます。順位だけで決めると階級は次のようになります。右の列は、その階級に必要な最低 PvE ポイントです。

| 順位 | 階級 | 最低 PvE ポイント |
| :---: | :--- | ---: |
| 1 | シニア提督 | 20,000 |
| 2 | シニア少佐 | 4,700 |
| 3 | シニア大尉 | 3,000 |
| 4 | 大尉 | 2,600 |
| 5 | シニア中尉 | 1,900 |
| 6–7 | 中尉 | 1,500 |
| 8 | ジュニア中尉 | 1,300 |
| 9–10 | シニア軍曹 | 1,000 |
| 11–13 | 軍曹 | 800 |
| 14–16 | ジュニア軍曹 | 610 |
| 17–20 | シニアパイロット | 350 |
| 21–24 | パイロット | 150 |
| 25–31 | ジュニアパイロット | 0 |

あなたは31人中16位で、PvE ポイントは 1,800 です。企業ページには「31人中 16位」と、小さなタグ「上位 52%」が表示されます。企業の上位 52% に入っているという意味です。14位から16位はジュニア軍曹なので、それがあなたの階級です。ポイントだけなら中尉（1,500）に届いています。軍曹になるには13位まで上がる必要があります。13位は Sable で、PvE ポイントは 2,100 です。抜くには 2,101 必要で、あと301ポイントです。企業ページはそれをそのまま表示します。「Sable を抜いて 軍曹 になるまで PvE ポイント 301」。

上位でもポイントは関係します。この企業の1位のパイロットの PvE ポイントが 12,000 なら、20,000 に達するまではシニア将軍で、順位が何位でも同じです。

> [!NOTE]
> 階級は人数を整数で区切って決めるため、小さな企業には上位の階級に誰もいないことがあります。大佐にはランキングに少なくとも46人のパイロットがいる企業が必要で、将軍には118人、シニア将軍には178人、ジュニア提督には301人、提督には675人が必要です。1位だけは例外です。どの企業にも1位はあり、そのパイロットは PvE ポイントが 20,000 に達した時点でシニア提督になります。

## ランキングに載るパイロット {#who-is-on-the-ladder}

パイロットが自企業のランキングに載るのは、次の**3つすべて**に当てはまるときです。

- 企業に所属している。
- PvE ポイントがある。最初の撃破で新人もランキングに載ります。
- 過去**30日**以内に飛行した。

ランキングに載っていないパイロットは、階級が表示されるどの場所でも**ジュニアパイロット**になり、順位はなく、企業のリストにも載りません。この決まりは、ゲームを一度試して去ったパイロットがいつまでも最下位に居座らないように、また、不在のパイロットが最高階級を何か月も持ち続けないようにするためのものです。

> [!TIP]
> 不在の間に失うものはありません。ポイントは保たれ、再び出撃するか、企業ページを開くだけで、離れたときのポイントで改めて順位に入ります。1位だったなら再びシニア提督になり、その階級にいたパイロットは1つ順位が下がります。

企業を変えると、ポイントも一緒に移り、新しい企業のランキングで、そのポイントに応じた順位に入ります。

## 階級の動き {#your-rank-moves}

- ほかのパイロットに抜かれると**下がります**。抜かれるたびに順位が1つ下がり、それが階級の最後の順位だったなら、1グレード下がります。
- ほかのパイロットを抜くと**上がります**。撃破が数えられた時点で反映されます。
- パイロットがランキングに入ったり出たりしても動くことがあります。どの階級も企業の割合で決まるためです。企業が大きくなっても、順位を保っているパイロットが下がることはありません。パイロットが去ると、階級の境目にいるパイロットが1グレード下がることがあります。
- 階級が通知されるのは、**上がった**ときだけです（[昇進](#promotions)）。下がっても通知はなく、記号が変わるだけです。

## PvE ポイントの稼ぎ方 {#how-you-earn-pve-points}

PvE ポイントは、3つのものから計算されます。

**レベル × 100 + 経験値 ÷ 1,000（切り捨て）+ 倒した各エイリアンのポイント**

より手ごわいエイリアンほど価値が高く、撃破はそのエイリアンを倒すのに必要なダメージに応じてポイントを加えます。群れの船とクランのウォーデンも同じ規則で数えるので、Pirate Scout は Bulwark と同じ価値です。撃破はすべて、エイリアン自身の名前であなたの撃破統計に数えられます。

| エイリアンまたは船 | 撃破1回あたりの PvE ポイント |
| :--- | ---: |
| Seeker | 1 |
| Phantasm | 2 |
| Bulwark | 4 |
| Goombah | 7 |
| Crystalys | 16 |
| Boss Seeker | 5 |
| Seeker Slave | 1 |
| Pirate Boss | 15 |
| Pirate Scout | 4 |
| Dormant Force | 25 |
| Dormant Pulse | 11 |
| Brood Warden I, II, III | 14, 18, 35 |
| Siege Warden I, II, III | 13, 17, 32 |
| Wrath Warden I, II, III | 14, 18, 34 |
| Brood Drone I, II, III | 1, 1, 2 |
| Siege Escort I, II, III | 2, 3, 6 |
| Wrath Guard I, II, III | 2, 3, 6 |

最初の5行は通常のエイリアン、次の6行は3つの群れの船です。最後は、クランのウォーデン戦のリーダーであるウォーデンと、その乗員の Brood Drone、Siege Escort、Wrath Guard です。I、II、III はウォーデンの強さで、ポイントはその順に並んでいます。

たとえば、レベル4で経験値 12,500、Seeker を300体、Phantasm を80体、Bulwark を10体倒したパイロットのポイントは、400 + 12 + 300 + 160 + 40 = **912** です。これは軍曹の最低ポイント（800）を満たしますが、実際に軍曹かどうかは、企業内での順位で決まります。

**ランキング**ページ（コミュニティ › ランキング）では、自分のポイントの内訳が分かり、そこにある**殿堂**には最も優れたパイロットが並びます。そこの PvE ポイントの横にある **(i)** には、5種類のエイリアン、各[群れ](/wiki/05-Swarms/Swarms.md)の撃破で得られるポイント（最小の船からボスまで）、そして[クランのウォーデン](/wiki/03-Mechanics/Clans.md#clan-wardens)が載っています。

## 記号 {#the-symbols}

ゲームは階級を小さな記号として描きます。段階を表す**形**は段階ごとの色で、グレードを表す**1個、2個、3個の印**は、ジュニアが1個、無印が2個、シニアが3個です。段階が上がるにつれて、色は冷たく地味なものから、暖かく明るいものへ進みます。

| 段階 | 形 | 色 |
| :--- | :--- | :--- |
| パイロット | 点 | スチールブルー |
| 軍曹 | 重ねたシェブロン | 銅色 |
| 中尉 | 重ねた平らな棒 | 銀色 |
| 大尉 | ひし形 | 緑 |
| 少佐 | 上向きの三角形（ペナント） | シアン |
| 大佐 | 中が空いた輪 | 金色 |
| 将軍 | 五芒星 | オレンジ |
| 提督 | 1〜3個の星を囲む、上が開いた月桂樹の輪 | ローズ |

## どこで見られるか {#where-you-see-them}

飛行中に見えるのは**記号だけ**で、言葉は表示されません。記号はパイロットの名前の前にあります。

- 船の上の名前タグと、ターゲットウィンドウ
- チャットの、その行を書いたパイロットの名前の前
- グループのリストと、ミニマップ上のグループの仲間のツールチップ
- キルフィードの、名前が出るパイロットの前（エイリアンの前にはありません）
- 殿堂、ランキングウィンドウ、そしてパイロットのプロフィール（大きく表示）

**言葉**（ジュニア軍曹、大尉 …）は、企業ページとツールチップにあります。記号にポインターを合わせてください。記号は、そのパイロットが**自分の企業**のパイロットの中でどこにいるかを示します。別の企業の少佐は、その企業の中での少佐であって、あなたの企業の中ではありません。[企業パイロット](/wiki/03-Mechanics/Company-Pilots.md)はゲーム自身の部隊で、階級はありません。

## 企業ランキング {#the-company-ranking}

**経済 › 企業**を開きます。**企業ランキング**セクションには、上から順に次のものが表示されます。

- **あなたの階級**：記号と名前、順位（「31人中 16位」）、順位の割合を示す小さなタグ（「上位 52%」）。
- **バーとその下の1行**：次の階級に何が必要かを示します。「Sable を抜いて 軍曹 になるまで PvE ポイント 301」のような行は、次の階級の最後のパイロットを指します。そのパイロットを抜けば、その階級はあなたのものです。ポイントだけが足りないときは、あと何 PvE ポイント必要かが表示されます。シニア提督には「最高階級です。」と表示されます。
- **企業のトップパイロット**と、そのポイント。
- **すべての階級**：開くまで閉じています。24階級がピラミッド状に並び、各階級に、企業の割合の大きさに応じた幅のバーと、3つの列（**割合**、今その階級にいる**人数**、**最低ポイント**）が付きます。自分の階級は目印が付き、行のツールチップには「自社の上位 10.2% が 大尉 以上です。」と表示されます。表の下の1行は、ランキングの対象を説明しています。
- **リスト**：**3つのワールドをまとめた自企業の上位50人のパイロット**。順位、記号、名前、PvE ポイントが並びます。自分の行は目印が付きます。

- PvE ポイントがまだないパイロットは、ランキングにもリストにも載りません。エイリアンを1体倒すと載ります。30日間不在だったパイロットも、再び出撃するか、ページを開くまで載りません。
- 表示されるのは、名前と公開された数字だけです。

## 昇進 {#promotions}

- 新しい最高階級に達すると、通知（「昇進: シニア軍曹」）と、短く控えめな音が出ます。「最高」とは、前回出撃してから知らされた中で最高の階級のことです。1グレード下がって取り戻した場合、2回目のメッセージはありません。不在の間に上がった階級は、次のログイン時に1回だけ知らされます。下がったことは知らされません。
- **ジュニア少佐**以上への昇進は、あなたのワールドで飛行している自企業のパイロットに向けて、チャットの**システム**タブにも表示されます。「Nova が ジュニア少佐 に昇進しました。」企業に伝わるのは、あなた自身の PvE ポイントで上がったときだけです。ほかのパイロットがランキングから抜けたために上がった場合は、あなたに通知が出るだけで、ほかの誰にも知らされません。

## 階級とワイプ {#ranks-and-the-wipe}

ワイプは誰のポイントも変えません。レベル、経験値、撃破統計は残り（[ワイプのタイムライン](/wiki/03-Mechanics/Wipe-Timeline.md#cross-season-progression-permanent-buffs-)）、PvE ポイントはそれらから計算されるので、ワイプのあとも企業のランキングは同じ順番です。ただし、階級はもう一生ものではありません。階級は順位に従うので、企業のパイロットの動きとともに動き、30日間不在だったパイロットは、再び飛行するまでランキングから外れます。

## どのくらいかかるか {#how-long-it-takes}

これは、パイロットがどれくらいの速さで狩りをするかのモデルによる**見積もり**で、測定ではありません。最低ポイントは難しい部分ではありません。1日2時間ほど、1シーズンで58時間狩りをするパイロットは、1シーズンで約 21,200 PvE ポイントになり、シニア提督が求める数さえ上回ります。狩りの時間で言うと、パイロットの最低ポイントは最初の1時間以内、軍曹は4時間、大尉は約9時間、少佐は14時間、大佐は22時間、将軍は32時間、提督は48時間、シニア提督は55時間です。

階級を決めるのは順位であり、ほかのパイロットも狩りをしています。31人の企業では、ほかの人のポイントがいくつあっても、大尉以上になれるのは上位4人だけです。最低ポイントは、新しい企業が最上位の階級を配ってしまうのを防ぎ、順位は、古い企業の頂点を小さく保ちます。
