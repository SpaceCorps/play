# 階級 {#ranks}

すべてのパイロットには**階級**があり、ジュニアパイロットからシニア提督まであります。3つのグレードを持つ8つの段階からなる軍隊式のはしごで、全部で24階級です。あなたの階級は **PvE ポイント**で決まります。レベル、経験値、倒したエイリアンから得られるポイントです。どの階級にも**最低ポイント**が必要で、上位6つの階級には、企業ごとの固定の**枠**もあります。飛行中、ゲームはパイロット名の前に小さな**記号**だけを表示するので、企業のトップクラスのパイロットと新人が一目で分かり、サーバー全体でただ1人のパイロットは、記号の上に金色の**王冠**を着けます。言葉での表記は、企業ページと記号のツールチップにあります。

**1分でわかる**

- 企業は、パイロットを PvE ポイントの多い順に並べた1つのリストを持っています。リストは企業ごとに別々で、ほかの企業のパイロットがあなたと競うことはありません。
- あなたの階級は、**ポイントが最低ポイントに届いていて、しかも企業にまだ空き枠がある階級のうち、いちばん高いもの**です。
- 上位6階級には、企業ごとの枠があります。**シニア提督 1枠**（PvE ポイント50,000から）、**提督 2枠**（45,000から）、**ジュニア提督 4枠**（40,000から）、**シニア将軍 8枠**（30,000から）、**将軍 10枠**（27,500から）、**ジュニア将軍 15枠**（25,000から）です。それより下の階級に人数制限はなく、それぞれ1つ上の階級より2,500ポイント少なく、ジュニア大尉の2,500ポイントまで下がります。
- **同じポイントなら同じ階級。**同じポイントのパイロットが違う階級になることはありません。階級の最後の枠が同点の途中に落ちる場合は、同点のパイロット全員が上のほうの階級になり、枠を超えることもあります。
- リストに載るのは、PvE ポイントがあり、直近30日以内に飛行したパイロットだけです。それ以外の人は、また飛行するまでジュニアパイロットで、枠は持ちません。
- 記号の上の金色の**王冠**は、サーバー全体（すべての企業、3つのワールド）で PvE ポイントが最も多いパイロットを示します。
- 階級は動きます。シニア大佐までは自分のポイントだけで決まるので、上がる一方です。上位6階級は企業のほかのパイロットにも左右され、ほかの人があなたの上の枠を取ると下がることがあります。下がったことは通知されません。新しい最高階級は通知されます。
- ワイプは誰のポイントも変えないので、リストが最初からやり直しになることはありません。
- 名前の前の記号が階級です。ティアは形、グレードは1つから3つの印で表します。

## 階級の決まり方 {#the-company-ladder}

あなたの企業のパイロットは、**3つのワールドをまとめて**1列に並びます。先頭は PvE ポイントが最も多いパイロットです。この列が**ランキング**です。ポイントが同じ場合は、レベルが高いほうが前、次に古参のパイロットが前になりますが、それはリストの並び順を決めるだけで、違う階級になることはありません。あなたの階級は、ポイントと企業の枠の2つで決まります。

1. **どの階級にも最低ポイントがあります**（[下の表](#the-24-ranks)）。ポイントが最低ポイントに届いていない階級になることはありません。
2. **上位6階級には枠があります。**枠は、いちばん高い階級から順に上から埋まります。50,000ポイントに届いたパイロットのうち上位の人がシニア提督になり（1枠まで）、残りのパイロットのうち45,000に届いた上位の人が提督になり（2枠まで）、以下ジュニア将軍まで同じように続きます。
3. **それ以外の人は、その6階級より下で、ポイントが届くいちばん高い階級になります。**それは最高でもシニア大佐です。階級の最低ポイントに届いても枠が埋まっている場合は、自分に空いている最も高い階級に下がります。
4. **同点が分けられることはありません。**同じポイントのパイロットは同じ階級です。階級の最後の枠が同点の途中に落ちる場合は、同点の全員が上のほうの階級になるので、階級は枠より多い人数を抱えることはあっても、本来より少なくなることはありません。

**例。**ある企業の上位12人のパイロットと、それぞれの階級です。

| 順位 | PvE ポイント | 階級 |
| :---: | ---: | :--- |
| 1 | 60,000 | シニア提督 |
| 2 | 52,000 | 提督 |
| 3 | 51,000 | 提督 |
| 4 | 50,500 | ジュニア提督 |
| 5 | 44,000 | ジュニア提督 |
| 6 | 30,000 | シニア将軍 |
| 7 | 29,000 | 将軍 |
| 8 | 28,000 | 将軍 |
| 9 | 26,000 | ジュニア将軍 |
| 10 | 24,999 | シニア大佐 |
| 11 | 21,000 | 大佐 |
| 12 | 1,000 | シニア軍曹 |

4位は50,500ポイントで、シニア提督の最低ポイントには届いていますが、シニア提督の1枠と提督の2枠が埋まっているので、ジュニア提督です。7位と8位は29,000と28,000で、どちらも将軍の27,500に届き、シニア将軍の30,000には届いておらず、将軍にはまだ枠があるので、どちらも将軍です。24,999ポイントのパイロットはジュニア将軍にあと1ポイント足りず、自分に空いている最高の階級であるシニア大佐です。もし最上位の2人がどちらも60,000なら、2人ともシニア提督で、次の2人（50,000と45,000）が提督の2枠になります。

> [!NOTE]
> 枠が効くのは、ある企業で最低ポイントに届くパイロットが、その階級の枠より多くなったときだけです。小さな企業では、階級は単にポイントで決まります。企業に1人だけのパイロットは、21,000 PvE ポイントなら大佐、50,000ならシニア提督です。

## ランキングに載るパイロット {#who-is-on-the-ladder}

パイロットが自企業のランキングに載るのは、次の**3つすべて**に当てはまるときです。

- 企業に所属している。
- PvE ポイントがある。最初の撃破で新人もランキングに載ります。
- 過去**30日**以内に飛行した。

ランキングに載っていないパイロットは、階級が表示される場所ではどこでも**ジュニアパイロット**で、枠を持たず、企業のリストにも載りません。このルールがあるのは、一度ゲームを試して去ったパイロットがいつまでも最下位に居座らないようにするためと、不在のパイロットが数か月にわたって数少ない上位の枠や王冠を持ち続けられないようにするためです。

> [!TIP]
> 不在のあいだ、何も失われません。ポイントはそのまま残り、再び出撃するか、企業ページを開くだけで、去ったときのポイントで、そのときのポイントと企業の枠が与える階級に、あらためて配置されます。

企業を変更すると、ポイントは引き継がれ、新しい企業のランキングに、そこでの枠が与える階級で入ります。

## 階級の動き {#your-rank-moves}

- **シニア大佐まではポイントだけで決まります。**次の最低ポイントにポイントが届くと、撃破がカウントされ次第、階級が上がり、ほかのパイロットがそれを下げることはできません。
- **上位6階級は、企業のほかのパイロットに左右されます。**自分より先に最低ポイントに届いたパイロットは枠を1つ取り、自分の階級の枠が埋まると、自分に空いている次の階級に下がります。パイロットがランキングや企業から抜けると枠が1つ空き、その後ろのパイロットが上がれます。
- 自分と同じポイントか、それより少ないポイントのパイロットが、自分の枠を奪うことはありません。
- 階級が**上がった**ときだけ、本人に通知されます（[昇進](#promotions)）。下がったことは通知されません。記号が変わるだけです。

## PvE ポイントの稼ぎ方 {#how-you-earn-pve-points}

PvE ポイントは、3つのものから計算されます。

**レベル × 100 + 経験値 ÷ 1,000（切り捨て）+ 倒した各エイリアンのポイント**

より手ごわいエイリアンほど価値が高く、撃破はそのエイリアンを倒すのに必要なダメージに応じてポイントを加えます。群れの船とクランのウォーデンも同じ規則で数えるので、Pirate Scout は Bulwark と同じ価値です。撃破はすべて、エイリアン自身の名前であなたの撃破統計に数えられます。

| エイリアンまたは船 | 撃破1回あたりの PvE ポイント |
| :--- | ---: |
| Seeker | 1 |
| Phantasm | 2 |
| Bulwark | 4 |
| Goombah | 7 |
| Crystalys | 16 |
| Boss Seeker | 5 |
| Seeker Slave | 1 |
| Pirate Boss | 15 |
| Pirate Scout | 4 |
| Dormant Force | 25 |
| Dormant Pulse | 11 |
| Brood Warden I, II, III | 14, 18, 35 |
| Siege Warden I, II, III | 13, 17, 32 |
| Wrath Warden I, II, III | 14, 18, 34 |
| Brood Drone I, II, III | 1, 1, 2 |
| Siege Escort I, II, III | 2, 3, 6 |
| Wrath Guard I, II, III | 2, 3, 6 |

最初の5行は通常のエイリアン、次の6行は3つの群れの船です。最後は、クランのウォーデン戦のリーダーであるウォーデンと、その乗員の Brood Drone、Siege Escort、Wrath Guard です。I、II、III はウォーデンの強さで、ポイントはその順に並んでいます。

たとえば、レベル4で経験値12,500のパイロットが、Seeker 300体、Phantasm 80体、Bulwark 10体を倒していれば、400 + 12 + 300 + 160 + 40 = **912**ポイントです。これで軍曹になります。最低ポイントは800で、次の階級シニア軍曹は1,000を必要とします。シニア大佐まではポイントだけがものを言います。

**ランキング**ページ（コミュニティ › ランキング）では、自分のポイントの内訳が分かり、そこにある**殿堂**には最も優れたパイロットが並びます。そこの PvE ポイントの横にある **(i)** には、5種類のエイリアン、各[群れ](/wiki/05-Swarms/Swarms.md)の撃破で得られるポイント（最小の船からボスまで）、そして[クランのウォーデン](/wiki/03-Mechanics/Clans.md#clan-wardens)が載っています。

ゲームは階級を小さな記号として描きます。段階を表す**形**は段階ごとの色で、グレードを表す**1個、2個、3個の印**は、ジュニアが1個、無印が2個、シニアが3個です。段階が上がるにつれて、色は冷たく地味なものから、暖かく明るいものへ進みます。

| 軍曹 | 重ねたシェブロン | 銅色 |
| 中尉 | 重ねた平らな棒 | 銀色 |
| 大尉 | ひし形 | 緑 |

| 提督 | 1〜3個の星を囲む、上が開いた月桂樹の輪 | ローズ |

## 王冠 {#the-crown}

**サーバー全体で PvE ポイントが最も多い**パイロットは、自分の階級の記号の上に小さな金色の**王冠**を着けます。「サーバー全体」とは、すべての企業と3つのワールドのことで、自分の企業だけではありません。サーバーに王冠は1つで、各企業のいちばん上のパイロットは、それぞれ自分の企業の階級を持ち続けます。最上位でちょうど同じポイントのパイロットが複数いれば、全員が着けます。

着けられるのは、ランキングに載っているパイロットだけです。30日間不在のパイロットは、ポイントがいくら多くても着けられません。王冠は、ランキングに載っているパイロットのうち最も多い人に移り、本人が再び飛行して首位に戻れば、取り戻せます。王冠が移っても誰にも通知はなく、見れば分かります。階級ではなく、何も与えません。王冠付きの記号にポインターを置くと、ツールチップに「サーバー最高の PvE パイロット」と出ます。

## どこで見られるか {#where-you-see-them}

飛行中に見えるのは**記号だけ**で、言葉は表示されません。記号はパイロットの名前の前にあり、王冠はその上に、次のすべての場所で表示されます。

- 船の上の名前タグと、ターゲットウィンドウ
- チャットの、その行を書いたパイロットの名前の前
- グループのリストと、ミニマップ上のグループの仲間のツールチップ
- キルフィードの、名前が出るパイロットの前（エイリアンの前にはありません）
- 殿堂、ランキングウィンドウ、そしてパイロットのプロフィール（大きく表示）
- 企業ページ：自分の階級、上位パイロットのリスト、すべての階級の表。

**言葉**（ジュニア軍曹、大尉 …）は、企業ページとツールチップにあります。記号にポインターを合わせてください。記号は、そのパイロットが**自分の企業**のパイロットの中でどこにいるかを示します。別の企業の少佐は、その企業の中での少佐であって、あなたの企業の中ではありません。[企業パイロット](/wiki/03-Mechanics/Company-Pilots.md)はゲーム自身の部隊で、階級はありません。

## 企業ランキング {#the-company-ranking}

**経済 › 企業**を開きます。**企業ランキング**セクションには、上から順に次のものが表示されます。

- **あなたの階級**：記号（王冠があなたのものなら王冠付き）と名前、順位（「31人中 16位」）、パーセンタイルの小さなタグ（「上位 52%」）。
- **バーと、その下の1行**：次の階級に必要なものを示します。「ジュニア将軍 まで PvE ポイント 2,500」のような行は、次の階級の最低ポイントまであと何 PvE ポイント必要かを示します。次の階級に空き枠がないときは、最後の枠を持つパイロットの名前が出ます：「Sable を抜いて ジュニア将軍 になるまで PvE ポイント 3,100」。同じポイントは同じ階級なので、そのパイロットと同じポイントに届けば十分です。シニア提督には「最高階級です。」と出ます。
- 企業の**トップパイロット**とそのポイント。
- **すべての階級**：開くまでは閉じています。24階級が高い順に並び、企業ごとの**定員**（ダッシュは人数制限なし）、いま各階級にいる**人数**（人数がいちばん多い階級と同じ幅のバー付き）、**最低ポイント**が表示されます。自分の階級には印が付き、行のツールチップには「シニア提督：1 企業あたり 1 枠、50,000 PvE ポイントから。」と出ます。表の下の1行は、誰がランキングに載るかを示します。
- **リスト**：3つのワールドをまたいだ、企業の上位**50人のパイロット**。順位、記号、名前、PvE ポイントが載ります。自分の行には印が付きます。

- PvE ポイントがまだないパイロットは、ランキングにもリストにも載りません。エイリアンを1体倒すと載ります。30日間不在だったパイロットも、再び出撃するか、ページを開くまで載りません。
- 表示されるのは、名前と公開された数字だけです。

## 昇進 {#promotions}

- 新しい最高階級に達すると、通知（「昇進: シニア軍曹」）と、短く控えめな音が出ます。「最高」とは、前回出撃してから知らされた中で最高の階級のことです。1グレード下がって取り戻した場合、2回目のメッセージはありません。不在の間に上がった階級は、次のログイン時に1回だけ知らされます。下がったことは知らされません。
- **ジュニア少佐**以上への昇進は、あなたのワールドで飛行している自企業のパイロットに向けて、チャットの**システム**タブにも表示されます。「Nova が ジュニア少佐 に昇進しました。」企業に伝わるのは、あなた自身の PvE ポイントで上がったときだけです。ほかのパイロットがランキングから抜けたために上がった場合は、あなたに通知が出るだけで、ほかの誰にも知らされません。

## 階級とワイプ {#ranks-and-the-wipe}

ワイプは誰のポイントも変えません。レベル、経験値、撃破の統計は残り（[ワイプのタイムライン](/wiki/03-Mechanics/Wipe-Timeline.md#cross-season-progression-permanent-buffs-)）、PvE ポイントはそこから計算されるので、企業のランキングはワイプのあとも同じ順序のままで、階級も王冠もそのままです。ただし、階級は一生ものではありません。上位6階級は企業のほかのパイロットに左右され、30日間不在のパイロットは、また飛行するまでランキングから外れます。

## どのくらいかかるか {#how-long-it-takes}

これは、パイロットの狩りの速さを表すモデルからの**見積もり**で、実測ではありません。1日に約2時間、1シーズンで58時間狩りをするパイロットは、1シーズンで約21,200 PvE ポイントになり、大佐です。狩りの時間で言うと、パイロットの最低ポイントは最初の1時間以内、軍曹は4時間、大尉は18時間、少佐は38時間、大佐は55時間、ジュニア将軍は67時間、将軍は73時間、シニア将軍は78時間、ジュニア提督は101時間、提督は113時間、シニア提督は124時間で届きます。

つまり、典型的なアクティブなパイロットは、2シーズン目に枠のある階級に届きます。枠を取れるかどうかは、同じく狩りをする企業のほかのパイロット次第です。階級の枠が効くのは、その最低ポイントに届くパイロットが枠より多くなったときだけで、それまでは階級は単にあなたのポイントで決まります。
