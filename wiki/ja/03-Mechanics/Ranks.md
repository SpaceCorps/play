# 階級 {#ranks}

すべてのパイロットには**階級**があり、ジュニアパイロットからシニア提督まであります。3つのグレードを持つ8つの段階からなる軍隊式のはしごで、全部で24階級です。登るには**PvE ポイント**を使います。レベル、経験値、倒したエイリアンから得られるポイントです。飛行中、ゲームはパイロット名の前に小さな**記号**だけを表示するので、新人とベテランが一目で分かります。言葉での表記は、企業ページと記号のツールチップにあります。

**1分でわかる**

- 階級は PvE ポイントに従います。狩りをして、レベルを上げれば、階級は上がっていきます。
- 24階級あります。パイロット、軍曹、中尉、大尉、少佐、大佐、将軍、提督が、それぞれジュニア、無印、シニアの3段階です。
- 名前の前の記号が階級です。形が段階を、1〜3個の印がグレードを表します。
- 階級は**一生もの**です。ワイプはレベル、経験値、撃破統計を残すので、ポイントも階級も残ります。
- 企業ページには、あなたのワールドにいる自企業の上位50人のパイロットが並び、次の階級まであとどれくらいかが分かります。

## PvE ポイントの稼ぎ方 {#how-you-earn-pve-points}

PvE ポイントは、3つのものから計算されます。

**レベル × 100 + 経験値 ÷ 1,000（切り捨て）+ 倒した各エイリアンのポイント**

より手ごわいエイリアンほど価値が高く、撃破はそのエイリアンを倒すのに必要なダメージに応じてポイントを加えます。群れの船とクランのウォーデンには、独自のポイントがあります。撃破はすべて、エイリアン自身の名前であなたの撃破統計に数えられます。

| エイリアンまたは船 | 撃破1回あたりの PvE ポイント |
| :--- | ---: |
| Seeker | 1 |
| Phantasm | 2 |
| Bulwark | 4 |
| Goombah | 7 |
| Crystalys | 16 |
| Boss Seeker | 5 |
| Seeker Slave | 1 |
| Pirate Boss | 10 |
| Pirate Scout | 1 |
| Dormant Force | 25 |
| Dormant Pulse | 10 |
| ウォーデン I、II、III のリーダー | 10, 15, 25 |
| Brood Drone、Siege Escort、Wrath Guard（どの強さも） | 1 |

たとえば、レベル4で経験値12,500のパイロットが、Seeker 300体、Phantasm 80体、Bulwark 10体を倒したなら、400 + 12 + 300 + 160 + 40 = **912**ポイントで、ジュニア軍曹です。

**ランキング**ページ（コミュニティ › ランキング）では、自分のポイントの内訳が分かり、そこにある**殿堂**には最も優れたパイロットが並びます。[群れ](/wiki/05-Swarms/Swarms.md)の船と[クランのウォーデン](/wiki/03-Mechanics/Clans.md#clan-wardens)も表に載っています。

## 記号 {#the-symbols}

ゲームは階級を小さな記号として描きます。段階を表す**形**は段階ごとの色で、グレードを表す**1個、2個、3個の印**は、ジュニアが1個、無印が2個、シニアが3個です。段階が上がるにつれて、色は冷たく地味なものから、暖かく明るいものへ進みます。

| 段階 | 形 | 色 |
| :--- | :--- | :--- |
| パイロット | 点 | スチールブルー |
| 軍曹 | 重ねたシェブロン | 銅色 |
| 中尉 | 重ねた平らな棒 | 銀色 |
| 大尉 | ひし形 | 緑 |
| 少佐 | 上向きの三角形（ペナント） | シアン |
| 大佐 | 中が空いた輪 | 金色 |
| 将軍 | 五芒星 | オレンジ |
| 提督 | 1〜3個の星を囲む、上が開いた月桂樹の輪 | ローズ |

## どこで見られるか {#where-you-see-them}

飛行中に見えるのは**記号だけ**で、言葉は表示されません。記号はパイロットの名前の前にあります。

- 船の上の名前タグと、ターゲットウィンドウ
- チャットの、その行を書いたパイロットの名前の前
- グループのリストと、ミニマップ上のグループの仲間のツールチップ
- キルフィードの、名前が出るパイロットの前（エイリアンの前にはありません）
- 殿堂、ランキングウィンドウ、そしてパイロットのプロフィール（大きく表示）

**言葉**（ジュニア軍曹、大尉 …）は、企業ページとツールチップにあります。記号にポインターを合わせてください。[企業パイロット](/wiki/03-Mechanics/Company-Pilots.md)はゲーム自身の部隊で、階級はありません。

## 企業ランキング {#the-company-ranking}

**経済 › 企業**を開きます。**企業ランキング**セクションには、**あなたのワールドにいる自企業の上位50人のパイロット**が PvE ポイント順に並びます。順位、記号、名前、ポイントです。リストの上には、自分の階級、自分の順位（「41人中 3位」のように）、そして次の階級まであと何 PvE ポイント必要かを示すバーがあります。**すべての階級**は、上の表と同じ24階級の表を開きます。

- PvE ポイントがまだないパイロットは載りません。エイリアンを1体倒すと、リストに載ります。
- リストは**あなたのワールド**のものです。別のワールドで遊ぶ自企業のパイロットは、そのワールドのリストに載ります。
- 表示されるのは、名前と公開された数字だけです。

## 昇進 {#promotions}

- 新しい階級に達すると、通知（「昇進: シニア軍曹」）と、短く控えめな音が出ます。離れている間に上がった階級は、次のログイン時に1回だけ知らされます。
- **ジュニア少佐**以上への昇進は、あなたのワールドで飛行している自企業のパイロットに向けて、チャットの**システム**タブにも表示されます。「Nova が ジュニア少佐 に昇進しました。」

## 階級とワイプ {#ranks-and-the-wipe}

ワイプは、ここでは何も変えません。レベル、経験値、撃破統計は残り（[ワイプのタイムライン](/wiki/03-Mechanics/Wipe-Timeline.md#cross-season-progression-permanent-buffs-)）、PvE ポイントはそれらから計算されるので、ポイントも階級もすべてのワイプをまたいで残ります。階級は一生ものです。

## どのくらいかかるか {#how-long-it-takes}

これは、パイロットがどれくらいの速さで狩りをするかのモデルによる**見積もり**で、測定ではありません。2つ目の階級は狩りの最初の1時間以内に、軍曹は5時間以内に来ます。1日2時間ほど狩りをするパイロットは、最初のシーズンを大尉かシニア大尉で終えます。少佐には1〜2シーズン、大佐には2〜5シーズン、将軍には6〜11シーズンかかります。最後の3階級には880時間を超える狩り（1日2時間で15シーズン分）が必要で、最後の1つには1,700時間を超える狩りが必要です。ごく一握りの最強のパイロットのためのものです。
