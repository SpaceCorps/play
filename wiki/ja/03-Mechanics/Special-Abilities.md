# 特殊能力 {#special-abilities}

<!-- wiki-search: special ability; special abilities; ability; abilities; mob; mobs; regenerate; mending; shield burst; hardened plating; plating; enrage; call reinforcements; reinforcements; clones; decoy; flee and return; flee; life drain; nova pulse; nova; rocket barrage; barrage; veil; sow mines; mines; split; fragments; boss steps; ladder; three steps; warning; tell; surprise; warlord; warden; leader; 特殊能力; 再生; シールドバースト; 装甲硬化; 激昂; 増援要請; 分身; 離脱と帰還; ライフドレイン; ノヴァパルス; ロケット斉射; ベール; 機雷散布 -->

一部のエイリアンは**特殊能力**を持っています。船体が半分になったとき、一生に一度だけ使う技です。再生、シールドの爆発、逃走、助けを呼ぶこと。始まるまでは何も見えないので、どの狩りも不意打ちで終わるかもしれません。このページでは、各能力が何をするか、どう対処するかを説明します。ボスは違います。船体が減るにつれて、三つの段階で戦い方を変えます。また、最後のティアの小型エイリアンは、速く倒しすぎると破片に分かれることがあります。

## しくみ {#how-it-works}

<!-- mob-rules:begin -->
<!-- Generated from server/Resources/MobAbilities.json (and the client's locales/<language>/mobs.toml) by scripts/mob-abilities-wiki.sh: don't edit by hand. -->

- **一度だけ。** 能力を持つエイリアンは、一生に一度だけそれを使います。戦闘中に船体(シールドではなく)が最大値の50%を下回ったときです。この線より上から一撃で破壊された場合は発動せず、戦闘中でないエイリアンは戦闘が始まるまで待ちます。
- **まず予告。** 能力は予告から始まります。船に向かって閉じていくリングと、その上に出る言葉です。下の項目に「すぐに始まります」とある能力には、予告がありません。予告の間はまだ破壊でき、その場合は何も起きず、通常どおり報酬が支払われます。軽量種(Seeker と Phantasm)は動きが速く、予告も効果も通常の50%の長さです。
- **事前には何も見えません。** 能力を持つエイリアンは、予告が始まるまで、細部まで他のエイリアンと同じに見えます。ゲーム内のどこにも、どれがそうなのかは示されません。[旅人のガイド](/wiki/03-Mechanics/Travelers-Guide.md)でも同じです。
- **誰が持つか。** 企業セクターとデンジャーセクターのエイリアンのごく一部です。ティアが強いほど割合が大きくなり、群れのリーダー(Pirate Boss, Boss Seeker, Boss Phantasm, Boss Goombah と Boss Crystalys)は他より持ちやすくなっています。Deep Void、クランのダンジョン、ソロゲートのエイリアンは決して持たず、群れの手下、Warden のウェーブ、Dormant Force、Tesseract も持ちません。
- **報酬は他のエイリアンと同じ。** 能力を使うエイリアンは、使わないエイリアンとまったく同じように報酬を払い、ドロップし、カウントされます。能力は撃破に何も加えず、時間だけを奪います。撃破は権利を持っていたパイロットのものです。エイリアンが逃げたり、再生したり、隠れたりしている間も、権利は失効しません。
- **呼ばれた艦と分身は撃破になりません。** エイリアンが呼ぶ艦と作る分身は、報酬もドロップもなく、クエスト、統計、ランキングにも数えられません。呼んだ側ごとに最大6、一つのマップで最大24まで存在でき、マップ本来のエイリアンは変わらず時間どおりに戻ります。
- **マップの全員に見えます。** 能力が始まると、そのマップのパイロットに知らされます。ゲームがリング、言葉、効果を描き、音を鳴らします。

## 十二の能力 {#the-twelve-abilities}

能力は**予告**から始まります(項目に「すぐに始まります」とあるものを除く)。船に向かって閉じていくリングと、その上に出る言葉です。以下の時間と数値は重い種類のものです。数値がいくつかあるときは、括弧内のティア、つまりエイリアンの名前の前のギリシャ文字ごとの値です。

### 再生 {#regenerate}

その場に止まり、6秒かけて船体とシールドの15% / 20% / 25% / 30% (α / β / γ / δ)を回復します。その間は何も撃ちません。船体とシールドを合わせた最大値の10%に達するダメージで中断され、それまでに回復した分は保たれます。

- **予告**: 1.5秒
- **艦の上に出る言葉**: 再生中
- **持つもの**: どのエイリアンでも
- **対処**: ロケットや大勢の艦で一気に削るか、予告の間に破壊してください。

### シールドバースト {#shield-burst}

最大船体の15% / 20% / 30% / 40% (α / β / γ / δ)にあたる新しいシールド層がシールドの上に加わります。残っている間はあらゆる攻撃を丸ごと受け止め、使い切るか10秒で消えます。

- **予告**: 1秒
- **艦の上に出る言葉**: シールド展開
- **持つもの**: どのエイリアンでも
- **対処**: シールドを貫通する弾薬とロケットのほうがよく通ります。または別のエイリアンを撃って、消えるのを待ちましょう。

### 装甲硬化 {#hardened-plating}

7秒 / 8秒 / 10秒 (β / γ / δ)の間、あらゆる攻撃の50%しか受けません。船体もシールドも同じで、2倍の頑丈さです。戦い続け、こちらの命中数値は灰色になります。

- **予告**: 1.5秒
- **艦の上に出る言葉**: 装甲硬化
- **持つもの**: 重量種(Bulwark, Goombah と Crystalys)と重量種の群れのリーダー(Pirate Boss と Boss Phantasm)、β以上
- **対処**: 終わるのを待ち、その間は別のエイリアンを攻撃して、バーストは終わった後のためにとっておきましょう。

### 激昂 {#enrage}

10秒の間、ダメージは×1.3 / ×1.4 / ×1.5 / ×1.75 (α / β / γ / δ)、速度は×1.25になります。

- **予告**: 1秒
- **艦の上に出る言葉**: 激昂
- **持つもの**: どのエイリアンでも
- **対処**: シールドを維持し、動き続け、射程の外にいましょう。

### 増援要請 {#call-reinforcements}

4 / 6 (γ / δ)の小型エイリアンが、マップの最も近い端から、3秒間隔の2回のウェーブで入ってきます。来る種類はPhantasm(Bulwark と Goombahが呼んだもの); Bulwark(Crystalysが呼んだもの)です。合わせて船体とシールドの45% / 60% (γ / δ)を持ち、その一斉射撃の50%を撃ちます。報酬もドロップもなく、何にも数えられず、45秒後、または呼んだ側が破壊されると去ります。

- **予告**: 2秒
- **艦の上に出る言葉**: 増援要請中
- **持つもの**: 重量種(Bulwark, Goombah と Crystalys)と重量種の群れのリーダー(Boss Phantasm と Boss Goombah)、γ以上
- **対処**: 呼んだ側を破壊してください。艦は一緒に消えます。範囲攻撃の武器なら一掃できます。

### 分身 {#clones}

3 (γ / δ)の分身が周りに現れ、名前も見た目も同じです。合わせて船体とシールドの18% (γ / δ)を持ち、何も撃たず、報酬もなく、15秒、または本物が破壊されるまで続きます。分身が出ている間、本物には細いリングが付き、ターゲットウィンドウでは分身が「デコイ」と表示されます。

- **予告**: 1秒
- **艦の上に出る言葉**: 分身中
- **持つもの**: どのエイリアンでも、γ以上
- **対処**: 本物のリングと動く船体バーを追うか、範囲攻撃の武器を使いましょう。

### 離脱と帰還 {#flee-and-return}

5秒 / 6秒 / 7秒 / 8秒 (α / β / γ / δ)の間、速度×2で攻撃者から逃げ、その後、最初に自分を攻撃したパイロットに向き直ります。マップから出ることも安全地帯に入ることもなく、その間ずっと攻撃でき、撃破の権利を持っていたパイロットはそれを保ちます。

- **予告**: 0.5秒
- **艦の上に出る言葉**: 離脱中
- **持つもの**: どのエイリアンでも
- **対処**: 追いかけるか、飛んでいる間にロケットを当てましょう。

### ライフドレイン {#life-drain}

10秒の間、他には何も撃ちません。毎秒、射程内のすべての艦を、避けようのない完全な一斉射撃で吸い取り、与えたダメージの75% / 100% / 100% (β / γ / δ)を回復します。回復は合計で船体の20%までです。

- **予告**: 1秒
- **艦の上に出る言葉**: 吸収中
- **持つもの**: 重量種(Bulwark, Goombah と Crystalys)と重量種の群れのリーダー(Pirate Boss, Boss Phantasm, Boss Goombah と Boss Crystalys)、β以上
- **対処**: 射線に岩か壁を置くか、ステルスにするか、射程から出ましょう。

### ノヴァパルス {#nova-pulse}

予告の間、周りの地面にリングが広がります。リングが満ちると、中にいるすべての艦を一度ずつ、その一斉射撃の4 / 5 (γ / δ)で攻撃します。半径は700 / 800 (γ / δ)ユニットです。

- **予告**: 2.5秒
- **艦の上に出る言葉**: ノヴァ
- **持つもの**: 重量種(Bulwark, Goombah と Crystalys)と重量種の群れのリーダー(Pirate Boss, Boss Phantasm と Boss Goombah)、γ以上
- **対処**: リングが満ちる前に外へ出ましょう。避けられる唯一の一撃です。

### ロケット斉射 {#rocket-barrage}

3秒かけて、標的に4 / 6 / 8 (β / γ / δ)発の[Rivetロケット](/wiki/06-Items/Rockets.md#the-twelve-rockets)を撃ちます。種類はRivet I / II / II (β / γ / δ)です。まっすぐ飛び、誘導はされません。

- **予告**: 1.5秒
- **艦の上に出る言葉**: 斉射
- **持つもの**: 重量種(Bulwark, Goombah と Crystalys)と重量種の群れのリーダー(Boss Phantasm と Boss Goombah)、β以上
- **対処**: 動き続けましょう。ロケットはまっすぐ飛びます。間に岩があれば止まります。

### ベール {#veil}

6秒 / 8秒 (γ / δ)の間、700ユニットより離れた艦はロックオンできず、ロックしていた場合も失われます。それより近ければ通常どおり見えます。戦い続け、爆風は今までどおり当たります。

- **予告**: なし。すぐに始まります。
- **艦の上に出る言葉**: 隠蔽中
- **持つもの**: 重量種(Bulwark, Goombah と Crystalys)と重量種の群れのリーダー(Pirate Boss, Boss Phantasm, Boss Goombah と Boss Crystalys)、γ以上
- **対処**: 700ユニット以内まで近づきましょう。

### 機雷散布 {#sow-mines}

標的が立っていた場所の周りの半径500ユニットのリングに、4 / 6 / 8 (β / γ / δ)個の機雷を置きます。機雷は着地の3秒後に作動可能になり、30秒残り、その上を最初に通ったパイロットの艦の下で一度だけ爆発して、エイリアンの一斉射撃の2 / 3 / 3 (β / γ / δ)を与えます。機雷はエイリアンを傷つけません。

- **予告**: 1.5秒
- **艦の上に出る言葉**: 機雷散布中
- **持つもの**: 重量種(Bulwark, Goombah と Crystalys)と重量種の群れのリーダー(Pirate Boss, Boss Phantasm, Boss Goombah と Boss Crystalys)、β以上
- **対処**: 避けて通りましょう。地面に描かれていて、作動可能になるのは遅めです。

## 分裂 {#splitting}

<!-- mob-split:begin -->
<!-- Generated from server/Resources/MobAbilities.json (and the client's locales/<language>/mobs.toml) by scripts/mob-abilities-wiki.sh: don't edit by hand. -->

最後のティアの小型エイリアンは、速く倒しすぎると分裂することがあります。対象はδティアのSeeker, Phantasm, Bulwark, Goombah と Crystalysだけで、他のエイリアンにはなく、上の能力の一つでもありません。両方を持つエイリアンもいます。

- **いつ**: パイロットが、最初に受けたダメージから5秒以内に破壊したとき。そんなに速く倒れたエイリアンすべてが分裂するわけではありません。
- **何が出るか**: 同じ種類とティアのエイリアンが3体。大きさは70%で、それぞれ船体とシールドの25%と完全な一斉射撃を持ち、破壊された場所の周りに現れます。破壊したパイロットに向かい、180秒後に去ります。
- **普通のエイリアンです**: 一体ごとにその種類と同じ報酬を払い、同じものをドロップし、クエストと統計に数えられます。能力は持たず、分裂することもありません。
- **制限**: 一つのマップに存在できる破片は最大60体で、マップ本来のエイリアンの出現を妨げません。
- **意味すること**: エイリアンを十分に速く倒せるクルーは、一体から最大4回の撃破を得られます。そうでないクルーは何も得られません。

## ボスの三つの段階 {#the-bosses-three-steps}

どのボスも三つの段階で戦い方を変えます。戦いが始まったとき、船体が三分の二を切ったとき、三分の一を切ったときです。段階は一度だけ起こり、元には戻りません。ただし、下に書かれているとおり、ボスが最初からやり直す場合は別です。

<!-- mob-ladders:begin -->
<!-- Generated from server/Resources/MobAbilities.json (and the client's locales/<language>/mobs.toml) by scripts/mob-abilities-wiki.sh: don't edit by hand. -->

- **段階ごとの小休止。** 最初の後に、やることのある段階が始まると、ボスは1.5秒の間ダメージを受けません(ダンジョンの Warlordとソロゲートのボスは3秒)。
- **特殊能力も。** Pirate Boss, Boss Seeker, Boss Phantasm, Boss Goombah と Boss Crystalysは特殊能力も持つことがあります(Dormant Force と Tesseractは持ちません)。それは二番目と三番目の段階の間に来ます。二つが同時に始まりそうなときは、後のほうが最大3秒待ちます。リーダー自身の段階が使う能力が選ばれることはありません。
- **最初からやり直し。** Tesseractは、完全に回復すると段階を最初からやり直します。

### ダンジョンの Warlord {#the-dungeon-warlord}

- **三分の二を切ると**: 能力と能力の間隔が4秒に、待機時間が×0.75になります。
- **三分の一を切ると**: 間隔が2秒に、待機時間が×0.5になり、ダメージが×1.25になります。無料のMeteor一斉射撃を一度行い、Swarmは120秒より短い間隔では戻りません。
- **段階ごとの小休止。** 段階が始まると、Warlord は3秒の間ダメージを受けません。
