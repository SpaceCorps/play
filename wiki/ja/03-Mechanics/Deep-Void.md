# Deep Void

<!-- wiki-search: deep void; dv-1; the hollow reach; void gate; threshold; seed; unwakened; crossing; breach; last light; lantern; lanterns; snuffer; fear; monster; flare; flares; davidski; leviathan; lost expedition; darkness; running dark; void bloom; static storm; dark matter; ランタン; 恐怖; モンスター; フレア; 暗闇; ダークマター; 失われた遠征隊; 渡航; graveyard; maw; lattice; throat; drowned flagship; listener; revenant; void mite; shade; blackout; gravity sink; crystal; wall shadows; quartermaster; contract; whisper; dormant swarm; 結晶; ブラックアウト; 重力の穴; 壁の影; ささやき; 契約; 騒音 -->

**Deep Void** は Dormant Swamp の向こうに広がる闇です。その最初のマップ **`DV-1`「The Hollow Reach」** はゲームで最も大きなマップで、暗闇に包まれています。見えるのは光が照らすものだけです。各ワールドは Unwakened を倒し、`DS-4` に **Void Gate** を建造することで道を開きます。その後、キーカードの持ち主がゲートを開くと、近くにいる全員が向こう側へ渡ります。中では光があなたを生かします。ランタンと中央の Last Light です。持ち込んだフレアは行く手を照らし、誘導ロケットをそらしますが、何も締め出しません。闇に長くいるほど **恐怖** がたまり、恐怖が満ちると、殺すことのできない何かがやって来ます。

**1 分でわかる**

- [Unwakened](/wiki/03-Mechanics/Dormant-Swamp.md) は倒せるようになりました。各ワールドで **シーズン最初の撃破** が起きると、そのワールドの **Threshold** が `DS-4` の右上の隅に開きます。
- ワールドのパイロットたちが **Void Gate** に **Dark Matter Plate 20 枚** と **Thulium 200,000** を入れると、ゲートは **24 時間** かけて建造されます。**加速用 Thulium** を入れればもっと速くなります。
- **Dormant Keycard**（最後の [シグナル](/wiki/03-Mechanics/Signals.md) の報酬）を持つパイロットが **5,000 Thulium** でゲートを開きます。**120 秒** 後、リングの中にいる全員がそろって **Breach** へ渡ります。
- `DV-1` では船の前方の円錐だけが見えます。**真の光**（灯ったランタン、Last Light、Breach）は Void のエイリアンを寄せつけず、恐怖を下げます。フレアは真の光ではありません。
- Deep Void で死ぬと基地に戻されます。安全地帯の外はどこでも PvP です。

## Threshold と Void Gate {#the-threshold-and-the-void-gate}

- **Unwakened は倒せます。** 死んでから 24 時間後に戻り、沼地の 3 基の砲台（ロケット砲台 1 基とレーザー砲台 2 基）には耐久値がつきました。破壊された砲台は Unwakened が戻るまで止まったままです。[Dormant Swamp](/wiki/03-Mechanics/Dormant-Swamp.md) を参照してください。
- **Threshold。** あるワールドの Unwakened がそのシーズンで初めて倒されると、そのワールドの `DS-4` の右上、およそ **27,400 / 4,800** に場所が開きます。そこには **Seed**（ごく小さなブラックホール。飾りなので引力も放射線もありません）が **Void Gate** の空のフレームの中に浮かび、土台には 20 個の暗い受け口があります。Slumbering Void と Dormant Sentinel が周囲 2,500〜4,100 ユニットのリングを巡回します。ワイプまで残ります。`DS-4` は PvP で、Threshold もそうです。
- **ゲートはワールドごとに建てます。** Alpha、Beta、Gamma にはそれぞれ専用の Threshold、ゲート、プールがあります。3 つのゲートはどれもサーバーに 1 つだけの `DV-1` へ通じています。ワールドのゲートが建造を始めたときと開いたときには、サーバー全体に知らされます。
- **パネル。** フレームから **800 ユニット** 以内で、そのパネルが積荷から **Dark Matter Plate** を、財布から **Thulium**（1,000 単位）を受け取ります。そのワールドのパイロットなら誰でも、いつでも、いくらでも入れられます。入れたものはフレームに残り、返ってきません。クローク中の船はパネルを使えません。パネルには上位の貢献者と、ほかのワールドのゲートの進み具合が表示されます。

| プール | 容量 | 役割 |
| :--- | ---: | :--- |
| Dark Matter Plates | 20 | 建造を始める条件の半分 |
| Thulium | 200,000 | 残りの半分 |
| 加速用 Thulium | 最大 1,000,000 | 建造を速める |

### 建造 {#the-build}

20 枚目のプレート **と** 200,000 個目の Thulium が入ると、フレームはサーバーの時計で **24 時間** かけて建造されます。**5 段階** で、4 時間 48 分ごとに 1 段階ずつ進みます。アンカー、下部アーチ、支柱、クラウン、点火です。その後、ゲートはシーズンの残りのあいだ **開いた** ままです。

**加速用 Thulium** は建造を速めます。Threshold が開いた時点からゲートが開くまで、ゲート 1 つにつき最大 **1,000,000** Thulium まで入れられます。速度を 2 倍にするたびに、前回より多くの Thulium が必要です。建造中に入れた Thulium は、残りの作業を速めます。

| 加速用 Thulium | ゼロからの建造時間 | 速度 |
| ---: | ---: | ---: |
| 0 | 24 時間 | ×1 |
| 100,000 | 11 時間 13 分 | ×2.1 |
| 200,000 | 6 時間 41 分 | ×3.6 |
| 400,000 | 2 時間 48 分 | ×8.6 |
| 600,000 | 1 時間 18 分 | ×18.5 |
| 800,000 | 39 分 | ×37 |
| 1,000,000 | 20 分 | ×72 |

**フレームへのウェーブ。** フレームの建造中は、建造作業 2 時間ごとに **Slumbering Void 9 体と Dormant Sentinel 3 体** のウェーブがフレームに迫ります。1 回の建造で 11 回、どの速度でも同じです。ウェーブはフレームを囲むリングまで飛び、**ゲートを撃ちます**。ワールドには「フレームが攻撃を受けています。」と知らされます。1 体でも生きていて射程内にいる間、建造は**一時停止**し、フレームは**作業を失います**。1 ウェーブにつき最大 **30 分**で、その段階の開始点より前には戻りません。ウェーブを倒せば止まります。加速用の Thulium は建造を速くしますが、安全にはしません。ウェーブは作業の同じ時点で来ます。

### 渡航 {#the-crossing}

開いたゲートは、各パイロットが一人ずつ跳ぶポータルではなく、近くにいる全員を運ぶ仕掛けです。

- **起動。** **Dormant Keycard** を持つパイロットが Seed から 800 ユニット以内でゲートを起動し、**5,000 Thulium** を支払います。
- **カウントダウン：120 秒。** 誰がゲートを開いたかがサーバーに知らされ、終了 30 秒前にもう一度知らされます。Seed の周り **1,500 ユニット** のリングが渡航範囲を示します。
- **ウェーブ。** 0、30、60、90 秒の時点で、**12、15、24、27 体**（合計 78 体）の 4 つのウェーブが Threshold の端から現れます。最初は Slumbering Void と Lurker、2 つ目のウェーブからは Dormant Sentinel、最後のウェーブには Inert Mass も加わります。リングの中と近くにいるパイロットを狩ります。最初に狙われるのは起動した人です。ライバルも来られます。`DS-4` は PvP です。
- **渡航。** 0 になると、リングの中で生きている全パイロットがそろって `DV-1` へ渡り、**Breach** に着きます。同乗者にキーカードは不要で、支払いもありません。クローク中の船も渡ります。ミッションアイテムを運んでいるパイロットは渡れません。
- **休止。** ゲートは再び起動できるようになるまで **3 分間** 休みます。
- **帰り道は無料です。** Last Light と Breach のポータルは、通常のポータルジャンプと同じように、あなた一人を自分のワールドの Void Gate へ運びます。Base CPU も Deep Void で使えます。
- **ワイプ。** ワイプのとき、すべての Void Gate は Seed の中へ崩れ落ち、次のシーズンにまた建造されます。キーカード、探索済みのマップ、失われた遠征隊、実績は残ります。

## DV-1, The Hollow Reach

- **サーバー全体で 1 つのマップ。** Alpha、Beta、Gamma のパイロットが一緒に `DV-1` を飛びます。各サーバー（Home、US、Singapore）にそれぞれ 1 つあります。ワールドチャットとクランは自分のワールドのままです。
- **大きさ。** 128,000 × 72,000 ユニット、`DS-4` の 16 倍の面積です。巡航速度で端から端まで約 6 分かかります。
- **強さと報酬。** 全員に 1 組の数値、Gamma のものが使われます。エイリアンは Alpha の 2 倍の強さで、3 倍の報酬を払います。
- **安全地帯の外はどこでも PvP。** Last Light の安全地帯、Breach のキャンプ、ポータルのリングは安全です。それ以外の場所では、どのワールドのパイロットでもあなたを攻撃できます。
- **死。** Deep Void で死ぬと基地に送られます。戻るには渡航が必要です。
- **壁。** 結晶の尾根、残骸、壊れた巨大構造物が、船もエイリアンも射撃も遮り、あなたの光も遮ります（[光と壁](#light-and-walls)を参照）。クリックで指定した針路は、それらを避けるように計画されます。

| 地域 | どんな場所か |
| :--- | :--- |
| Last Light | 中央の基地。照らされ、守られ、安全です（下記参照）。 |
| The Breach | すべての渡航の到着地点。西にあり、Davidski のキャンプがあります。 |
| The Hollows | 北西にある結晶の尾根の密な迷路。脇道では Lurker が待ち構え、Shade がその間をうろつきます。 |
| The Glow | 北にある放射線の地帯。あらゆる大きさの Void Bloom と、Void Mite の群れがいます。 |
| The Silent Expanse | 南の開けた真っ暗な領域。Leviathan の縄張りで、Dormant の群れが 1 日に 1 回訪れる場所です。 |
| The Graveyard | 北東にある失われた遠征隊の残骸地帯。Revenant、Shade、そして中央には Drowned Flagship がいます。 |
| The Maw | 東にある壊れたリングで、遠くからでも光る 3 つの小さなブラックホールを囲みます。Deep Mass が持ち場を守っています。 |
| The Lattice | 南西にある結晶のパイロンで、撃ち壊せる淡い結晶の壁でつながっています。その裏には Lurker の巣があります。 |
| The Throat | 南東の果てで生きた結晶に封印されており、あなたの失われた遠征隊が開くまで入れません。中には Listener がいます。 |

### 闇と視界 {#darkness-and-sight}

- **あなたの光** は、船の前方に画面の端まで伸びる **円錐** と、周りの小さな **光の輪** です。どんな光が照らすものでも見えます。自分の光、グループの光、ほかのパイロットの円錐、ランタン。Skylab の[レーダーモジュール](/wiki/03-Mechanics/Skylab.md#radar-module)はレベル 3 であなたの円錐を 80 度から 110 度に広げます（マップに入ったときに読み取られます）。
- **光るもの** は遠くからでも見えます。Void Bloom、ランタン、Last Light、Seed、Angler のおとり、Maw の重力の穴、Leviathan の目。どの光も照らしていないものは描かれません。船も、名前も、体力バーもです。
- **判断するのはサーバーです。** どの光も照らしていないものは、そもそもあなたのゲームに送られないので、PvP でも闇は公平です。
- **無灯火飛行。** **0** を押すと光が消えます。ほかのパイロットからは、別の光に照らされたときしか見えず、あなたにも光るものしか見えません。撃つと 5 秒間光が戻ります。光を消して闇にいると、恐怖は 1.5 倍の速さで増えます。
- **マップは霧です。** `DV-1` は 2,000 ユニットの区画 2,304 個でできていて、光が見つけるまで真っ黒です。見つけた区画はずっとあなたのものです。銀河マップには探索した割合が表示されます（**探索済み 37 %**）。

### 光と壁 {#light-and-walls}

- **壁はあなたの光を遮ります。** あなたの円錐とハローは、結晶、残骸、岩を通りません。壁の向こうにいるエイリアンや、ライトを消して飛ぶ船は、あなたには照らされません。描かれず、名前も体力バーもなく、ロックオンもできません。これが Hollows を本物の迷路にしています。船から 150 ユニット以内では何も隠れません。
- **光るものは決して遮られません。** ライトをつけた船は自分で光り（あなたの光はあなたの居場所を教えてしまいます）、ランタン、Last Light、Breach は壁を越えて光ります。間に何があっても、Void は外に締め出されます。フレア、Void Bloom、Angler のおとりも壁を越えて光りますが、その中にあるものを見せるだけです。
- **サーバーが決めます。** 壁があなたから隠すものは、あなたのゲームにはまったく送られません。改造したクライアントには、明かせるものが何もありません。
- **影を描くのはコンピューターだけで、スマホは描きません。** **壁の影**（設定、グラフィック）はコンピューターでは初期設定でオンで、絵が変わるだけです。スマホとブラウザーは影を描きませんが、サーバーは同じものを隠します。
- **なくなった壁は何も遮りません。** 結晶が撃ち壊されると（下を参照）、あなたの光、射撃、針路は、すぐにその隙間を通ります。

### 壊せる結晶 {#breakable-crystal}

Lattice の淡い結晶の壁は撃ち壊せます。ほかの壁は壊れません。

- **レーザーだけ。** 1,400 ユニット以内から結晶を押してターゲットにし、船と同じように撃ちます（ダブルクリック、ターゲットウィンドウの攻撃ボタン、または攻撃キー）。ターゲットウィンドウには**結晶**とそのヒットポイントが表示され、レーザーが届かないときは**遠すぎます**または**間に障害物あり**と出ます。ロケット、爆発、Siphon Battery は結晶に何もしません。
- **全員のダメージが合算されます。** パイロット 1 人なら 1 分以上、5 人のクルーなら約 15 秒です。傷ついた壁は決して治りません。壊れた壁は **30 分**後に完全な形で再び生え、その中にあるものを押し出します。
- **報酬はなく、全員にとっての扉になります。** 壁が壊れたことはマップ全体に伝わります（誰が壊したかは伝わりません）。ライバルもあなたと同じようにその隙間を使え、背後の Lurker の巣は開いてしまいます。

### 危険 {#hazards}

- **Void Bloom**：4,000〜7,500 ユニットの放射線の塊で、他のどこよりも Glow に多くあります。縁では毎秒、艦の最大船体の 1 %、中心では 4 % を船体から直接焼き（シールドは受け止めません）、クロークしていても防げません。[Radiation tech](/wiki/03-Mechanics/Pilot-Skills.md) で線量を下げられます。光っているので遠くから見えます。横切ることになるクリックは、ブラックホールが進路を曲げるのと同じように、迂回するよう計画されます。内側で終わるクリックはそのまま飛行します。残り時間を示すゲージが表示され、縁の手前で警告が鳴り、内側ではガイガーカウンターが鳴ります。
- **Static Storm**：外側の地域を 10 分間漂う、3,000 ユニットの嵐です。中では毎秒、艦の最大船体の 1 % を船体から直接失い、光の届く距離が半分になります。発生の 30 秒前にマップへ警告が出ます。
- **重力の穴**：Maw にある 3 つの小さなブラックホールで、それぞれ `DS-4` の[ブラックホール](/wiki/03-Mechanics/Black-Hole.md)を半分の大きさにしたものです。穴は 1,500 ユニットから引き寄せ、2,000 から放射線で焼き（Radiation tech で線量を下げられます）、150 で船もエイリアンも同じように飲み込みます。2,400 ユニットから光るので、殺される前に見えます。ゲージ、警告、ガイガーカウンターはブラックホールと同じように働きます。穴を横切ることになるクリックは、迂回するよう曲げられます。内側で終わるクリックはそのまま飛行します。エイリアンは自分からは円の中に入りませんが、押し込まれたものは引力に捕らえられます。
- **ブラックアウト**：20〜30 分ごとにマップ全体が暗くなります。5 秒前に鼓動が鳴り、そのあと **20 秒間**、すべての光の届く距離が 40 % になります。あなたの円錐とハロー、ランタン、フレアです。Last Light の投光と Breach の光は決して縮まないので、そこへ走ってください。恐怖は、光の残った範囲の内側でしか下がりません。死者が起き上がるのはこのときです。Revenant は 1.5 倍の速さで動き、暗闇が真の光の外に置き去りにしたパイロット 1 人につき、さらに 2 体が呼び出されます（同時に最大 24 体。暗闇が降りてから 80 秒後に消えます）。

## 光と闇 {#light-against-dark}

**真の光** とは、あなたを生かす光です。灯った **ランタン**（2,500 ユニット）、**Last Light**（5,000）、そして **Breach**（1,500）。その中では：

- **Void のエイリアンは入ってきません。** そのレーザーも光の縁で止まります。あなたを追っていたエイリアンはあきらめて闇へ戻ります。
- **ただし、その光の中から撃った場合は別です。** 真の光の中に立ったまま命中させたエイリアンは、最後の命中からしばらくの間あなたを標的にします。その光の中に入ってきて攻撃し、Revenant もその光では動きを止めません。闇の中からの命中は何も変えず、撃っていないそばのパイロットは放っておかれます。**Last Light と Breach の光は決して譲りません**。そこから撃っても挑発は起きません。Deep Mass、Dormant Swarm の艦、ボスは挑発されません。
- **恐怖が下がります**（下記参照）。下がるのはここだけです。
- **ほかのパイロットはまだ攻撃できます。** 光が遠ざけるのは Void であって、ライバルではありません。しかも光はあなたの姿を彼らに見せます。

船の円錐、フレア、Void Bloom、Angler のおとりは真の光ではありません。

### ランタン {#lanterns}

失われた遠征隊は `DV-1` に **78 基のランタン** を立てました。そのほとんどはとうに消えています。

- 400 ユニット以内で、積荷の **ダークマター 1 個** を使って **灯します**。**10 分間** 光ります。誰でも燃料を足せて、タンクには最大 **1 時間** 分入ります。サーバーの時計で燃え続けます。
- **ちらつき。** 最後の 1 分になるとランタンはちらつき、近くのパイロットに知らされます。
- **壊れることがあります。** ランタンの耐久値は 300,000 です。Snuffer に食べられるほか、**パイロットも撃って消せます**（報酬はなく、誰がやったかはマップ全体に知らされます）。壊れたランタンはすぐに消えて燃料を失い、3 分後にまた灯せます。
- **共有。** ランタンはみんなのもの、3 つのワールドすべてのものです。ミニマップと全体マップには、見つけたランタンが灯っている、ちらついている、消えている、壊れている、のどれかで表示されます。
- **初めての光。** 人生で初めて各ランタンを灯すと **1,000 XP** がもらえ、**点灯夫** の [実績](/wiki/03-Mechanics/Achievements.md) に数えられます。

### Snuffer {#snuffers}

青白く、蛾のようで、弱い **Snuffer** は、パイロットをまったく相手にしません。撃ってくることもありません。闇の中から波のように現れて、灯ったランタンへ向かいます。真の光に入ってくる唯一のエイリアンで、ランタンにたどり着いた 1 体ごとに、その外殻を食べ、燃料を燃やします。誰も守っていないランタンは数分で食べ尽くされます。撃ち落としましょう。ときどきダークマターを落とします。

### 恐怖とモンスター {#fear-and-the-monster}

**恐怖** は、船体とシールドの横に表示される 0〜100 % のバーで、Deep Void のマップでだけ使われます。

| 行動 | 恐怖 |
| :--- | :--- |
| 闇の中にいる | 毎秒 +0.8（空から満杯まで約 2 分） |
| 無灯火で飛ぶ（光を消す） | 闇による増加 × 1.5 |
| 1,000 ユニット以内のグループメンバー | 1 人ごとに闇による増加 −20 %、最大 −40 % |
| 飛行：速いほど増える | 毎秒 350 ユニットまでは増えず、1,000 で毎秒 +1、それ以上も同じ直線で増加（1,650 で +2）。Afterburner はただ速い船として扱う |
| レーザー斉射 1 回 | +0.15 |
| ロケット 1 発 | +4、特殊ロケットは +8、N.U.K.E. または N.I.K.E. は +15 |
| **真の光の中にいる** | **毎秒 −10**、何も加算されません |

4 つの [パイロットスキル](/wiki/03-Mechanics/Pilot-Skills.md) が、それぞれ 1 つの要因をレベル 100 で最大 20 % 減らします。**Grit** は闇、**Thruster theory** は高速飛行、**Laser tech** は斉射、**Rocket tech** はロケットによる恐怖です。

| 恐怖 | 起こること |
| ---: | :--- |
| 50 % | エイリアンが 1.5 倍遠くからあなたに気づきます。 画面の端でささやきが始まります。 |
| 75 % | 8,000 ユニット以内の強いエイリアンが狩りに来ます。 あなたの光の端に暗い影が這い寄ります。 |
| 100 % | **モンスターが来ます。** |

**ささやきと影**は、真の光の外で、あなた自身の画面にだけ描かれます。45〜90 秒ごとに船の後ろに短い 1 行が現れ、ハローの縁に数匹の虫が現れます。雰囲気のためだけのもので、撃つこともできず、あなたを傷つけることもできません（本物の生き物も光の縁に潜んでいます）。**暗闇のささやきと影**（設定、インターフェース）でオフにできます。

**モンスター** は触手と虫の群れで、恐怖が満杯になったただ一人のパイロットを目指して闇から現れます。速度は **750** で、どの船よりも速く、壁をすり抜け、**倒すことはできません**。追いつかれると **船は一瞬で飲み込まれます**。シールドもクロークも役に立ちません。光の中には決して入りません。恐怖が下がり始めた瞬間（真の光にたどり着いた瞬間）、向きを変えて逃げていきます。恐怖は死亡時、渡航時、ログイン時に 0 に戻ります。

### フレア {#flares}

**フレア**（ショップの特殊ロケットで、Davidski と Quartermaster も売っています）はカーソルの方向へ最大 1,000 ユニット撃ち出され、**そこで 10 秒間燃え続けます**。燃えているあいだ、800 ユニット以内でロックオンしている誘導ロケットはすべてフレアへ向きを変え、無害にはじけます。これはどのマップでも同じです。Deep Void では、その **700 ユニットの光は見るための光で、真の光ではありません**。光の中にあるものを見せるだけで、**何も止めません**。Void のエイリアンやボスは、燃えているフレアの下でも、フレアがないのとまったく同じようにあなたを攻撃します。Void Mite はフレアに引き寄せられず、中で恐怖は下がらず、モンスターもフレアから向きを変えません。フレアは 10 秒間の明かりであり、誘導ロケットへのおとりです。避難所ではありません。

## Last Light

戻らなかった遠征隊の前哨基地で、`DV-1` の中央にあります。その防衛設備は今も動いています。

| リング | 半径 | 役割 |
| :--- | ---: | :--- |
| 投光照明 | 5,000 | 真の光。昼間のように明るい。 |
| 防衛 | 4,500 | 4 基のレーザータレットと 1 基のロケット砲台がエイリアンを撃ちます。パイロットは決して撃ちません。 |
| 安全地帯 | 3,000 | 何もあなたを傷つけられません。PvP はありません。 |
| Mission Control、Xenolab、Quartermaster | 1,600 | **Void Control** が失われた遠征隊と日替わりの契約を与え、**Xenolab** が [旅人のガイド](/wiki/03-Mechanics/Travelers-Guide.md) を研究し、**Quartermaster** がレーザー弾薬、ロケット、Repair Drone を売ります。 |
| 回復リング | 1,200 | 安全地帯に守られているあいだ、毎秒総 HP の 2 % を回復します。 |

タレットのダメージは誰の報酬にもなりません。パイロットは自分が与えた分だけ報酬を受け取ります。中央にある Last Light のポータルは、無料で自分のワールドの Void Gate へ運んでくれます。ハンガーはないので着陸はできません。 **Quartermaster** は飛行中のパイロットに、あなたにとってのショップの価格で売ります。**Flares** も売っており、1 個 25,000 Credits（Davidski の分は 30,000）で、20 個まで持てます。

## Davidski のキャンプ {#davidskis-camp}

すべての渡航は **Breach** に着きます。そこでは [Davidski](/wiki/03-Mechanics/Davidski.md) が Breach の光の中に金色の Ironclad を停めています。いつものように、彼が一番乗りでした。

- **キャンプは安全です。** 1,500 ユニット以内では PvP がなく、その光は真の光です。
- **彼は倒せません。** 撃つと、安全地帯であろうとなかろうと、300,000 の射撃を 2〜3 発撃ち返してきます。
- 1,500 ユニット以内で **話しかけましょう**。初めて訪れたときは、彼のウィンドウが自動で開きます。闇について説明し、失われた遠征隊の最初の 2 段階を与え、頼めば *Calloway* の最後の飛行の記録をもう一度見せてくれます。
- **彼の店**：**Flares** が 1 つ 30,000 Credits、**Organic Scanner I** が 250,000 Credits。スキャナーは研究すれば（CPUs）組立でも作れます。

## エイリアン {#the-aliens}

Deep Void のエイリアンはどれも、闇の中では単独のパイロットにとって脅威ですが、真の光の中ではどれもあなたに届きません（その光の中から撃った場合を除く。[光と闇](#light-against-dark) を参照）。多くが、このマップのありふれた戦利品である **ダークマター** を落とします。ランタンで燃やさなかった分は持ち帰れます。数値は [旅人のガイド](/wiki/03-Mechanics/Travelers-Guide.md) にあります。この Wiki は、あなたが習得または研究したものの数値しか表示しません。

- Dormant Swamp の **Slumbering Void** が、基地の外のあらゆる場所をうろついています。**Deep Mass** は持ち場を離れません。Dormant Swamp の Inert Mass に、はるかに厚いシールドを与えた独自の種類です。
- **Lurker** は脇道や Lattice の巣で光をまとわずに待ち構えます。船が近づくと目を覚まし、飛びかかって強くかみつき、そのまま戦い続けます。
- **Angler** は、遠くからは灯ったランタンに見える光をぶら下げています。それはランタンではありません。近づくと光が消え、闇から Lurker が出てきます。
- **Revenant** は失われた遠征隊の残骸で、闇の中でしか動きません。**真の光**も、どのパイロットの円錐も、どのパイロットの光の輪も Revenant を凍りつかせます。**ただし、狙われているパイロット自身の光の輪は別です**。自分の光の輪では止められないので、一人のときは円錐を当て続けて止めます。Void Bloom の輝きと Angler のおとりでは決して凍りつきません。闇の中では素早く迫り、**シールドと船体を同時に吸い取ります**。シールドは船体を守らず、**Grit や Diminisher でもこの吸い取りは軽減されません**。凍りついた Revenant は何も吸い取りません。 Graveyard にあふれ、ブラックアウトはさらに呼び起こします。1 体を光の中に保ち、倒してください。
- **Void Mite** は 10〜30 体の群れで飛び、主に Glow にいます。光に引き寄せられ、狩れる中で最も明るいパイロットへ向かいます（フレアは彼らをどこにも引き寄せず、何からも遠ざけません）。ライトを消して飛ぶと見失い（撃つと 5 秒間ライトがつきます）、Void のエイリアンが入れない真の光でも見失います。船に触れた Mite はシールドを、シールドがなくなれば船体を吸い取ります。群れ全体なら無防備な船を破壊でき、Mite に食われた船は撃破者も報酬もなく沈みます。1 体では弱く、大きな爆発や貫通する射撃で群れを一掃できます。
- **Shade** はパイロットのふりをします。本物の船の見た目、ミニマップ上の点、ノイズの名前（`%`、`#`、`@`、`&`、`?` から 3〜6 文字）を持ち、ライトをつけた船と同じように光ります。パイロットの名前は英数字とアンダースコアで、ノイズになることはありません。それが見分け方です。Shade は、あなたが近づいたときや、あなたを狩っているときに正体を現し、攻撃が当たると 20 秒間、全員に正体が見えます。真の光には決して入りません。Shade への招待やプライベートメッセージは、そんなパイロットはいないかのように返されます。Shade は Graveyard と Hollows に出没します。
- **Snuffer** はランタンを食べます（上記参照）。**モンスター** は恐怖が満杯になると来ます（上記参照）。
- 新しい種類には **6 つのドロップ**があります。Revenant Ash、Mite Swarm Core、Shade Mask、Flagship Log、Listener Shard、Void Coordinates です。今のところはコレクション用で、オークションでは売れず、まだレシピもありません。[リソース](/wiki/06-Items/Resources.md)を参照してください。

### Leviathan {#the-leviathan}

全長およそ **10,000 ユニット** の体節を持つ巨大な虫が、**Silent Expanse** を泳ぎ回っています。見えるのは光が当たった部分と、体に沿って並ぶ目だけです。

- **その体は**、通り抜けたすべての船を傷つけます。頭が最も強力で、船を押しのけます。
- **目が撃ちます**：各体節の目が開いて紫に光り、その 1 秒後に射程内で真の光の中にいない最も近いパイロットを撃ちます。無灯火飛行でも隠れられません。開いた目はダメージをすべて受けますが、閉じた体節は半分しか受けません。頭はより多く受けます。
- **突進します**：すべての目が一斉に閉じ、頭が一直線に突っ込みます。
- **潜ります**：闇の中に沈み、パイロットたちを突き抜けて浮上します。浮上する場所は 2 秒前に紫の波紋で示されます。
- **各パーツには独自の船体とシールドがあります。** 頭、各体節、尾はそれぞれ別々に破壊され、命中は当たったパーツだけを傷つけ、何も回復しません。
- **体が分断されます。** パーツを撃ち落とすとそこで虫が切断され、断片はそれぞれ独りで飛び続けます。短い断片は突進も潜行も巻きつきもできません。
- **ボスは 1 体です。** すべての断片のすべてのパーツが破壊されたときにだけ倒れ、最後に落ちたパーツが撃破になります。下の 60 % と 30 % は戦い全体の残りで数えます。
- **自分の縄張りにとどまります**（Silent Expanse の中）。
- **60 % 未満** になると、グループの周りに巻きつきます。光っている体節を壊すとリングが開きます。**30 % 未満** になると、近くのランタンが 5 倍の速さで燃料を燃やします。
- そばにいると恐怖が毎秒 1 ずつ余分に増えるので、長い戦いはモンスターとの競争でもあります。
- 倒されてから {{guide:vitals.respawn@The Leviathan}} 後に戻ってきます。その箱は 1 回だけ抽選され、撃破で報酬を受け取るパイロットのあいだで分けられます。

### Drowned Flagship {#the-drowned-flagship}

Static に奪われた遠征隊の旗艦は、**Graveyard** の中心に横たわっています。真の光には決して入らない、巨大で遅い船です。3 つのフェーズを持つ 1 体のボスで、フェーズは二つの値のうち低いほうに従います。**船体の残り割合、または船体とシールドを合わせた残り割合**です。そのため、貫通射撃でもフェーズを飛ばすことはできません。

- **最初から舷側砲。** 視界に船がある側の舷は砲弾の一斉射撃を行い、直前に閃光が走ります。両側にパイロットがいれば、両方の砲列が撃ちます。
- **3 分の 2 から 3 分の 1 までは Lights Out。** {{guide:behaviour.ability:lightsout.everySeconds@The Drowned Flagship}} 秒ごとに、{{guide:behaviour.ability:lightsout.reach@The Drowned Flagship}} ユニット以内のすべてのパイロットが {{guide:behaviour.ability:lightsout.seconds@The Drowned Flagship}} 秒間ライトを失い（撃っても戻りません）、その範囲のランタンとフレアも同じです（ランタンは燃料を保ち、戻ります）。船が見えているパイロットには数秒前に警告が出ます。Revenant が現れ、暗闇に落とされたパイロットを狩ります。Last Light と Breach は決して消えません。ライトを失ったパイロットは照らされません。あなた自身の光だけであなたを見ていたライバルは、あなたを見ることも、ロックオンすることもできなくなり、あなたも光るものしか見えません。
- **3 分の 1 を下回ると、裂け目が漏れ出します。** 裂けた船体から、倒されるまで Void Mite が出てきます。Lights Out は終わります。
- **呼び出したものや漏れ出したものは、何にもカウントされません。** その Revenant と Mite はほかのものと同じように動き、傷つけますが、報酬も、ドロップも、クエスト、契約、ランキングへのカウントもありません。
- 撃破から {{guide:vitals.respawn@The Drowned Flagship}} 後に戻り、箱は最もダメージを与えたパイロットに渡ります。撃破への参加は、失われた遠征隊のステップ 8 です。

### Listener {#the-listener}

Static の源：**Throat** にある巨大な結晶の耳で、生きた結晶の向こうにいます。封印は、失われた遠征隊のステップ 9 の探索タスクが終わるとあなたのために開き、ステップが完了すると永久に開きます。パイロットごとに別々に開くので、そこまで進んでいないクルーの仲間はついてこられません。

- **狩りはせず、自前のレーザーもありません。** 聞くだけです。その聴覚の範囲内（あなたのレーザーの射程よりはるかに遠くまで届きます）で撃つレーザーの一斉射撃やロケットごとに、あなたに **騒音** が 1 つ加わります。恐怖バーの下のバーにスタック数が表示されます。
- **騒音が {{guide:behaviour.ability:noise.stacks@The Listener}} になると、あなたが選ばれることがあります。** 一度に 1 人のパイロットだけです。短い予告のあと、重いビームが来ます。真の光、安全な場所、クロークに入る、自分とそれの間に壁を置く、その射程から出る、ライトを消して飛ぶ、のどれかでビームは途切れます。すでにライトを消して飛んでいるパイロットは選ばれません。選ばれたあとは数秒待ってから次を選び、選ばれたパイロットの騒音は 0 から始まります。
- **静かにすると消えます。** 撃たずに {{guide:behaviour.ability:quiet.clearDarkSeconds@The Listener}} 秒間ライトを消して飛ぶと、騒音が消えます。クルーは交代で音を立てます。
- その体は大きく、レーザーは射程が中心までで数えられるため、内側からでも届きます。
- 撃破から {{guide:vitals.respawn@The Listener}} 後に戻ります。箱は一度だけ抽選され、撃破で報酬を受け取るパイロットで分けられます。その中に **Void Coordinates** が 1 つ入っています。撃破への参加は、失われた遠征隊のステップ 10 です。

### Dormant の群れの訪問 {#the-dormant-swarms-visit}

1 日に 1 回、[Dormant の群れ](/wiki/05-Swarms/Dormant-Swarm.md)（Dormant Force とその 2 体の Dormant Pulse）が **Silent Expanse** に来て、90 分とどまります。誰かが戦った場合は、破壊されるまでとどまります。誰も知らせず、どの地図にも印はなく、暗闇の中で見つけることになります。Dormant Swamp の群れで、攻撃されるまでは受け身ですが、攻撃されると、攻撃された船の近くにいるものがすべて加勢します。その船は `DS-4` と同じ報酬とドロップを持ち、強さは Deep Void のものです。最初の訪問はマップができてから 1〜6 時間後、次の訪問は前の訪問が終わった 1 日後に来ます。

## 失われた遠征隊 {#the-lost-expedition}

Deep Void のクエストチェーンです。一度に 1 段階ずつ進み、どの段階も人生で一度きりです（ワイプでも失われません）。最初の 2 段階、*記録* と *一つ灯せ* は Breach で Davidski が与え、残りは Last Light の **Void Control** が与えます。Davidski の段階の後は、どの段階も Dark Matter Plate を 1 枚支払います。各段階と報酬は [クエスト](/wiki/03-Mechanics/Quests.md#lost-expedition-table) の表にあります。

**Void 契約。** *First Light* を受け取ると、Void Control は毎日 3 つの契約も掲示します。全パイロットに同じもので、易しい契約、中くらいの契約、難しい契約が、10 種類の中から選ばれます（Void、Lurker、Snuffer、Revenant、Mite、Shade、Angler を一定数狩る、ランタンに火を灯す、ランタンの光の中で 10 分過ごす、Leviathan の撃破に参加する、など）。クエストと同じように受けて、こなして、受け取ります。終わっていないものは、日付が 00:00 UTC に切り替わるときに消えます。連続ボーナスはありません。それぞれがステップの 4 分の 1 を支払い、Deep Void での作業の受け取りには**あなた自身のワールド**の倍率が適用されます（Alpha ×1、Beta ×2、Gamma ×3）。その日の 3 つで、ブースト前に Alpha では 1,192,500 Credits と 8,925 Thulium、Beta ではその 2 倍、Gamma では 3 倍、さらにダークマター 25 です。難しい契約だけが Dark Matter Plate を 1 枚加えます。

## 知っておきたいこと {#good-to-know}

- **燃料を持っていきましょう。** ランタン用のダークマター、そして長い横断のための空の恐怖バー。フレアは数秒間だけ明るく照らし、誘導ロケットをそらしますが、何も遠ざけません。
- **一緒に飛びましょう。** 近くのグループメンバーは闇の中での恐怖の増加を遅らせ、みんなの円錐が同じ場所を照らします。
- **ロケットはうるさい。** ロケットは 1 発ごとに大量の恐怖を加えます。闇の中の戦いは、バーとの戦いでもあります。
- **光はあなたを見せてしまいます。** PvP では、灯ったランタンは、それが見えるすべてのライバルにあなたの姿を見せます。
- **結晶は慎重に撃ちましょう。** あなたが壊した壁はライバルにとっても扉で、元に戻るのは 30 分後です。
