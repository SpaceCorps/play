# Inviter des amis {#invite-friends}

Chaque pilote a un **code d’invitation** personnel. Un ami qui découvre le jeu l’utilise une fois et reçoit un pack de départ ; quand cet ami atteint le niveau 5, vous récupérez une récompense en Thulium, et davantage à mesure que d’autres de vos amis y arrivent. Tout se trouve sur une seule page : **Communauté › Inviter des amis**.

## Votre code {#your-code}

- Ouvrez **Communauté › Inviter des amis** pour voir votre code, écrit comme `BCDF-GHJK`. Il est créé la première fois que vous regardez et il est à vous pour toujours : il ne change jamais, et personne d’autre ne le voit.
- **Copier le code** place le code dans votre presse-papiers ; **Copier le message** y place un court texte, prêt à coller pour un ami : le nom du jeu, votre code et l’endroit où le saisir (et, hors Steam, où se procurer le jeu). Dans la version Steam, le message omet l’adresse de téléchargement.
- Vous pouvez saisir un code en majuscules ou en minuscules, avec ou sans le trait d’union.

## Ce que reçoit un ami {#what-a-friend-gets}

Un ami saisit votre code sous **Communauté › Inviter des amis** (la page affiche une carte **Un code d’un ami ?** à tout pilote qui peut encore en utiliser un) et reçoit, aussitôt et en une seule fois :

| Pack de départ | |
| :--- | :--- |
| **Crédits** | 100 000 |
| **Thulium** | 5 000 |
| **N.I.K.E.** | 1 |
| **Quantum Laser 2** | 1 |
| **Engine II** | 1 |
| **Advanced Plasma** | 1 000 |

Le pack arrive dans le hangar de l’ami. Advanced Plasma est une munition x2. Si une partie du pack ne peut pas être remise, rien ne l’est, et le jeu invite à réessayer plus tard.

## Qui peut utiliser un code {#who-can-use-a-code}

Le code est réservé aux **nouveaux comptes**, et le jeu y veille :

- **Niveau 4 ou moins.** Un pilote de niveau 5 ou plus ne peut pas utiliser de code.
- **Une fois par compte.** Un compte qui a utilisé un code ne peut pas en utiliser un autre.
- **Jamais votre propre code.**
- **Trois par adresse réseau et par jour.** Depuis une même adresse réseau (un foyer, une école, l’adresse partagée d’un opérateur mobile), 3 codes au plus peuvent être utilisés en 24 heures. La page l’indique quand un réseau a épuisé sa part ; réessayez demain ou depuis un autre réseau.
- **Pas de devinettes.** Dix codes que personne n’a, saisis en dix minutes, et le jeu vous demande d’attendre.

Un ami qui ne peut pas utiliser un code se voit expliquer pourquoi, en termes simples, sous le champ.

## Quand un ami atteint le niveau 5 {#when-a-friend-reaches-level-5}

Quand un ami qui a utilisé votre code atteint le **niveau 5** (160 000 d’expérience), une récompense de **2 500 Thulium** vous attend dans la liste d’amis, avec un bouton **Récupérer** à côté de l’ami. Elle n’est jamais versée d’elle-même : vous la récupérez, une fois par ami, quand vous voulez, même si le compte de l’ami n’existe plus entre-temps.

Un ami affiche l’un de ces trois états, en toutes lettres comme en couleur :

- **Inscrit** : a utilisé votre code.
- **Niveau 5 atteint** : la récompense vous attend.
- **Récupéré** : vous l’avez récupérée.

L’entrée **Inviter des amis** du groupe Communauté de la barre latérale porte un petit **(!)** tant que quelque chose attend d’être récupéré, tout comme **Retour à la base** en vol.

## Paliers {#milestones}

Les amis qui atteignent le niveau 5 comptent aussi pour une échelle de paliers. Chaque palier est payé une seule fois, dans n’importe quel ordre, quand vous le récupérez :

| Amis au niveau 5 | Récompense |
| :---: | :--- |
| **3** | 5 000 Thulium |
| **5** | 10 000 Thulium |
| **10** | 25 000 Thulium |
| **25** | 75 000 Thulium |

Un palier affiche **Verrouillé** (avec le nombre d’amis qui manquent encore), **Prêt** (avec un bouton **Récupérer**) ou **Récupéré**. Seuls comptent les amis qui ont atteint le niveau 5, pas ceux qui ont seulement utilisé le code, et un ami qui l’a atteint reste compté pour de bon.

## Bon à savoir {#good-to-know}

- La [réinitialisation](/wiki/03-Mechanics/Wipe-Timeline.md) de la saison ne touche ni les codes, ni les amis, ni ce que vous avez récupéré.
- Les récompenses et les paliers sont définis sur le serveur de jeu et peuvent changer lors d’une mise à jour ; la page affiche toujours ceux en vigueur.
- Un serveur de jeu qui date d’avant Inviter des amis n’a pas cette page : la section l’indique.
- Les amis que vous invitez peuvent rejoindre votre [clan](/wiki/03-Mechanics/Clans.md) ou votre [groupe](/wiki/03-Mechanics/Groups.md) comme n’importe quel autre pilote.
