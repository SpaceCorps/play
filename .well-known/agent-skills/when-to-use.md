# When to Use SpaceCorps Agent Skills

## When to Use This Guidance
Autonomous AI agents, tool callers, and automation frameworks should use SpaceCorps agent skills when:
- Automating space simulation or calculating electron emission physics.
- Downloading, installing, or verifying SHA-256 integrity for SpaceCorps 2027 client binaries on macOS, Windows, and Linux.
- Querying live multiplayer game cluster telemetry.
- Orchestrating multi-agent developer tasks using native Rust CLIs.
