# SpaceCorps Discord server art

Server icon and banner options for the **SpaceCorps - Alpha test** Discord server
(https://discord.gg/VjW67tkrTb). Everything is made from SpaceCorps 2027's own art: the game's
ship and portal models rendered in Blender, its skybox nebulae, its UI icons and the crest on the
ships' hulls. Type: Inter (SIL Open Font License 1.1).

## Avatars (server icon)

Square PNGs at 1024 px (`avatar-N-*.png`) and 512 px (`@512.png`). Discord shows the icon as a
circle, as small as 48 px, so every design stays inside the circle and carries no small text.

| File | What it is |
|---|---|
| `avatars/avatar-1-rocket` | The app icon's rocket on coral: matches the game's icon; the clearest at 48 px. |
| `avatars/avatar-2-horizon` | The Wraith in silhouette climbing past a planet's edge at sunrise. |
| `avatars/avatar-3-insignia` | The crest from the ships' hulls as a badge, with one dot per company. |
| `avatars/avatar-4-hero` | A close-up render of the Wraith over a blue nebula (best from about 96 px up). |
| `avatars/avatar-5-crescent` | A planet whose lit crescent forms a "C", with an orbit and a small moon. |

## Banners

JPGs at 1920x1080 (`banner-N-*.jpg`, the invite background) and 960x540 (`@960.jpg`, the server
banner). They keep the top band (the server name on desktop), the lower left (the name on mobile)
and the centre (the invite card) calm.

| File | What it is |
|---|---|
| `banners/banner-1-fleet` | The five ships flying in formation past a coral planet, no text. |
| `banners/banner-2-title` | "SpaceCorps 2027 · Alpha test" with the Wraith. |
| `banners/banner-3-companies` | The three companies, each with its ship, colour and name. |
| `banners/banner-4-portal` | The Wraith heading into a portal, no text. |

Server icon: Server Settings › Overview. Banner and invite background: Server Settings › the Server
Boost perks (they need boost levels 2 and 1).
